## Architectural Decisions (resolved during planning)

These choices are recorded so the executor does not re-litigate them.

1. **Skill name enum is open for extension, closed for v1.** The flag accepts the
   string `claude` only. The validation function returns the supported set as a
   slice so adding `copilot`/`cursor` later is a one-line change. The error path
   returns exit `3` (matching the M9-005 `--output` invalid-value path).

2. **Embed package lives at `templates/templates.go`** mirroring `schemas/schemas.go`
   (M8-001 pattern). Files live under `templates/skills/<skill-name>/curlew/SKILL.md`
   so a future `templates/skills/copilot/curlew/SKILL.md` does not collide.

3. **`{{curlew_version}}` substitution is plain string replacement, not
   `text/template`.** The placeholder body has no other tokens; `text/template`
   would force us to escape `{{` in legitimate Markdown Curlew examples that
   M10-002 will add (e.g., `{{base_url}}`). Plain `strings.ReplaceAll` is
   sufficient and removes a dependency surface.

4. **`scaffold.Options` gains two fields, not three.** `SkillName string` and
   `CurlewVersion string`. We do **not** add a separate `EnableEvents bool`
   because `SkillName != ""` is the sole trigger for events stream + .gitignore
   extension at this slice. Keeping the surface narrow now leaves room for an
   explicit `EnableEvents` later if a use case appears that decouples it from a
   skill choice.

5. **Default-format coupling is internal to the scaffold package**, not the CLI.
   When `SkillName == "claude"` and `OutputFormat == ""`, the scaffold treats
   format as `markdown` *for the purpose of emitting the `output:` block*. CLI
   validation (M9-005) is unchanged: the CLI passes `OutputFormat` through
   verbatim. This keeps the `--output unknown` error path (exit 3 with the
   format enum in stderr) intact and untouched.

6. **`ensureGitignore` refactor preserves byte-equality for the bare-init path.**
   The new signature accepts `[]string` of entries. Callers passing the single
   `[]string{".env"}` produce identical bytes to the M9-005 single-entry path.
   The order of appended entries (when both `.env` and `.curlew/` are written)
   is `.env` then `.curlew/` — matches the order users see in `init --help`
   and in the SKILL.md spec.

7. **Pre-existing files are never overwritten.** `installSkill` skips writing
   `.claude/skills/curlew/SKILL.md` if the file already exists, returning a
   sentinel `ErrSkillExists` so re-invoking `init --skill claude` is a no-op
   on the skill file (consistent with the existing `ErrProjectExists` rule for
   `curlew.yaml`). The behavior aligns with the observable that `init` should
   never destroy user work.

8. **Pre-existing `responses/` directory is untouched** because `init` does
   *not* create `responses/`. The directory is created on first run of the
   markdown formatter (M9-002+). This satisfies the "responses preserved"
   observable trivially: we have no code path that touches `responses/`.

9. **The placeholder body is intentionally uncomfortable.** Per task scope:
   "a stranded user (only M10-001 merged, M10-002 stalled) should immediately
   see the warning." The placeholder body contains a one-line H1 plus a
   "Content populated by M10-002" notice and a comment block linking the
   relevant tasks. The version comment is the only stable substring across
   M10-001 and M10-002 (asserted by the observable).

10. **Schema fixture is added under `internal/schema/testdata/`** following the
    existing naming `output_collection_skill_claude.yaml` (per task spec). The
    fixture mirrors the actual scaffolded `curlew.yaml` byte-for-byte for the
    `--skill claude` (no explicit `--output`) variant. The existing
    `TestSchema_scaffolded_all_output_formats_validate` is extended with one
    new sub-test driving `scaffold.Init(Options{Dir: tmp, SkillName: "claude",
    CurlewVersion: "test"})`.

```go
// Package templates embeds default skill files that scaffold.Init can copy
// into a user project. Mirror of schemas/schemas.go (M8-001): files in
// templates/skills/<name>/... are the source of truth; this package exposes
// a thin Render helper that performs the {{curlew_version}} substitution.
package templates

import (
	"embed"
	"errors"
	"fmt"
	"strings"
)

//go:embed skills/claude/curlew/SKILL.md
var claudeSkillFS embed.FS

// ErrUnknownSkill is returned by Render when the named skill has no embedded
// template. Sentinel so the CLI layer can branch on it cleanly.
var ErrUnknownSkill = errors.New("unknown skill")

// SupportedSkills lists the skill enum accepted by Render and by the CLI
// layer's --skill flag. v1 ships with "claude" only; the slice is the
// extension point for copilot/cursor in later slices.
var SupportedSkills = []string{"claude"}

// SkillRelativePath returns the in-project path where a skill's SKILL.md
// should land (e.g. ".claude/skills/curlew/SKILL.md"). Currently identical
// for every skill name; kept as a function so the path can vary by skill if
// a future agent platform expects a different layout.
func SkillRelativePath(skillName string) string {
	return ".claude/skills/curlew/SKILL.md"
}

// Render returns the SKILL.md content for the named skill with
// {{curlew_version}} replaced by version. Returns ErrUnknownSkill for any
// skillName outside SupportedSkills.
func Render(skillName, version string) (string, error) {
	switch skillName {
	case "claude":
		raw, err := claudeSkillFS.ReadFile("skills/claude/curlew/SKILL.md")
		if err != nil {
			return "", fmt.Errorf("reading embedded claude SKILL.md: %w", err)
		}
		return strings.ReplaceAll(string(raw), "{{curlew_version}}", version), nil
	default:
		return "", fmt.Errorf("%w %q (supported: %s)", ErrUnknownSkill, skillName, strings.Join(SupportedSkills, ", "))
	}
}

// IsSupportedSkill reports whether s is one of the known skill names.
func IsSupportedSkill(s string) bool {
	for _, k := range SupportedSkills {
		if s == k {
			return true
		}
	}
	return false
}
```

```go
// ensureGitignore creates .gitignore with a .env entry, or appends it if the
// file already exists but doesn't contain .env.
func ensureGitignore(path string) error {
	existing, err := os.ReadFile(path)
	if err != nil && !errors.Is(err, os.ErrNotExist) {
		return fmt.Errorf("reading .gitignore: %w", err)
	}

	if err == nil {
		// File exists — check each line for an exact .env entry
		for _, line := range strings.Split(string(existing), "\n") {
			if strings.TrimSpace(line) == ".env" {
				return nil
			}
		}
		// Append .env on its own line
		content := string(existing)
		if !strings.HasSuffix(content, "\n") {
			content += "\n"
		}
		if err := os.WriteFile(path, []byte(content+".env\n"), 0o644); err != nil { //nolint:gosec
			return fmt.Errorf("appending to .gitignore: %w", err)
		}
		return nil
	}

	return writeFile(path, ".env\n")
}
```

#### New Code

```go
// ensureGitignore creates .gitignore with the given entries (one per line),
// or appends any missing entries if the file already exists. The order of
// entries in the appended block matches the order in the entries slice.
// Existing entries (already present on their own line, trimmed) are skipped
// — entries are matched exactly, not as substrings, so ".env" never matches
// ".env.example" or similar.
func ensureGitignore(path string, entries []string) error {
	existing, err := os.ReadFile(path)
	if err != nil && !errors.Is(err, os.ErrNotExist) {
		return fmt.Errorf("reading .gitignore: %w", err)
	}

	have := make(map[string]bool)
	if err == nil {
		for _, line := range strings.Split(string(existing), "\n") {
			have[strings.TrimSpace(line)] = true
		}
	}

	var missing []string
	for _, e := range entries {
		if !have[e] {
			missing = append(missing, e)
		}
	}
	if len(missing) == 0 && err == nil {
		return nil
	}

	var content string
	if err == nil {
		content = string(existing)
		if !strings.HasSuffix(content, "\n") {
			content += "\n"
		}
	}
	for _, e := range missing {
		content += e + "\n"
	}
	if err := os.WriteFile(path, []byte(content), 0o644); err != nil { //nolint:gosec
		if errors.Is(err, os.ErrNotExist) {
			return fmt.Errorf("writing .gitignore: %w", err)
		}
		return fmt.Errorf("appending to .gitignore: %w", err)
	}
	return nil
}
```

#### New `Init` Flow (key changes only)

```go
func Init(opts Options) error {
	dir := opts.Dir
	if dir == "" {
		dir = "."
	}
	// ... existing existence and project-name resolution unchanged ...

	// Determine the format that drives the output: block.
	formatForBlock := opts.OutputFormat
	enableEvents := false
	if opts.SkillName == "claude" {
		enableEvents = true
		if formatForBlock == "" {
			formatForBlock = "markdown"
		}
	}

	gitignoreEntries := []string{".env"}
	if opts.SkillName != "" {
		gitignoreEntries = append(gitignoreEntries, ".curlew/")
	}

	// ... existing MkdirAll for environments + collections unchanged ...

	if err := writeFile(filepath.Join(dir, "curlew.yaml"), curlewYAML(projectName, formatForBlock, enableEvents)); err != nil {
		return err
	}
	if err := ensureGitignore(filepath.Join(dir, ".gitignore"), gitignoreEntries); err != nil {
		return err
	}
	if err := writeFile(filepath.Join(dir, ".env.example"), envExample()); err != nil {
		return err
	}
	if err := writeFile(filepath.Join(dir, "environments", "dev.yaml"), devEnvironment()); err != nil {
		return err
	}
	if err := writeFile(filepath.Join(dir, "collections", "sample.yaml"), sampleCollection()); err != nil {
		return err
	}

	if opts.SkillName != "" {
		if err := installSkill(dir, opts.SkillName, opts.CurlewVersion); err != nil {
			return err
		}
	}

	return nil
}

// installSkill renders the named skill template and writes it to the
// canonical relative path under dir. Skips writing if the destination file
// already exists (matching ErrProjectExists semantics: never overwrite user
// work). Creates parent directories as needed.
func installSkill(dir, skillName, version string) error {
	rendered, err := templates.Render(skillName, version)
	if err != nil {
		return fmt.Errorf("rendering skill %q: %w", skillName, err)
	}
	rel := templates.SkillRelativePath(skillName)
	dest := filepath.Join(dir, filepath.FromSlash(rel))
	if _, err := os.Stat(dest); err == nil {
		// Pre-existing skill file: leave it alone (consistent with
		// ErrProjectExists behaviour for curlew.yaml).
		return nil
	}
	if err := os.MkdirAll(filepath.Dir(dest), 0o750); err != nil {
		return fmt.Errorf("creating skill directory: %w", err)
	}
	if err := os.WriteFile(dest, []byte(rendered), 0o644); err != nil { //nolint:gosec
		return fmt.Errorf("writing skill file: %w", err)
	}
	return nil
}
```

#### New `outputBlock` and `curlewYAML`

```go
func curlewYAML(projectName, outputFormat string, enableEvents bool) string {
	return fmt.Sprintf("project_name: %q\n"+
		"variables:\n"+
		"  base_url: \"https://httpbin.org\"\n"+
		"%s", projectName, outputBlock(outputFormat, enableEvents))
}

func outputBlock(format string, enableEvents bool) string {
	var base string
	switch format {
	case "", "terminal":
		base = "output:\n  format: terminal\n  verbosity: normal\n"
	case "json":
		base = "output:\n  format: json\n  report: results.json\n  verbosity: normal\n"
	case "tap":
		base = "output:\n  format: tap\n  verbosity: normal\n"
	case "junit":
		base = "output:\n  format: junit\n  report: results.xml\n  verbosity: normal\n"
	case "html":
		base = "output:\n  format: html\n  report: report.html\n  verbosity: normal\n"
	case "markdown":
		base = "output:\n  format: markdown\n  report: responses/\n  verbosity: normal\n"
	default:
		base = "output:\n  format: terminal\n  verbosity: normal\n"
	}
	if !enableEvents {
		return base
	}
	// Splice the events: line in before the verbosity: line so the output
	// keeps the existing field order: format, report?, events, verbosity.
	const verbosityLine = "  verbosity: normal\n"
	const eventsLine = "  events: .curlew/run.ndjson\n"
	if i := strings.Index(base, verbosityLine); i >= 0 {
		return base[:i] + eventsLine + base[i:]
	}
	// Defensive: if verbosity is missing, append events at the end.
	return base + eventsLine
}
```

```go
func initCmdOut(args []string, stdout, stderr io.Writer) int {
	dir := "."
	projectNameFlag := ""
	outputFormat := ""
	skillName := ""
	var positional []string
	for i := 0; i < len(args); i++ {
		switch args[i] {
		case "--help", "-h":
			printInitHelpTo(stdout)
			return 0
		case "--project-name":
			i++
			if i >= len(args) {
				_, _ = fmt.Fprintln(stderr, "Error: --project-name requires a value")
				return 1
			}
			projectNameFlag = args[i]
		case "--output":
			i++
			if i >= len(args) {
				_, _ = fmt.Fprintln(stderr, "Error: --output requires a value")
				return 1
			}
			outputFormat = args[i]
		case "--skill":
			i++
			if i >= len(args) {
				_, _ = fmt.Fprintln(stderr, "Error: --skill requires a value")
				return 1
			}
			skillName = args[i]
		default:
			positional = append(positional, args[i])
		}
	}
	if len(positional) > 0 {
		dir = positional[0]
	}

	if outputFormat != "" && !output.IsSupportedFormat(outputFormat) {
		_, _ = fmt.Fprintf(stderr, "Error: unknown --output value %q (supported: %s)\n",
			outputFormat, output.FormatList())
		return 3
	}
	if skillName != "" && !templates.IsSupportedSkill(skillName) {
		_, _ = fmt.Fprintf(stderr, "Error: unknown --skill value %q (supported: %s)\n",
			skillName, strings.Join(templates.SupportedSkills, ", "))
		return 3
	}

	absDir, err := filepath.Abs(dir)
	if err != nil {
		_, _ = fmt.Fprintf(stderr, "Error: %v\n", err)
		return 1
	}
	projectName := projectNameFlag
	if projectName == "" {
		projectName = filepath.Base(absDir)
	}

	if err := scaffold.Init(scaffold.Options{
		Dir:            dir,
		ProjectName:    projectName,
		OutputFormat:   outputFormat,
		SkillName:      skillName,
		CurlewVersion: version,
	}); err != nil {
		_, _ = fmt.Fprintf(stderr, "Error: %v\n", err)
		return 1
	}

	_, _ = fmt.Fprintln(stdout, "Project initialized successfully!")
	_, _ = fmt.Fprintln(stdout)
	_, _ = fmt.Fprintln(stdout, "Created:")
	_, _ = fmt.Fprintln(stdout, "  curlew.yaml")
	_, _ = fmt.Fprintln(stdout, "  .gitignore")
	_, _ = fmt.Fprintln(stdout, "  .env.example")
	_, _ = fmt.Fprintln(stdout, "  environments/dev.yaml")
	_, _ = fmt.Fprintln(stdout, "  collections/sample.yaml")

		_, _ = fmt.Fprintf(stdout, "  %s\n", templates.SkillRelativePath(skillName))
	}
	_, _ = fmt.Fprintln(stdout)
	_, _ = fmt.Fprintln(stdout, "Next steps:")
	_, _ = fmt.Fprintln(stdout, "  curlew run collections/sample.yaml")
	return 0
}
```

## Risks and Edge Cases

- **Risk: Embed path uses backslashes on Windows.** `//go:embed
  skills/claude/curlew/SKILL.md` requires forward slashes (Go embed spec).
  No mitigation needed beyond using forward slashes consistently in the
  embed directive — Go normalises at runtime.
  **Mitigation:** keep `embed.FS.ReadFile` calls keyed by forward slashes and
  use `filepath.FromSlash` only at the destination side (already done in
  `installSkill`).

- **Risk: `outputBlock` regression for callers that don't know about events.**
  `TestOutputBlock_DefaultFallback` is the only direct external caller in
  tests. `curlewYAML` is the only in-package caller, updated in lockstep.
  **Mitigation:** the new signature accepts `enableEvents bool`; the
  `false` value is byte-for-byte identical to the pre-change function. The
  test update is mechanical.

- **Edge case: `--skill claude --output unknown` ordering.** The CLI
  validates `--output` before `--skill`. `--output unknown` exits 3 with the
  unknown-format message even when `--skill claude` is also passed. This
  matches the M9-005 contract (output validation is independent of any
  skill choice).
  **Handling:** preserve the existing `--output` validation block; add the
  `--skill` validation immediately after it. Order is documented in `--help`.

- **Edge case: `--skill ""` (empty value).** The flag *requires* a value; if
  the user types `curlew init --skill` with no token, the parser exits 1
  with `Error: --skill requires a value`. An empty positional after the
  flag (e.g. `--skill ""`) routes through `IsSupportedSkill` which returns
  `false`, so the user gets exit 3 with the unknown-skill message. This
  matches `--output ""` behaviour.
  **Handling:** parse logic in Step 4 already handles both cases via the
  existing `i++; if i >= len(args)` pattern and the `IsSupportedSkill`
  guard.

- **Edge case: `--skill claude` invoked twice (re-init).** The first run
  succeeds (skill file written). The second run fails with `ErrProjectExists`
  because `curlew.yaml` already exists. The skill file is not touched.
  **Handling:** existing `ErrProjectExists` short-circuit in `Init` runs
  before `installSkill`. Unchanged.

- **Edge case: pre-existing user-edited `.claude/skills/curlew/SKILL.md`.**
  `installSkill` skips the write when the destination exists. The test
  `TestInit_SkillClaude_PreservesExistingSkillFile` asserts this. The user
  scenario is "user-edited the skill, deleted curlew.yaml to re-init" —
  rare but possible.
  **Handling:** explicit `os.Stat` skip in `installSkill`; documented in
  the function comment.

- **Edge case: `responses/` directory created before `init`.** The scaffold
  never touches `responses/`; the markdown formatter (M9-002+) creates it
  on first run of `curlew run`.
  **Handling:** `TestInit_SkillClaude_PreservesExistingResponsesDir` is
  trivially satisfied because no code path writes to that directory at
  scaffold time.

- **Risk: `--skill` flag breaks downstream argument parsing for positional
  `[dir]`.** The flag is consumed in the `for` loop before the positional
  collection, matching the `--output` pattern. Mixing `curlew init --skill
  claude /tmp/foo` and `curlew init /tmp/foo --skill claude` both yield
  the same result (the for-loop is order-independent for non-positional
  flags).
  **Mitigation:** asserted by `TestInit_SkillClaude_FullPipeline` which
  passes `dir` after `--skill claude` — the test would fail if positional
  ordering were broken.

- **Risk: golangci-lint `gosec` complains about file mode `0o644` on
  `installSkill`'s `os.WriteFile`.** Same `//nolint:gosec` annotation used
  by existing `writeFile` applies; `0o644` is the project-wide convention
  for scaffolded text files.
  **Mitigation:** add the `//nolint:gosec` comment matching the pattern in
  `scaffold.go`.
