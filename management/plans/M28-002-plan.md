## Key Decisions

**D1 — the README changes, deliberately.** The DoD requires the quickstart be
"executed against a local server" and its "output asserted against what the
README shows". Both are unsatisfiable against today's text: the output block
shows bytes the binary cannot produce (F5), and the commands hard-depend on
httpbin.org with no substitutable seam (F6). Recorded in CHANGELOG as a **fix**,
not a docs tidy-up.

**D2 — one quickstart, under `## Quickstart`.** The hero keeps the YAML (the
genuine selling point) and hands the command + output to the section that is
executed. Two competing quickstarts in one file is the drift this task removes,
and `readmeSectionBlocks` reaches `##` sections with no new machinery (the hero
sits under the H1 with no `##` heading, so it is unreachable by the existing
extractor anyway).

**D3 — redirection is by environment, never by text rewriting.** README names
`"$BASE_URL"`; the harness supplies `BASE_URL`, `NO_COLOR`, `CURLEW_CONFIG_DIR`
and `PATH` through `cmd.Env`. **No `:-` default** — under `bash -u` an unset
`BASE_URL` fails loudly rather than silently reaching a public host, which keeps
the "no non-loopback host" guard meaningful.

**D4 — CONTRIBUTING's command list is derived in both directions.**
(a) `GateModes` parses `ci-local.sh`'s `case "$MODE" in` arms — the script, not
its usage comment — and `AuditGate` fails when the gate grows a mode CONTRIBUTING
never names *or* CONTRIBUTING names a mode the gate would reject. (b)
`docs.GateTools` is stated once in Go and must appear in **both** CONTRIBUTING.md
and `ci-local.sh`. This mirrors `internal/schema/parity_test.go`, which likewise
derives both sides from the artefacts. Chosen over "just tell readers to run the
script" because the task's behaviour explicitly names four commands.

**D5 — mudflat in-process.** Faster, no build step, no PID management,
parallel-safe via `127.0.0.1:0`, and §13.1 constrains only the reverse import
direction (F4).

```go
func TestReadme_quickstart_actually_works(t *testing.T) {
	repoRoot := readmeRepoRoot(t)
	doc := readmeReadFileOrFatal(t, filepath.Join(repoRoot, readmeFile))

	qs, err := quickstartExtract(doc)
	if err != nil {
		t.Fatalf("extract quickstart: %v", err)
	}
	// Floors, independent of the sentinels above: a truncated block must fail
	// here rather than be executed and "matched" against a truncated
	// expectation. Measured on this tree: 3 command lines, 14 non-blank
	// expected-output lines.
	if len(qs.commands) < 3 {
		t.Fatalf("found %d quickstart command(s); measured 3 on this tree", len(qs.commands))
	}
	// The harness supplies environment and never rewrites text (D3), so a
	// README that hardcodes a URL would silently stop being redirectable.
	if !strings.Contains(qs.script, "$BASE_URL") {
		t.Fatal("the quickstart block names no $BASE_URL -- the harness can no longer redirect it at a local server")
	}
	for _, host := range []string{"httpbin.org", "example.com", "https://"} {
		if strings.Contains(qs.script, host) { /* t.Fatalf: must not reach the public internet */ }
	}

	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Minute)
	defer cancel()

	base := quickstartServer(ctx, t)
	binary := buildBinary(t) // existing helper

	dir := t.TempDir()
	script := filepath.Join(dir, "quickstart.sh")
	if err := os.WriteFile(script, []byte(qs.script), 0o600); err != nil { /* fatal */ }

	cmd := exec.CommandContext(ctx, "bash", "-euo", "pipefail", script)
	cmd.Dir = dir
	cmd.Env = append(os.Environ(),
		"BASE_URL="+base,
		"NO_COLOR=1",
		"CURLEW_CONFIG_DIR="+t.TempDir(),
		"PATH="+filepath.Dir(binary)+string(os.PathListSeparator)+os.Getenv("PATH"),
	)
	out, err := cmd.CombinedOutput()
	if err != nil { /* t.Fatalf with block + output */ }

	got := quickstartNormalizeDurations(strings.TrimSpace(string(out)))
	want := quickstartNormalizeDurations(strings.TrimSpace(qs.want))
	if got != want { /* t.Errorf with a line-by-line diff */ }
}
```

## Risks and Edge Cases

- **Risk:** a quickstart command that cannot run in a test (`curlew ui` blocks;
  `go install`/`brew` need network) → **Mitigation:** the block holds only
  terminating, hermetic commands; `ui` and the glob move to prose. The test
  **errors** on any fence language other than `bash`/`sh` rather than skipping it
  (the `readme_install_exec_test.go:79-82` precedent).
- **Risk:** nondeterministic output → **Mitigation:** `quickstartNormalizeDurations`
  maps `\d+ms` → `<ms>` on both sides. Measured: nothing else varies in this path
  — no UUIDs, no dates, no host names. Colour is off (piped, plus `NO_COLOR=1`).
- **Risk:** machine state leaking into output → **Mitigation:** `CURLEW_CONFIG_DIR`
  is a fresh `t.TempDir()` (the `smoke/run.sh:11-12` precedent), which also keeps
  telemetry from adding lines.
- **Risk:** `curlew` not on PATH inside the script → **Mitigation:** `buildBinary(t)`
  returns a temp-dir binary; the harness prepends its directory to `PATH` via
  `cmd.Env`.
- **Risk:** port conflicts under `t.Parallel()` or concurrent gates →
  **Mitigation:** `net.Listen("tcp", "127.0.0.1:0")`. Never the fixed 8080/18080
  the manual and dogfood gate use.
- **Risk:** the test hangs → **Mitigation:** `exec.CommandContext` with a 5-minute
  `context.WithTimeout`, mirroring `readme_install_exec_test.go:73`.
- **Risk:** the harness silently redirecting nothing, so the block reaches the
  public internet → **Mitigation:** two guards — the extracted script must contain
  `$BASE_URL`, and no extracted command line may contain a non-loopback host.
- **Risk:** a vacuous "output matches" → **Mitigation:** full equality on
  normalised stdout, plus floors (≥3 command lines, ≥14 non-blank expected-output
  lines, and the expected block must contain `passed`).
- **Risk:** test cost paid three times (`go test`, `-race`, `-cover`) →
  **Mitigation:** measured — the mudflat probe answered in 0.00s and the whole
  probe test took 0.407s including build. Cost is dominated by `buildBinary`
  (~1-2s warm). Well under the tagged tests this gate already pays for.
- **Risk:** `errcheck` on `srv.Serve(ln)` in a goroutine → **Mitigation:**
  `go func() { _ = srv.Serve(ln) }()`; `Serve` already swallows
  `http.ErrServerClosed` (`server.go:182-184`).
- **Risk:** mudflat drifting (e.g. `/anything` renamed) → **Mitigation:** covered
  by `TestParity_EveryEndpointIsExercised`, which would fail first; and a 404 here
  still shows up attributably as a failed status assertion in the diffed output.
- **Edge case:** Windows portability → **Handling:** the test needs `bash`, as does
  every existing README/release test and `ci-local.sh` itself. `filepath.Dir` and
  `os.PathListSeparator` are used for PATH construction so the code is at least
  not gratuitously POSIX.
- **Edge case:** `curlew init`'s own "Next steps:" line does not mention `--var`
  → **Handling:** a cosmetic inconsistency in the binary's output, reproduced
  faithfully in the expected block. Out of scope here; an M28-003-shaped follow-up.
