# Implementation Plan: M18-001

## Overview

Lift the existing `?format=csv` audit-log endpoint into a true bulk-export endpoint per spec v4-1: JSONL added alongside CSV, `Transfer-Encoding: chunked` row-at-a-time streaming, the `MaxLimit=200` cap removed for `format ∈ {csv, jsonl}` callers, and an Enterprise tier gate via a new `AuditLogExportTierGate` that reuses the M16 `ITierGate` foundation. The existing paginated JSON path is preserved unchanged (cap intact) as a regression guard.

## Key Architectural Decisions

1. **Sync streaming, not async job.** Per v4-1: "No async-job model in v1 — sync streaming covers ~1M rows comfortably." Implements a row-at-a-time `IAsyncEnumerable<OrganizationAuditLogEntry>` projection fed into `HttpResponse.BodyWriter`. `Transfer-Encoding: chunked` is set implicitly by ASP.NET when `Content-Length` is not pre-known and we write to the body progressively.
2. **Reuse `ITierGate` canonical seam.** Mirrors `DashboardTierGate` / `ScheduleExecutorTierGate` shape: per-feature static adapter wrapping `gate.EnsureAsync(orgId, Enterprise, ct)`. No EF tier query duplicated.
3. **Three-call decision sequence at endpoint entry.** Order matters and is encoded by spec/RBAC layering:
   1. Auth (already enforced by `RequireAuthorization()` middleware + `CurrentUserAccessor`)
   2. Filter validation (`user_id` GUID-parse — same as current code) — pure parse error, no DB
   3. Tier gate (only when `format ∈ {csv, jsonl}`) — this slice's new gate, **before** the existing Owner/Admin RBAC + DB enumeration, so that a Team-tier admin gets 402 (correct) rather than 200 with a payment-required upgrade prompt-by-data
   4. Owner/Admin RBAC + filter execution (existing `AuditLogQueryService` path; for exports, dispatches to the streaming overload)
4. **Preserve paginated JSON path unchanged.** When `format` is null, `"json"`, or any unrecognised value, the endpoint returns the existing `ListAuditLogResponse` with `MaxLimit=200` clamp. Tier gate is **not** consulted on this path — Team/Free orgs continue to see paginated JSON. Regression guard is behaviour #4 in the YAML.
5. **JSONL property names match the JSON paginated response.** Same `AuditLogEntryDto`, same `System.Text.Json` serialiser configuration. JSONL is `WriteAsync(JsonSerializer.SerializeToUtf8Bytes(dto)) + '\n'` per row — no shape drift.
6. **CSV streaming reuses `AuditLogCsvFormatter` logic by row.** Rather than refactoring the formatter, the streamer writes the header row literally then calls a per-row formatter helper (refactored out of the existing `Format([])` method). RFC-4180 quoting + formula-injection prefixing is preserved verbatim. The existing `AuditLogCsvFormatter.Format(IReadOnlyList<...>)` API stays in place because the web layer client-side CSV path doesn't use it (the web layer formats CSV itself in TS) — but server-side ad-hoc callers and the existing `AuditLogCsvFormatterTests` suite must keep passing.
7. **Content-Disposition timestamp.** Filename format per the YAML observable: `audit-log-{orgId}-{yyyyMMddTHHmmss}.{ext}` — note the second-precision `T`-separated timestamp from the existing `:yyyyMMdd` (date-only) format. Behaviour #7 in the YAML mandates this finer-grained timestamp; updating the existing CSV-path filename is acceptable since (a) it carries no API contract, and (b) the existing test only checks for `attachment` disposition type, not the filename. The web client-side CSV path is unaffected.
8. **Cancellation propagation.** `HttpContext.RequestAborted` (already exposed as the ASP.NET-injected `CancellationToken`) is passed straight into `AsAsyncEnumerable().WithCancellation(ct)`. EF Core's async enumerator disposes its database connection on cancellation. Behaviour #5 verified by a unit test that cancels the token mid-stream and asserts the enumerator was disposed.
9. **OpenAPI surface.** `format=jsonl` is already accepted as a query string; the Swagger surface test already passes because the parameter `format` is declared. We add a `Produces("text/csv", "application/x-ndjson", "application/json")` annotation and document `format` enum values (`csv`, `jsonl`, `json`) in a doc comment. No new Swagger schema needed for the streamed body.
10. **Interim Owner/Admin check kept.** The scope explicitly defers `audit_log.export` RBAC permission to M18-002. This slice keeps the existing `AuditLogQueryService.cs:24` Owner/Admin check at endpoint entry for the export path (factored to avoid running the full query first) — a member gets 403 before the gate even runs the streaming write.

```csharp
namespace ApiTool.Backend.Internal.TierGates;

using ApiTool.Backend.Data.Entities;
using System.Diagnostics;

/// <summary>
/// Per-feature adapter for audit-log bulk-export endpoints. Requires Enterprise tier (v4.4 decision v4-1).
/// Spec: docs/SPECIFICATION.md "Audit Log Export &amp; Retention" → Bulk Export Endpoint.
/// </summary>
public static class AuditLogExportTierGate
{
    /// <summary>The minimum subscription tier required to bulk-export audit-log entries.</summary>
    public const SubscriptionTier RequiredMinimum = SubscriptionTier.Enterprise;

    /// <summary>
    /// Delegates to <see cref="ITierGate.EnsureAsync"/> with <see cref="RequiredMinimum"/>
    /// and maps the result to <see cref="AuditLogExportError"/>.
    /// </summary>
    public static async Task<AuditLogExportError> EnsureEnterpriseAsync(
        ITierGate gate, Guid orgId, CancellationToken ct) =>
        await gate.EnsureAsync(orgId, RequiredMinimum, ct) switch
        {
            TierGateResult.Allowed        => AuditLogExportError.None,
            TierGateResult.OrgNotFound    => AuditLogExportError.OrgNotFound,
            TierGateResult.TierIneligible => AuditLogExportError.TierIneligible,
            _ => throw new UnreachableException(),
        };
}
```

```csharp
/// <summary>
/// Verifies the caller has Owner/Admin role on the org. Returns
/// <see cref="AuditLogError.PermissionDenied"/> if not. Used by the
/// bulk-export endpoint to fail fast before opening the stream.
/// </summary>
/// <remarks>
/// Interim: this enforces the same hardcoded Owner/Admin gate as
/// <see cref="QueryAsync"/>. M18-002 will replace both call sites
/// with the `audit_log.view` / `audit_log.export` RBAC permissions.
/// </remarks>
public async Task<AuditLogError> EnsureExporterAuthorisedAsync(
    Guid userId, Guid orgId, CancellationToken ct)
{
    var member = await db.OrganizationMembers
        .FirstOrDefaultAsync(m => m.OrgId == orgId && m.UserId == userId, ct);
    if (member is null || member.Role == OrgRole.Member)
        return AuditLogError.PermissionDenied;
    return AuditLogError.None;
}

/// <summary>
/// Streams all rows matching <paramref name="filter"/> for an org, newest-first,
/// without applying the <c>MaxLimit=200</c> cap that <see cref="QueryAsync"/>
/// enforces. Caller is responsible for tier-gating and RBAC; this method
/// performs no auth checks (RBAC is deliberately decoupled so the endpoint
/// can fail fast before opening the response stream).
/// </summary>
public IAsyncEnumerable<AuditLogEntryDto> StreamForExportAsync(
    Guid orgId, AuditLogFilter filter, CancellationToken ct)
{
    var q = BuildFilteredQuery(orgId, filter)
        .OrderByDescending(e => e.CreatedAt)
        .Select(e => new AuditLogEntryDto(
            EventType: e.EventType,
            UserId: e.ActorId == Guid.Empty ? null : e.ActorId.ToString("N"),
            UserEmail: e.ActorEmail,
            TargetType: e.TargetType,
            TargetId: e.TargetId.HasValue ? e.TargetId.Value.ToString("N") : null,
            CreatedAt: e.CreatedAt,
            IpAddress: e.IpAddress,
            Success: e.Success,
            FailureReason: e.FailureReason));
    return q.AsAsyncEnumerable().WithCancellation(ct);
}

private IQueryable<OrganizationAuditLogEntry> BuildFilteredQuery(
    Guid orgId, AuditLogFilter filter)
{
    var q = db.OrganizationAuditLog.Where(e => e.OrgId == orgId);
    if (filter.EventType is not null)
        q = q.Where(e => e.EventType == filter.EventType);
    if (filter.UserId.HasValue)
        q = q.Where(e => e.ActorId == filter.UserId.Value);
    if (filter.From.HasValue)
        q = q.Where(e => e.CreatedAt >= filter.From.Value);
    if (filter.To.HasValue)
        q = q.Where(e => e.CreatedAt <= filter.To.Value);
    return q;
}
```

```csharp
// AuditLogExportStreamer.cs
namespace ApiTool.Backend.Audit;

using System.Text;
using System.Text.Json;
using Microsoft.AspNetCore.Http;

/// <summary>
/// Streams audit-log entries to <see cref="HttpResponse.BodyWriter"/> as either
/// newline-delimited JSON (JSONL) or RFC-4180 CSV. Used by the bulk-export path
/// of <see cref="AuditLogEndpoints"/>; never returns an <see cref="IResult"/>
/// because the caller has already taken ownership of the response.
/// </summary>
public static class AuditLogExportStreamer
{
    private const int FlushEveryRows = 100;
    private static readonly byte[] Newline = "\n"u8.ToArray();

    /// <summary>Writes a JSONL stream — one JSON object per line — for the given org.</summary>
    public static async Task WriteJsonlAsync(
        HttpResponse response,
        string orgId,
        IAsyncEnumerable<AuditLogEntryDto> rows,
        DateTime utcNow,
        CancellationToken ct)
    {
        ConfigureResponseHeaders(response, orgId, "jsonl", "application/x-ndjson", utcNow);
        var rowCount = 0;
        await foreach (var dto in rows.WithCancellation(ct))
        {
            ct.ThrowIfCancellationRequested();
            var bytes = JsonSerializer.SerializeToUtf8Bytes(dto, JsonOptions);
            await response.BodyWriter.WriteAsync(bytes, ct);
            await response.BodyWriter.WriteAsync(Newline, ct);
            if (++rowCount % FlushEveryRows == 0)
                await response.BodyWriter.FlushAsync(ct);
        }
        await response.BodyWriter.FlushAsync(ct);
    }

    /// <summary>Writes a CSV stream with a header row and one data row per entry.</summary>
    public static async Task WriteCsvAsync(
        HttpResponse response,
        string orgId,
        IAsyncEnumerable<AuditLogEntryDto> rows,
        DateTime utcNow,
        CancellationToken ct)
    {
        ConfigureResponseHeaders(response, orgId, "csv", "text/csv", utcNow);
        await response.BodyWriter.WriteAsync(
            Encoding.UTF8.GetBytes(AuditLogCsvFormatter.HeaderRow + "\n"), ct);
        var rowCount = 0;
        await foreach (var dto in rows.WithCancellation(ct))
        {
            ct.ThrowIfCancellationRequested();
            var line = AuditLogCsvFormatter.FormatRow(dto) + "\n";
            await response.BodyWriter.WriteAsync(Encoding.UTF8.GetBytes(line), ct);
            if (++rowCount % FlushEveryRows == 0)
                await response.BodyWriter.FlushAsync(ct);
        }
        await response.BodyWriter.FlushAsync(ct);
    }

    private static void ConfigureResponseHeaders(
        HttpResponse response, string orgId, string ext, string contentType, DateTime utcNow)
    {
        response.StatusCode = StatusCodes.Status200OK;
        response.ContentType = contentType;
        response.Headers.ContentDisposition =
            $"attachment; filename=\"audit-log-{orgId}-{utcNow:yyyyMMddTHHmmss}.{ext}\"";
        // Hint proxies (nginx) not to buffer — preserves chunked semantics end-to-end.
        response.Headers["X-Accel-Buffering"] = "no";
        // Do NOT set Content-Length: omitting it triggers Transfer-Encoding: chunked under Kestrel.
    }

    private static readonly JsonSerializerOptions JsonOptions = new()
    {
        PropertyNamingPolicy = JsonNamingPolicy.SnakeCaseLower,
        DefaultIgnoreCondition = System.Text.Json.Serialization.JsonIgnoreCondition.Never,
    };
}
```

```csharp
// AuditLogCsvFormatter.cs — refactor
internal const string HeaderRow =
    "created_at,event_type,user_id,user_email,target_type,target_id,success,ip_address";

internal static string FormatRow(AuditLogEntryDto e) =>
    string.Join(',', new[]
    {
        Quote(e.CreatedAt.ToString("O")),
        Quote(e.EventType),
        Quote(e.UserId ?? string.Empty),
        Quote(e.UserEmail ?? string.Empty),
        Quote(e.TargetType ?? string.Empty),
        Quote(e.TargetId ?? string.Empty),
        Quote(e.Success ? "true" : "false"),
        Quote(e.IpAddress ?? string.Empty),
    });

public static byte[] Format(IReadOnlyList<AuditLogEntryDto> entries)
{
    var sb = new StringBuilder();
    sb.AppendLine(HeaderRow);
    foreach (var e in entries)
        sb.AppendLine(FormatRow(e));
    return Encoding.UTF8.GetBytes(sb.ToString());
}
```

```csharp
private static async Task<IResult> GetAuditLog(
    string orgId,
    string? event_type,
    string? user_id,
    DateTime? from,
    DateTime? to,
    int? limit,
    string? format,
    HttpContext http,
    CurrentUserAccessor users,
    ITierGate tierGate,
    AppDbContext db,
    AuditLogQueryService svc,
    CancellationToken ct)
{
    var userId = await users.ResolveAsync(ct);
    if (userId is null) return Unauthorized401;

    if (!OrgId.TryParse(orgId, out var orgGuid))
        return HttpResults.Json(
            new ErrorResponse("permission_denied", "Organization not found."),
            statusCode: StatusCodes.Status403Forbidden);

    Guid? userIdFilter = null;
    if (user_id is not null)
    {
        if (!Guid.TryParseExact(user_id, "N", out var uid))
            return HttpResults.Json(
                new ErrorResponse("invalid_filter", "user_id must be a valid GUID in hex format (N)."),
                statusCode: StatusCodes.Status400BadRequest);
        userIdFilter = uid;
    }

    if (from.HasValue && to.HasValue && from > to)
        return HttpResults.Json(
            new ErrorResponse("invalid_filter", "from must be before to."),
            statusCode: StatusCodes.Status400BadRequest);

    var filter = new AuditLogFilter(event_type, userIdFilter, from, to, limit);
    var isExport = IsExportFormat(format, out var exportFormat);

    if (isExport)
    {
        // Owner/Admin RBAC fail-fast before opening the stream.
        // Interim — M18-002 replaces with `audit_log.export` permission.
        var rbac = await svc.EnsureExporterAuthorisedAsync(userId.Value, orgGuid, ct);
        if (rbac == AuditLogError.PermissionDenied)
            return HttpResults.Json(
                new ErrorResponse("permission_denied", "Admins and owners only."),
                statusCode: StatusCodes.Status403Forbidden);

        var gateErr = await AuditLogExportTierGate.EnsureEnterpriseAsync(tierGate, orgGuid, ct);
        if (gateErr == AuditLogExportError.OrgNotFound)
            return TierGateProblemFactory.AuthenticatedOrgNotFound(http);
        if (gateErr == AuditLogExportError.TierIneligible)
            return await TierGateProblemFactory.AuthenticatedTierIneligibleAsync(
                http, db, orgGuid, AuditLogExportTierGate.RequiredMinimum, "audit_log_export", ct);

        var rows = svc.StreamForExportAsync(orgGuid, filter, ct);
        var now = DateTime.UtcNow;
        if (exportFormat == ExportFormat.Jsonl)
            await AuditLogExportStreamer.WriteJsonlAsync(http.Response, orgId, rows, now, ct);
        else
            await AuditLogExportStreamer.WriteCsvAsync(http.Response, orgId, rows, now, ct);
        return HttpResults.Empty;  // headers + body already written
    }

    // Paginated JSON path (regression-guarded — MaxLimit=200 still applies).
    var (items, err, msg) = await svc.QueryAsync(userId.Value, orgGuid, filter, ct);
    if (err == AuditLogError.InvalidFilter)
        return HttpResults.Json(new ErrorResponse("invalid_filter", msg!),
            statusCode: StatusCodes.Status400BadRequest);
    if (err == AuditLogError.PermissionDenied)
        return HttpResults.Json(new ErrorResponse("permission_denied", msg ?? "Admins and owners only."),
            statusCode: StatusCodes.Status403Forbidden);

    return HttpResults.Ok(new ListAuditLogResponse(items));
}

private enum ExportFormat { Jsonl, Csv }

private static bool IsExportFormat(string? format, out ExportFormat parsed)
{
    if (string.Equals(format, "jsonl", StringComparison.OrdinalIgnoreCase))
    { parsed = ExportFormat.Jsonl; return true; }
    if (string.Equals(format, "csv", StringComparison.OrdinalIgnoreCase))
    { parsed = ExportFormat.Csv; return true; }
    parsed = default;
    return false;
}
```

## Risks and Edge Cases

- **Risk: Kestrel buffering masks chunked encoding in tests.** ASP.NET's `TestServer` can buffer the full response before exposing headers, making `TransferEncodingChunked` indistinguishable from a fixed-length body. **Mitigation:** assert `Content-Length` is *absent* and `Transfer-Encoding: chunked` is *present* by reading via `HttpCompletionOption.ResponseHeadersRead`; if `TestServer` consolidates anyway, fall back to asserting `response.ContentLength.Should().BeNull()` in unit tests against `DefaultHttpContext` (where Kestrel buffering is not in play), and accept that the integration test asserts the absence of `Content-Length` only.
- **Risk: `AsAsyncEnumerable()` over SQLite (test DB) may not behave the same as Postgres (prod).** SQLite returns rows in a single round-trip; Postgres streams them. **Mitigation:** test coverage for behaviour #5 (cancellation mid-stream) uses an in-memory generator (not EF) in the `AuditLogExportStreamerTests`, isolating the streaming-writer's cancellation contract from EF transport. The EF cancellation test (`StreamForExportAsync_propagates_cancellation`) verifies `OperationCanceledException` surfaces — sufficient for the behaviour.
- **Risk: `HttpResults.Empty` vs explicit `Results.Empty` semantics.** ASP.NET Minimal API treats a returned `IResult.Empty` after the response is already started as a no-op. **Mitigation:** verified via a focused integration test that the response body is non-empty after the endpoint returns (the streamer wrote it, the empty result no-ops afterward).
- **Risk: Filename quoting in `Content-Disposition`.** The header value contains a literal `"` around the filename. `RFC 6266` allows `quoted-string`; ASP.NET passes it through verbatim. **Mitigation:** integration test asserts `resp.Content.Headers.ContentDisposition.FileName` parsed value matches `"audit-log-{orgId}-{stamp}.{ext}"` with quotes.
- **Edge case: Empty result set.** Zero rows + `format=jsonl` → response is just headers + chunked-terminator (empty body). Zero rows + `format=csv` → response is `header\n` only. **Handling:** unit-test both with an empty `IAsyncEnumerable`; both should return 200 with the appropriate envelope and an "empty" body shape per format.
- **Edge case: Large row payloads.** No per-row size limit. A row with a 1MB `PayloadJson` would emit 1MB+ on one line of JSONL. **Handling:** acceptable for v1 per v4-1 ("sync streaming covers ~1M rows"); not a blocker. Documented as a future async-job-export consideration if customer rows exceed Postgres's default 1GB row limit.
- **Edge case: Client requests `?limit=10&format=jsonl`.** The `limit` parameter is silently ignored on the export path (it's a paginated-path concept). **Handling:** documented in the route's doc comment; no error returned. Filter-table tests assert `filter.Limit` is irrelevant to `StreamForExportAsync` output.
- **Edge case: `format=CSV` (upper-case).** Existing code uses `StringComparison.OrdinalIgnoreCase`; the new dispatch preserves this. Test: `Get_audit_log_format_uppercase_jsonl_dispatches_to_export` (added to the table-driven suite).
- **Edge case: Org row exists but org has zero subscription rows.** `TierGate.EnsureAsync` treats this as Free → `TierIneligible`. **Verified** by existing `TierGateTests.EnsureAsync_treats_missing_subscription_row_as_Free`. Test in this slice: an Enterprise check on a no-subscription org returns 402 (not 404). Note this differs from `OrgNotFound` semantics — the org *exists*, the subscription does not.
- **Risk: web export route at `web/src/routes/(app)/org/[slug]/audit-log/export/+server.ts` calls `auditLogApi.list(..., limit: 200)`, not `?format=csv`.** Therefore the web button is unaffected by the changes to the server-side CSV path. **Mitigation:** documented; no web changes in scope. Behaviour #8 explicitly defers the web wiring to M18-012.
- **Risk: no real-world cost.** Implementation uses in-memory SQLite for tests, no paid services touched. Manual observable verification against `docker-compose -f docker-compose.test.yml up -d` uses the local stack. Per project rule: no cloud, no live KMS, no live Stripe, no SendGrid — none required for this slice.

## Open Questions Resolved (Pipeline Mode Decisions)

Per pipeline-mode instructions, the following were resolved by best judgment rather than asked:

1. **Should the existing `Get_audit_log_csv_format_returns_text_csv_with_content_disposition` test be deleted or updated?**
   **Decision:** Update — seed Enterprise so it asserts the streamed CSV envelope. Preserves the existing safety net for the disposition header on the path that previously shipped; cheaper than churn.

2. **Order of RBAC check vs tier gate on the export path?**
   **Decision:** RBAC first, gate second. Matches the existing `Get_audit_log_for_unknown_org_returns_403` test's anti-enumeration shape (an unknown org → 403, never 404). A Team-tier *member* still gets 403 (not 402) — the more informative error for that user, since they cannot perform the action regardless of tier.

3. **Should `?format=json` explicitly opt into the paginated path, or should only "no format" do that?**
   **Decision:** Both fall through to the paginated path. Symmetric: `format` is conceptually a synonym set where `{csv, jsonl}` triggers export and everything else (null, `"json"`, `"xml"`, garbage) → paginated. No 400 for unknown `format` — the existing endpoint silently fell through, so preserving that avoids a behaviour change on the regression-guard path.

4. **Per-row flush interval (100 rows)?**
   **Decision:** 100 rows balances client-perceived latency (a 350-row export flushes 4 times) against syscall overhead. Documented as a tunable; not exposed as configuration.

5. **`X-Accel-Buffering: no` header?**
   **Decision:** Add it. Defensive against nginx/CloudFront-style proxies that would otherwise buffer the entire response and defeat the chunked contract for end users. Zero-cost defensive header.

6. **JSONL serialiser settings?**
   **Decision:** `JsonNamingPolicy.SnakeCaseLower` + `DefaultIgnoreCondition.Never`. Matches the existing paginated JSON shape (which relies on ASP.NET's default snake_case-via-`JsonOptions` on Minimal API serialisation). Verified by re-parsing each line in the integration test and asserting `event_type` exists.

7. **Filename timestamp granularity?**
   **Decision:** `yyyyMMddTHHmmss` per the YAML observable. Supersedes the existing `:yyyyMMdd` (date-only) format on the CSV path. No external contract on this filename to break.

8. **Should the new `audit_log_export` feature code in the tier-gate problem details be hyphenated or underscored?**
   **Decision:** Underscored (`audit_log_export`), matching the existing `schedule_executor` and `vault_config` codes in `TierGateProblemFactory.AuthenticatedTierIneligibleAsync` callers (e.g. `ScheduleExecutorEndpoints.cs:238`).
