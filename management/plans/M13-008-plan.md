# Implementation Plan: M13-008

## Overview

Adds the `$faker.*` file-data family — 4 functions (`$faker.fileName`, `$faker.fileExtension`, `$faker.mimeType`, `$faker.imageUrl`) — to the dynamic-variable registry. Three zero-arg functions draw from a shipped extension/MIME-type parallel pool; `$faker.imageUrl` is the family's only argument-bearing function with a 0-or-2 arity that mirrors `$faker.price` (M13-007), reusing M12-001's `parseDynArgs` unchanged.

## Architectural Decisions

1. **Parallel pool of extensions and MIME types.** Two new file-scope slices `fileExtensions` and `fileMimeTypes` ship as a 1:1 parallel pool (per task scope: "$faker.fileName composes a random base name plus a random extension drawn from the same extension pool"). The pool is *aligned* (codes/names line up by index) but the three RNG-bearing functions (`fileName`, `fileExtension`, `mimeType`) draw independently — same pattern as the M13-007 currency triple. Alignment is asserted by a new `TestFakerFile_PoolAlignment` test mirroring `TestFakerFinancial_CurrencyPoolAlignment`.

2. **Base-name composition for `$faker.fileName`.** The base name is composed from a small lowercase token pool (e.g. `document`, `report`, `invoice`, `image`, …) joined with a random extension drawn from `fileExtensions`. This guarantees the regex `^[a-z0-9_-]+\.[a-z0-9]+$` (per behavior 1) for every shipped permutation. No hyphenation/underscore decoration in the shipped pool — keeping the regex simple. (Decision: lowercase tokens only; no hyphens or digits in the shipped base-name pool. The regex in behavior 1 explicitly allows them, so the test passes today and the pool can grow later without a regex change.)

3. **`$faker.imageUrl` arity-flex shape.** Mirrors `$faker.price` exactly: switch on `len(args)`, with `case 0` returning the constant default URL `https://picsum.photos/640/480` and `case 2` doing `strconv.Atoi` + positivity-check on each arg. The default form is intentionally deterministic — its output is the constant default URL (per behavior 9), so it is **excluded** from the no-seed-entropy assertion. This is documented inline in the test code.

4. **Error code naming.** Two new structured error codes under the existing `DYNFN_FAKER_*_BAD_*` family:
   - `DYNFN_FAKER_IMAGEURL_BAD_INPUT` — non-integer arg.
   - `DYNFN_FAKER_IMAGEURL_BAD_DIMENSION` — integer ≤ 0 (mirrors `_BAD_LENGTH` semantics from `$randomBase64`).

   Both shapes mirror `$randomBase64` / `$randomPassword` per behavior 7 ("error shape"). One arg or 3+ args produce the canonical `DYNFN_ARITY` error with message "expected 0 or 2 arguments, got N" — same wording as `$faker.price`'s arity error.

5. **No `parseDynArgs` modification.** Per task scope: "Per M13 Open Decision #6, M12-001's parseDynArgs is reused without modification". `internal/variable/variable.go` is **not** edited.

6. **Manual DynFunc form for `$faker.imageUrl`.** Like `$faker.price` and `$randomBase64`, `$faker.imageUrl` is registered with the explicit `func(rng *rand.Rand, args []string) (string, error)` shape rather than `noArgs` / `oneArg` / `twoArgs`, because none of those wrappers handles 0-or-2 arity flex.

7. **Pool size.** ~10 extensions and matching MIME types (per spec example: `pdf`, `jpg`, `png`, `mp4`, `txt`, `csv`, `json`, …) — large enough for unseeded-entropy collision-resistance, small enough to keep the binary footprint negligible.

```go
    // $faker.* file-data family — M13-008 (en-US only; locale
    // deferred per M13 Open Decision #1). SPECIFICATION.md:838-845.
    // Three RNG-bearing functions are deterministic under --seed via
    // intn over the parallel fileExtensions / fileMimeTypes pool.
    // $faker.imageUrl has 0-or-2 arity that mirrors $faker.price
    // (M13-007); the no-arg form returns a constant default URL and
    // is intentionally deterministic across runs (per behavior 9).

    // $faker.fileName — base name + dotted extension, both lowercase.
    // Result matches ^[a-z0-9_-]+\.[a-z0-9]+$ per behavior 1.
    r.funcs["faker.fileName"] = noArgs("faker.fileName", func(rng *rand.Rand) string {
        base := fileBaseNames[intn(rng, len(fileBaseNames))]
        ext := fileExtensions[intn(rng, len(fileExtensions))]
        return base + "." + ext
    })

    // $faker.fileExtension — 2-to-4 char lowercase string with no
    // leading dot. Matches ^[a-z0-9]{2,4}$ per behavior 2.
    r.funcs["faker.fileExtension"] = noArgs("faker.fileExtension", func(rng *rand.Rand) string {
        return fileExtensions[intn(rng, len(fileExtensions))]
    })

    // $faker.mimeType — type/subtype matching ^[a-z]+/[a-z0-9.+-]+$
    // per behavior 3. Drawn from the parallel fileMimeTypes pool.
    r.funcs["faker.mimeType"] = noArgs("faker.mimeType", func(rng *rand.Rand) string {
        return fileMimeTypes[intn(rng, len(fileMimeTypes))]
    })

    // $faker.imageUrl — 0-or-2 arity. No-arg form returns the
    // constant default https://picsum.photos/640/480 (behavior 4).
    // Two-arg form parses positive-integer width/height via
    // strconv.Atoi and formats https://picsum.photos/<w>/<h>
    // (behavior 5). Bad input → DYNFN_FAKER_IMAGEURL_BAD_INPUT;
    // non-positive → DYNFN_FAKER_IMAGEURL_BAD_DIMENSION (behaviors
    // 6, 7). 1-arg or 3+-arg → DYNFN_ARITY ("expected 0 or 2
    // arguments"), mirroring $faker.price.
    r.funcs["faker.imageUrl"] = func(_ *rand.Rand, args []string) (string, error) {
        switch len(args) {
        case 0:
            return "https://picsum.photos/640/480", nil
        case 2:
            w, err := strconv.Atoi(args[0])
            if err != nil {
                return "", &apierrors.Structured{
                    Category: apierrors.CategoryInput,
                    Code:     "DYNFN_FAKER_IMAGEURL_BAD_INPUT",
                    Message:  fmt.Sprintf("invalid width %q: must be an integer", args[0]),
                    Hint:     "Pass two single-quoted positive-integer strings, e.g. {{$faker.imageUrl('800', '600')}}.",
                    Inner:    err,
                }
            }
            h, err := strconv.Atoi(args[1])
            if err != nil {
                return "", &apierrors.Structured{
                    Category: apierrors.CategoryInput,
                    Code:     "DYNFN_FAKER_IMAGEURL_BAD_INPUT",
                    Message:  fmt.Sprintf("invalid height %q: must be an integer", args[1]),
                    Hint:     "Pass two single-quoted positive-integer strings, e.g. {{$faker.imageUrl('800', '600')}}.",
                    Inner:    err,
                }
            }
            if w < 1 {
                return "", &apierrors.Structured{
                    Category: apierrors.CategoryInput,
                    Code:     "DYNFN_FAKER_IMAGEURL_BAD_DIMENSION",
                    Message:  fmt.Sprintf("width %d is invalid: must be a positive integer", w),
                    Hint:     "Pass positive-integer dimensions, e.g. {{$faker.imageUrl('800', '600')}}.",
                }
            }
            if h < 1 {
                return "", &apierrors.Structured{
                    Category: apierrors.CategoryInput,
                    Code:     "DYNFN_FAKER_IMAGEURL_BAD_DIMENSION",
                    Message:  fmt.Sprintf("height %d is invalid: must be a positive integer", h),
                    Hint:     "Pass positive-integer dimensions, e.g. {{$faker.imageUrl('800', '600')}}.",
                }
            }
            return fmt.Sprintf("https://picsum.photos/%d/%d", w, h), nil
        default:
            return "", &apierrors.Structured{
                Category: apierrors.CategoryInput,
                Code:     "DYNFN_ARITY",
                Message:  fmt.Sprintf("expected 0 or 2 arguments, got %d", len(args)),
                Hint:     "Call $faker.imageUrl with no arguments (default 640x480) or with two single-quoted positive integers, e.g. {{$faker.imageUrl('800', '600')}}.",
            }
        }
    }
```

## Risks and Edge Cases

- **Risk:** Pool drift — someone reorders `fileExtensions` but forgets `fileMimeTypes`. → **Mitigation:** `TestFakerFile_PoolAlignment` asserts equal length and pins three canonical pairings (idx 0, 1, 6).
- **Risk:** A future contributor adds an extension matching `^[A-Z]` or with leading dot. → **Mitigation:** `TestFakerFile_ExtensionShape` regex `^[a-z0-9]{2,4}$` — fails the build on regression.
- **Risk:** A future contributor adds a base name with whitespace, breaking `^[a-z0-9_-]+$`. → **Mitigation:** `TestFakerFile_BaseNameShape`.
- **Edge case:** `$faker.imageUrl('1','1')` (minimum valid dimensions) — covered explicitly in `TestRegistry_FakerImageUrl_Args`.
- **Edge case:** `$faker.imageUrl('1.5','480')` — `strconv.Atoi` rejects floats, producing `BAD_INPUT`. Covered in `TestRegistry_FakerImageUrl_BadInput`.
- **Edge case:** `$faker.imageUrl('','480')` — empty string, `strconv.Atoi` returns error → `BAD_INPUT`. Covered.
- **Edge case:** Per-request memoization could mask bugs in seeded reproducibility tests. → **Mitigation:** `TestRegistry_FakerImageUrl_Args` calls `s.EndRequest()` + `s.BeginRequest()` between iterations to flush the cache, mirroring `TestRegistry_FakerFinancial_PriceArgs` (dynamic_test.go:3761-62).
- **Edge case:** `noArgs` wrapper rejects `$faker.fileName('arg')`. The wrapper's `arityError` path is already covered by existing tests for other zero-arg faker functions; we don't add a redundant assertion.
- **Risk:** The default `$faker.imageUrl` URL ("https://picsum.photos/640/480") could be confused for a non-deterministic value in the unseeded-entropy assertion. → **Mitigation:** `TestRegistry_FakerFile_Unseeded` explicitly excludes `$faker.imageUrl` and `TestRegistry_FakerImageUrl_DefaultsAreDeterministic` pins the constant-output property positively.
