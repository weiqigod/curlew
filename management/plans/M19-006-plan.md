# Implementation Plan: M19-006

## Overview

## Key Architectural Decisions

1. **Flat layout, no nested subdirectories.** The 10 per-topic files all live alongside `SKILL.md` at `templates/skills/claude/apitest/`. Claude skill conventions encourage flat reference files; nesting would complicate the embedded-FS walker without benefit. The walker is still made recursive so a future topic file could be nested without re-engineering.
2. **`embed` widened to the whole directory.** Replace the single-file `//go:embed skills/claude/apitest/SKILL.md` with `//go:embed all:skills/claude/apitest` and walk it with `fs.WalkDir`. The `all:` prefix is required because Claude tooling does not produce dot-prefixed files but it makes the embed self-evidently recursive.
3. **New `templates.Walk` API.** Add `func Walk(skillName string) (iter.Seq2[string, []byte], error)` returning relative paths and rendered bytes (with `{{apitest_version}}` substitution already applied to every `.md` file). The existing `Render` helper stays as a thin wrapper that returns the root `SKILL.md` for backward compatibility with any callers that read just the entry point.
4. **`SkillRelativePath` is for the root only.** It keeps returning `.claude/skills/apitest/SKILL.md`. A new `SkillRootDir` helper returns `.claude/skills/apitest` for callers (the scaffolder, the snapshot test, the playbook test) that need to enumerate files.
5. **Snapshot test stays single-file.** `TestSkillClaude_SkillFileSnapshot` continues to snapshot just `SKILL.md` byte-for-byte. The 10 topic files are asserted structurally (presence + key strings) in new sub-tests rather than via 10 separate snapshot goldens; the operator voice is hand-curated and snapshotting every file would convert authoring iteration into a churn of "update the snapshot" commits without catching bugs the structural assertions miss.
6. **`installSkill` becomes a directory walker.** It iterates `templates.Walk("claude")`, mirrors the relative paths under `<dir>/.claude/skills/apitest/`, and applies the same skip-if-exists semantics file-by-file. A pre-existing file (whether `SKILL.md` or a topic file) is preserved verbatim; sibling files are still scaffolded.
7. **Content authoring decision.** Each topic file is rewritten in the existing `SKILL.md`'s second-person operator voice (concise, file-path-pointer style), lifting concrete examples from the corresponding `docs/MANUAL.md` sections. Per scope, this is NOT a verbatim MANUAL.md copy and explicitly does NOT touch MANUAL.md.
8. **No version comment in topic files.** Only the root `SKILL.md` carries the `<!-- apitest-skill: claude v1.0 (apitest {{apitest_version}}) -->` line. Topic files are dataless reference and do not need a version banner; this also keeps the templating substitution-free for those files (faster, less to test).

```go
//go:embed all:skills/claude/apitest
var claudeSkillFS embed.FS

// SkillRootDir returns the in-project directory where a skill's files land.
func SkillRootDir(_ string) string { return ".claude/skills/apitest" }

// Walk yields (relativePath, body) pairs for every file under the named
// skill's embedded directory. relativePath is relative to the skill root
// (e.g. "SKILL.md", "variables.md"). Bodies are returned verbatim — no
// {{apitest_version}} substitution; callers (installSkill, Render) handle
// substitution where needed.
func Walk(skillName string) (iter.Seq2[string, []byte], error) {
    base, err := embeddedBase(skillName)
    if err != nil { return nil, err }
    return func(yield func(string, []byte) bool) {
        _ = fs.WalkDir(claudeSkillFS, base, func(p string, d fs.DirEntry, err error) error {
            if err != nil || d.IsDir() { return err }
            rel, _ := strings.CutPrefix(p, base+"/")
            body, rerr := claudeSkillFS.ReadFile(p)
            if rerr != nil { return rerr }
            if !yield(rel, body) { return fs.SkipAll }
            return nil
        })
    }, nil
}

func embeddedBase(skillName string) (string, error) {
    switch skillName {
    case "claude": return "skills/claude/apitest", nil
    default: return "", fmt.Errorf("%w %q (supported: %s)", ErrUnknownSkill, skillName, strings.Join(SupportedSkills, ", "))
    }
}

// Render returns the rendered root SKILL.md content for the named skill,
// with {{apitest_version}} replaced. Backwards-compatible with pre-M19-006
// callers that consumed only the entry-point file.
func Render(skillName, version string) (string, error) {
    base, err := embeddedBase(skillName)
    if err != nil { return "", err }
    raw, err := claudeSkillFS.ReadFile(base + "/SKILL.md")
    if err != nil { return "", fmt.Errorf("reading embedded %s/SKILL.md: %w", base, err) }
    return strings.ReplaceAll(string(raw), "{{apitest_version}}", version), nil
}
```

#### New Code (sketch)

```go
func installSkill(dir, skillName, version string) error {
    seq, err := templates.Walk(skillName)
    if err != nil { return fmt.Errorf("walking skill %q: %w", skillName, err) }
    rootRel := templates.SkillRootDir(skillName) // ".claude/skills/apitest"
    for rel, body := range seq {
        dest := filepath.Join(dir, filepath.FromSlash(rootRel), filepath.FromSlash(rel))
        if _, statErr := os.Stat(dest); statErr == nil {
            continue // skip per-file: never overwrite user-edited content
        }
        if err := os.MkdirAll(filepath.Dir(dest), 0o750); err != nil {
            return fmt.Errorf("creating skill directory: %w", err)
        }
        // Substitute only in .md files (template tokens never appear elsewhere
        // and substitution on, say, a future binary asset would corrupt it).
        out := body
        if strings.HasSuffix(rel, ".md") {
            out = []byte(strings.ReplaceAll(string(body), "{{apitest_version}}", version))
        }
        if err := os.WriteFile(dest, out, 0o644); err != nil { //nolint:gosec
            return fmt.Errorf("writing skill file %s: %w", rel, err)
        }
    }
    return nil
}
```

## Risks and Edge Cases

- **Risk: `//go:embed all:skills/claude/apitest` accidentally embeds a binary or hidden file.** → **Mitigation:** keep the directory `.md`-only (already the case); add a Walk-time assertion in tests that every embedded path ends in `.md`.
- **Risk: The snapshot test churns on every voice/wording tweak to `SKILL.md`.** → **Mitigation:** accepted cost — the snapshot is the trip-wire for accidental upstream edits to the embedded template. The 10 topic files deliberately have no snapshot; they are guarded by structural assertions only.
- **Risk: Per-file skip-if-exists strands a partial user-edited skill in an out-of-date state when one new file ships but a sibling already exists.** → **Mitigation:** documented in the `## Notes` section of `SKILL.md` — `apitest init --skill claude` never overwrites; users who want the latest run it in a fresh directory and diff (matches the existing pattern in the current `SKILL.md` lines 126-129).
- **Risk: `iter.Seq2` is Go 1.23+; project uses Go 1.24.** → **Mitigation:** confirmed Go 1.24 in MEMORY.md; safe to use range-over-func.
- **Edge case: Empty directory (no files under the embed)** → **Handling:** `Walk` yields no entries; `installSkill` no-ops; this matches the pre-existing behaviour for an unknown skill (already gated by `embeddedBase`).
- **Edge case: User has manually nested a sub-directory inside `.claude/skills/apitest/`.** → **Handling:** the walker only writes files it knows about; user directories are untouched.
- **Edge case: `expressions.md` topic file might be confused with the existing `assertions.md` topic file by an agent.** → **Mitigation:** `assertions.md` ends with a "For CEL, see `expressions.md`" cross-reference; the decision table in `expressions.md` makes the operator-vs-CEL choice explicit.
