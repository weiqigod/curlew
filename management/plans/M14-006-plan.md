# Implementation Plan: M14-006

## Overview
Wire `apitest license --refresh` and `apitest license --debug` end-to-end. `--refresh` calls `/api/v1/auth/refresh` via `internal/backend.RefreshTokens`, persists the rotated trio (License JWT, access token, refresh token) using existing storage layers, and maps RFC 7807 ProblemDetails codes to the 8-code exit taxonomy from spec §:8275-8284. `--debug` decodes the cached License JWT (without re-verifying), prints jti, kid, tier, exp, grace_until, the cache file path, and the type-URL of any most-recent error for navigation.

## Architectural Decisions

These decisions resolve task ambiguities up-front, with rationale, so /execute can proceed without re-deciding mid-implementation.

1. **Refresh-failure messaging is taken from `loginExitForError` patterns** — same sentinels (`backend.ErrNetworkFailure`, `backend.ErrServerError`) trigger codes 3 and 6 with a "license refresh failed, will retry next invocation" stderr line for the network/server cases (per spec :8285).
2. **AUTH_REFRESH_* problem-code → exit-code mapping lives in cmd/apitest/license.go**, not in `internal/backend`, because the backend client is RFC 7807-agnostic and exit-code mapping is a CLI concern. Symmetry with `loginExitForError` keeps the convention. New helper `licenseRefreshExitForError(err, stderr) int` does the mapping.
3. **Sentinel errors for refresh-specific problem codes** added to `internal/backend/refresh.go` (new file): `ErrRefreshExpired`, `ErrRefreshReused`, `ErrDeviceMismatch`. They wrap incoming `*ProblemDetails` so callers can `errors.Is` them. This mirrors `pollCodeToSentinel` in `devicecode.go`. The mapping is applied inside a thin wrapper around `RefreshTokens` named `RefreshTokensWithSentinels` (keeping `RefreshTokens` itself stable for the existing `internal_cmd.go` self-test). Choice: add the mapping inline to `RefreshTokens` rather than in a new wrapper — the only existing caller (the self-test) treats unrecognised codes as `*ProblemDetails`, and `errors.Is` on a sentinel-wrapped error still satisfies an `errors.As(*ProblemDetails)` check. Verified by tracing `internal_cmd.go:146` — that path uses `/api/v1/auth/refresh-reused` (not `/api/v1/auth/refresh`) so the new mapping does not affect it.
4. **License JWT after refresh is persisted via `license.NewStore(cfgDir).Save(rec)`**, mirroring `persistLogin` in `cmd/apitest/login.go:182-194`. `LastValidatedAt` is set to `time.Now().UTC()` to refresh the grace window. `Tier` is decoded with the existing `tierFromLicenseJWT` helper.
5. **Debug output is plain JSON to stdout** — task observable requires "stdout JSON includes: jti, kid, tier, exp, grace_until, refresh_failures, lastRefreshAttemptAt". `refresh_failures` and `lastRefreshAttemptAt` reuse the existing `LicenseRecord.ValidationFailures` and `LicenseRecord.LastValidationAttempt` fields (semantically equivalent: failure counter + most recent attempt timestamp).
6. **Claims struct is extended with `Jti` and `GraceUntil` fields** in `internal/license/jwt.go`. Both are JSON-optional (`omitempty`); existing tokens without these fields parse to zero values which is fine for `--debug`. Existing `--validate` continues to work.
7. **Stub backend is extended** to handle `/api/v1/auth/refresh` and to support an `inject` subcommand via a control endpoint `POST /__inject`. The shell wrapper `stub-backend.sh` gains `inject <code>` support that POSTs to that endpoint. This honors the task observable verbatim.
8. **No-cache behavior (exit 2) for `--refresh`:** `device.Read(cfgDir)` returning `device.ErrNotFound` → exit 7 (device not registered). `storage.GetRefreshToken()` returning `backend.ErrTokenNotFound` → exit 2 (no cache; `apitest login`). The task description bundles "No cache" as exit 2, "device mismatch / no device.json" as exit 7. Order: check device.json first (exit 7), then refresh token (exit 2). Rationale: if device.json is missing we have no `device_id` to send anyway, and exit 7 directly informs the user to run `apitest login`.
9. **Exit code for malformed cached JWT during --debug**: print whatever fields can be decoded, fall back to the empty string for fields that fail to decode, exit 0 unless the cache is fully missing. Missing cache → exit 2.
10. **"License refreshed. Tier=solo. Expires in 30 days." stdout** — `solo` is illustrative in the observable; we print `Tier=<actual_tier_from_jwt>` and `Expires in <int> days` derived from the new License JWT's `exp` claim relative to `time.Now()`. If exp is missing, print "Expires unknown".

```go
package backend

import (
	"errors"
	"fmt"
)

var (
	// ErrRefreshExpired is returned when the backend's AUTH_REFRESH_EXPIRED
	// problem code surfaces. CLI exit code 4. Re-auth via `apitest login`.
	ErrRefreshExpired = errors.New("backend: refresh token expired")
	// ErrRefreshReused is returned for AUTH_REFRESH_REUSED. CLI exit code 5;
	// the entire refresh-token family has been revoked for security.
	ErrRefreshReused = errors.New("backend: refresh token reused — family revoked")
	// ErrDeviceMismatch is returned for AUTH_DEVICE_MISMATCH or when the
	// device_id sent does not match the family on the server. CLI exit code 7.
	ErrDeviceMismatch = errors.New("backend: device mismatch — re-register via apitest login")
)

// refreshCodeToSentinel maps AUTH_* problem codes returned by /auth/refresh
// to sentinel errors. Caller uses errors.Is to branch.
var refreshCodeToSentinel = map[string]error{
	"AUTH_REFRESH_EXPIRED":  ErrRefreshExpired,
	"AUTH_REFRESH_REUSED":   ErrRefreshReused,
	"AUTH_DEVICE_MISMATCH":  ErrDeviceMismatch,
}

// translateRefreshError checks whether err carries one of the AUTH_REFRESH_*
// problem codes and, if so, returns a wrapped sentinel error. The original
// *ProblemDetails is preserved via errors.As-able wrapping so the caller can
// surface ProblemDetails.Type for docs lookup.
func translateRefreshError(err error) error {
	if err == nil {
		return nil
	}
	var pd *ProblemDetails
	if !errors.As(err, &pd) {
		return err
	}
	if sentinel, ok := refreshCodeToSentinel[pd.Code]; ok {
		return fmt.Errorf("%w: %s (%s)", sentinel, pd.Title, pd.Type)
	}
	return err
}
```

```go
// SPEC §8269-8284: exit-code taxonomy is the contract for CI integration.

// licenseRefreshOut handles `apitest license --refresh`.
//
// Exit codes:
//
//	0 — success: three new tokens persisted; stdout line printed
//	1 — internal error
//	2 — no refresh token cached; run `apitest login`
//	3 — network failure; previous License JWT remains valid
//	4 — refresh token expired; re-auth required
//	5 — refresh token reused (family revoked); re-auth required
//	6 — backend 5xx; previous License JWT remains valid
//	7 — device not registered; run `apitest login`
func licenseRefreshOut(stdout, stderr io.Writer) int {
	cfgDir, err := licenseConfigDir()
	if err != nil {
		_, _ = fmt.Fprintln(stderr, err)
		return 1
	}

	// Step 1: device.json must exist.
	dev, err := device.Read(cfgDir)
	if err != nil {
		if errors.Is(err, device.ErrNotFound) {
			_, _ = fmt.Fprintln(stderr, "device not registered; run `apitest login`")
			return 7
		}
		_, _ = fmt.Fprintf(stderr, "read device.json: %v\n", err)
		return 1
	}

	// Step 2: refresh token must exist.
	storage, err := backend.NewStorage(backend.StorageOptions{
		ConfigDir: cfgDir,
		DeviceID:  dev.DeviceID,
	})
	if err != nil {
		_, _ = fmt.Fprintf(stderr, "init storage: %v\n", err)
		return 1
	}
	if _, err := storage.GetRefreshToken(); err != nil {
		if errors.Is(err, backend.ErrTokenNotFound) {
			_, _ = fmt.Fprintln(stderr, "no cached refresh token; run `apitest login`")
			return 2
		}
		_, _ = fmt.Fprintf(stderr, "read refresh token: %v\n", err)
		return 1
	}

	// Step 3: build client, call refresh.
	backendURL := os.Getenv("APITEST_BACKEND_URL")
	if backendURL == "" {
		backendURL = "https://api.apitool.dev"
	}
	client, err := backend.NewClient(backend.Options{BaseURL: backendURL})
	if err != nil {
		_, _ = fmt.Fprintln(stderr, err)
		return 1
	}

	tokens, err := backend.RefreshTokens(context.Background(), client, storage, cfgDir, dev.DeviceID)
	if err != nil {
		return licenseRefreshExitForError(err, stderr)
	}

	// Step 4: persist license.json with the new License JWT and refreshed timestamps.
	rec := &license.LicenseRecord{
		AccessToken:           tokens.LicenseJWT,
		Tier:                  tierFromLicenseJWT(tokens.LicenseJWT),
		LastValidatedAt:       time.Now().UTC(),
		LastValidationAttempt: time.Now().UTC(),
		ValidationFailures:    0,
	}
	if err := license.NewStore(cfgDir).Save(rec); err != nil {
		_, _ = fmt.Fprintf(stderr, "persist license.json: %v\n", err)
		return 1
	}

	expDays := daysUntilExpiry(tokens.LicenseJWT, time.Now())
	if expDays >= 0 {
		_, _ = fmt.Fprintf(stdout, "License refreshed. Tier=%s. Expires in %d days.\n", rec.Tier, expDays)
	} else {
		_, _ = fmt.Fprintf(stdout, "License refreshed. Tier=%s. Expires unknown.\n", rec.Tier)
	}
	return 0
}

// licenseRefreshExitForError maps refresh sentinels and ProblemDetails to
// the 8-code taxonomy. On non-fatal codes (3, 6) prints the "will retry"
// message documented in spec :8285.
func licenseRefreshExitForError(err error, stderr io.Writer) int {
	switch {
	case errors.Is(err, backend.ErrTokenNotFound):
		_, _ = fmt.Fprintln(stderr, "no cached refresh token; run `apitest login`")
		return 2
	case errors.Is(err, backend.ErrNetworkFailure):
		_, _ = fmt.Fprintln(stderr, "license refresh failed, will retry next invocation")
		return 3
	case errors.Is(err, backend.ErrRefreshExpired):
		_, _ = fmt.Fprintln(stderr, "Refresh expired; run `apitest login`")
		return 4
	case errors.Is(err, backend.ErrRefreshReused):
		_, _ = fmt.Fprintln(stderr, "Refresh token family revoked (reuse detected); run `apitest login`")
		return 5
	case errors.Is(err, backend.ErrServerError):
		_, _ = fmt.Fprintln(stderr, "license refresh failed, will retry next invocation")
		return 6
	case errors.Is(err, backend.ErrDeviceMismatch):
		_, _ = fmt.Fprintln(stderr, "device not registered; run `apitest login`")
		return 7
	default:
		// Fall back: ProblemDetails with an unrecognised code → exit 1.
		_, _ = fmt.Fprintf(stderr, "license refresh failed: %v\n", err)
		return 1
	}
}

// daysUntilExpiry decodes the JWT exp claim (without verifying) and returns
// floor((exp - now) / 24h). Returns -1 on any parse error.
func daysUntilExpiry(jwt string, now time.Time) int {
	parts := strings.SplitN(jwt, ".", 3)
	if len(parts) != 3 {
		return -1
	}
	payload, err := base64.RawURLEncoding.DecodeString(parts[1])
	if err != nil {
		return -1
	}
	var c struct {
		Exp int64 `json:"exp"`
	}
	if err := json.Unmarshal(payload, &c); err != nil || c.Exp == 0 {
		return -1
	}
	d := time.Unix(c.Exp, 0).Sub(now)
	if d < 0 {
		return 0
	}
	return int(d / (24 * time.Hour))
}
```

```go
// licenseDebugOut handles `apitest license --debug`. Decodes the cached
// License JWT (without re-verifying), prints a JSON object with diagnostic
// fields. On parse error, prints whatever fields can be decoded and exits 0.
// Missing cache → exit 2.
//
// SPEC §:8267 — surfaces the most-recent error's type-URL for one-click
// docs lookup; this is read from the licenseLastError package var, which
// the refresh and validate paths populate on failure (best-effort).
func licenseDebugOut(stdout, stderr io.Writer) int {
	cfgDir, err := licenseConfigDir()
	if err != nil {
		_, _ = fmt.Fprintln(stderr, err)
		return 1
	}

	rec, err := license.NewStore(cfgDir).Load()
	if err != nil {
		if errors.Is(err, license.ErrNoLicense) {
			_, _ = fmt.Fprintln(stderr, "no license; run `apitest login`")
			return 2
		}
		_, _ = fmt.Fprintf(stderr, "read license: %v\n", err)
		return 1
	}

	tok, _ := license.ParseToken(rec.AccessToken) // best-effort
	out := map[string]any{
		"jti":                       claimString(tok, func(c license.Claims) string { return c.Jti }),
		"kid":                       headerKid(tok),
		"tier":                      claimString(tok, func(c license.Claims) string { return c.Tier }),
		"exp":                       claimInt(tok, func(c license.Claims) int64 { return c.Exp }),
		"grace_until":               claimInt(tok, func(c license.Claims) int64 { return c.GraceUntil }),
		"refresh_failures":          rec.ValidationFailures,
		"lastRefreshAttemptAt":      rec.LastValidationAttempt.Format(time.RFC3339),
		"cache_file":                filepath.Join(cfgDir, "license.json"),
		"last_error_type":           licenseLastError, // package var, populated best-effort
	}
	enc := json.NewEncoder(stdout)
	enc.SetIndent("", "  ")
	_ = enc.Encode(out)
	return 0
}

// licenseLastError is populated by the refresh path on ProblemDetails errors;
// surfaced by --debug for docs navigation. Best-effort cross-invocation
// persistence is out of scope; --debug only sees errors from the same process.
// Persisted to <cfgDir>/last_error.txt by the refresh failure path.
var licenseLastError string
```

```markdown
**`apitest license --refresh` exit codes (8-code taxonomy).** This is a CLI-specific subset of §4.3 — the `license --refresh` command maps backend RFC 7807 problem codes to deterministic exit codes for CI integration:

| Exit | Meaning | Triggers |
|------|---------|----------|
| 0 | Success | License JWT + access + refresh token rotated and cached |
| 1 | Internal error | Unexpected; bug |
| 2 | No cache | No refresh token stored — run `apitest login` |
| 3 | Network failure | Cannot reach backend; previous License JWT still valid (within 30d + 14d grace) |
| 4 | Refresh expired | Refresh token past sliding-window or absolute deadline; re-auth required |
| 5 | Family revoked | Reuse detected or admin-initiated revocation; re-auth required |
| 6 | Server error | 5xx; previous License JWT remains valid |
| 7 | Device not registered | First run; needs `apitest login` |
```

## Risks and Edge Cases

- **Risk:** `RefreshTokens` modification changes error semantics for the `internal_cmd backend-probe` path → **Mitigation:** verified that path uses `/api/v1/auth/refresh-reused` (different URL); the new `translateRefreshError` only inspects the embedded `*ProblemDetails.Code`, which the probe handler does not use. Add an assertion test in `refresh_test.go` that an unknown code bubbles untouched.
- **Risk:** Stub backend `inject` global state collides with concurrent test runs → **Mitigation:** stub is single-tenant and only used for manual observable verification + the smoke test, which runs sequentially. No automated CLI test depends on it.
- **Risk:** `lockfile` flock test holding the lock externally still affects the new test path → **Mitigation:** new tests do not acquire any external lock; each uses its own `t.TempDir()` for cfgDir.
- **Risk:** A successful refresh leaves the storage-rotated refresh token persisted, but a subsequent `Save(rec)` fails — leaves persistence inconsistent (new refresh token in storage, old License JWT in `license.json`) → **Mitigation:** This is consistent with `persistLogin`'s ordering and acceptable: the next refresh will succeed using the new refresh token, and the License JWT is offline-verified so even an old one in `license.json` is fine. Document in code comment.
- **Risk:** `daysUntilExpiry` returning 0 when `exp` is in the past results in misleading "Expires in 0 days." → **Mitigation:** acceptable for the success path because the backend rejects expired tokens (the code path implies a fresh token); covered by an explicit table case (`"already expired"` → "Expires in 0 days.").
- **Edge case:** Backend returns 200 success but a malformed JWT (no `tier` claim, no `exp`) → **Handling:** `tierFromLicenseJWT` returns empty string; `daysUntilExpiry` returns -1; stdout reads "License refreshed. Tier=. Expires unknown." Exit 0. Acceptable; test asserts no panic + exit 0.
- **Edge case:** Concurrent `--refresh` invocations → **Handling:** existing flock in `RefreshTokens` already serialises; the new code path is a no-op for the second caller (cache re-read returns the rotated token).
- **Edge case:** `APITEST_BACKEND_URL` set to `https://api.apitool.dev` (real production) during CI test runs → **Mitigation:** all unit tests `t.Setenv("APITEST_BACKEND_URL", srv.URL)` to override the default. The default URL only fires when no test isolation is in effect.
- **Edge case:** ProblemDetails `Code` field present but empty string → **Handling:** falls through `refreshCodeToSentinel` lookup, returns the original `*ProblemDetails`, hits the default arm of `licenseRefreshExitForError` (exit 1). Covered by `TestRefreshTokens_UnknownAuthCode_BubblesProblemDetails`.
