## Design decisions

### D1 — The expensive test goes behind `//go:build readme_install`; the hermetic one does not

The task's `observable` runs both tests untagged. That is wrong for the first
one and right for the second, so the work is split across two files:

| File | Tag | Contents | Cost |
|---|---|---|---|
| `cmd/curlew/readme_install_test.go` | *(none)* | block extractor, `TestReadme_documents_a_binary_download`, `TestReadme_install_blocks_extraction` | milliseconds, no network |
| `cmd/curlew/readme_install_exec_test.go` | `readme_install` | `TestReadme_install_commands_execute` | ~14s, needs network + `gh` + git credentials |

Rationale: an untagged test is compiled into all three routine passes
(`scripts/ci-local.sh:190` plain, `:193` `-race`, `:196` `-coverprofile`), so the
executing test would run **three times per `--go` gate** and would make the
routine `go test` passes depend on the public internet, `gh`, and GitHub
credentials. M25-002 set this precedent for the same reason
(`release_artifacts_test.go:1`). The hermetic test has no such cost and stays
untagged so the task's observable works verbatim for it.

**The untagged file is compiled into the tagged build too**, so the extractor
lives there and the tagged file consumes it. That is the correct dependency
direction and avoids duplicating the parser.

**Consequence — the task file's observable is corrected.** `go test
./cmd/curlew/ -run TestReadme_install_commands_execute -v` without the tag exits
0 having run nothing: the identical vacuity M25-002 hit. `management/tasks/M25-003.yaml`
is updated so its observable carries `-tags readme_install`.

### D2 — A second build tag requires three companion edits, not one

Following `C` of the exploration and the existing wiring:

1. `//go:build readme_install` on the new exec file.
2. `.golangci.yml` `run.build-tags` **gains a second list entry** (it is extended,
   never replaced) — otherwise the file is silently unlinted, the exact failure
   the comment at `.golangci.yml:3-8` exists to prevent.
3. `scripts/ci-local.sh` gains a named step with its own `-list` vacuity guard.

**Symbol-collision hazard, and it is real.** `run.build-tags` sets *all* listed
tags at once, so golangci-lint compiles `release_artifacts_test.go` and
`readme_install_exec_test.go` into the same package. Every new symbol is
therefore prefixed `readme*` and must not reuse `releaseConfig`,
`loadReleaseConfig`, `releaseFindRepoRoot`, or `releaseArchiveNameRE`.

**Helpers cannot be borrowed across the tag boundary.** `loadReleaseConfig`
(`release_artifacts_test.go:462`) is unreachable from an untagged file, and its
`releaseConfig` struct (`:446-457`) parses `archives[].files` only — it does
**not** parse `name_template`. A separate, minimal parse is written.

### D3 — Missing network, `gh`, or credentials is a failure, never a skip

`release_artifacts_test.go:150` states the house position: "It never skips: a
missing goreleaser is a failure." The same applies here, for a stronger reason —
a skip is a silent pass, which is precisely the defect class this task exists to
close.

The trade-off is named rather than hidden: `./scripts/ci-local.sh --go` already
requires the network (goreleaser's `before: hooks: go mod download`), and the
routine `go test ./...` passes stay offline-clean because the executing test is
tagged. A developer with no network can still run the full untagged suite; they
cannot run the `--go` gate, which was already true before this task.

`gh` is a new gate dependency. It is probed and reported the way `lint_cmd` and
`goreleaser_cmd` already are (`ci-local.sh:125-160`): a missing `gh` prints an
install line and **returns non-zero**.

### D4 — Only `bash`/`sh` fences under `## Install` are executable, and every one of them is executed

This is how behaviour 4 ("a new install method added without a matching check
must fail") is satisfied **structurally, with no hand-maintained list**: the test
runs every block it finds. Adding a fourth block adds a fourth execution
automatically; if it does not work, the test fails.

A fence under `## Install` whose info string is anything other than `bash` or
`sh` is a **failure**, not a skip — otherwise a future author could park a broken
command in a ```` ```text ```` fence and quietly exempt it.

### D5 — Blocks run as whole scripts, not line by line

The clone block is stateful: `cd curlew` must affect the following
`go build ./cmd/curlew`. Each block is written verbatim to a file and run as
`bash -euo pipefail <file>`. The flags live on the interpreter, not in the
documented text, so the README stays byte-for-byte what the reader sees while a
failure in any line still fails the test. Verified by measurement rows 6 and 8.

### D6 — Isolation

Each block runs in its own `t.TempDir()` with `cmd.Env = append(os.Environ(),
"GOBIN="+<tmp>/bin)`. `GOBIN` is redirected because the README's `go install`
would otherwise overwrite the developer's own `~/go/bin/curlew`. `GOMODCACHE` is
deliberately **left shared** — that is the difference between the measured 7s
warm install and a cold multi-minute one. A `context.WithTimeout` of 10 minutes
bounds the whole thing, well above the ~14s measured, mirroring
`release_artifacts_test.go:202`.

### D7 — Homebrew: **no, not yet** — and the reason is disqualifying, not merely cautious

Recorded in `docs/TECH_CHOICES.md`. The decision and its evidence:

- A Homebrew tap serves a formula that fetches a release asset **anonymously**.
  Measurement 7 shows that request returns **404** because the repository is
  private. A tap today would not be a maintenance burden; it would be a formula
  that cannot install anything.
- `brews:` in goreleaser additionally needs a second repository
  (`homebrew-tap`) and a write-scoped token, adding a publish target that can
  fail *after* the tag is immutable.
- One maintainer, first release cut on 2026-08-16, no external users.

**Revisit trigger, written into the document:** when the repository is public
**and** a second release exists — i.e. when a tap would have something to serve
and a cadence to keep.

Because the decision is *made* rather than deferred, it goes in a new
`### Distribution` subsection under `## CLI — Go` (alongside `### Tooling` at
`:40` and `### Conventions` at `:54`), not in `## Decisions Not Yet Made`
(`:215`). Filing a made decision under "not yet made" would be the same category
error the task is warning against.

The two security documents claiming a tap exists are corrected in the same
change.

### D8 — `go install` reporting `0.1.0-dev` is documented here, not fixed here

Rows 4 and 6 show both source paths produce `curlew 0.1.0-dev`. Deriving the
version from `runtime/debug.ReadBuildInfo()` would fix it, but that changes
`--version`, `--help` and `info --format json`, and interacts with three tests in
`cmd/curlew/version_test.go` (notably `TestVersion_default_when_not_injected` at
`:114`, which currently *blesses* the `-dev` default). That is a separate
vertical slice. This task **documents** the difference in the README and asserts
that the download path yields a released version, so the gap is measured rather
than assumed.

### D9 — The tests verify the *published* tool, by design

`go install …@latest` resolves to v0.1.0 and `git clone` fetches `origin/main`;
neither reflects the working branch. This is correct — the README documents
installing the released tool, and that is what is being checked. Recorded so a
reviewer does not read it as a bug.

#### Why a new extractor rather than reusing `codeSpansWithLines`

`codeSpansWithLines` (`skill_commands_test.go:43`) is close but unusable as-is:
it **discards the fence info string** (`:52-61` `continue`s past the opening
fence without recording `bash`), and it merges inline `` `spans` `` with fenced
blocks into one `[]codeSpan`. D4 needs the language, and the rewritten Install
section is full of inline spans in prose that must never be executed. A
purpose-built walker is written; the existing helper is left untouched.

#### Proposed Go signatures

```go
// readmeBlock is one fenced code block found under a markdown heading.
type readmeBlock struct {
    lang string // the fence info string, verbatim ("bash", "text", "")
    body string // the block's contents, without the fence lines
    line int    // 1-based line of the opening fence
}

// readmeSectionBlocks returns every fenced code block that appears under the
// "## <heading>" section of doc, stopping at the next "## " heading.
func readmeSectionBlocks(doc, heading string) []readmeBlock

// readmeSectionText returns the raw text of the "## <heading>" section,
// used for prose assertions.
func readmeSectionText(doc, heading string) string

// readmeRepoRoot resolves the repository root from a test in cmd/curlew.
func readmeRepoRoot(t *testing.T) string

// readmeModulePath returns the module path declared in go.mod.
func readmeModulePath(t *testing.T, repoRoot string) string

// readmeArchiveConfig is the subset of .goreleaser.yaml this test holds the
// README to. Deliberately separate from releaseConfig in
// release_artifacts_test.go, which is behind a different build tag and parses
// archives[].files only.
type readmeArchiveConfig struct {
    ProjectName string `yaml:"project_name"`
    Archives    []struct {
        NameTemplate    string   `yaml:"name_template"`
        Formats         []string `yaml:"formats"`
        FormatOverrides []struct {
            GOOS    string   `yaml:"goos"`
            Formats []string `yaml:"formats"`
        } `yaml:"format_overrides"`
    } `yaml:"archives"`
}

func loadReadmeArchiveConfig(path string) (readmeArchiveConfig, error)

// renderNameTemplate substitutes the documentation placeholders into
// name_template and reports any goreleaser action it did not recognise, so a
// template that grows a new {{ ... }} fails loudly instead of rendering wrong.
func renderNameTemplate(tmpl, projectName string) (rendered string, unknown []string)
```

```go
//go:build readme_install

// This file executes the command blocks under README.md's "## Install"
// heading. It is behind //go:build readme_install because it costs ~14s and
// needs the public internet, an authenticated gh, and git credentials for a
// private repository — none of which the three routine `go test` passes in
// scripts/ci-local.sh should acquire. scripts/ci-local.sh names the test here
// as an unconditional step of its own, so the tag is not an opt-out.
package main

func TestReadme_install_commands_execute(t *testing.T) {
    repoRoot := readmeRepoRoot(t)
    doc := readFileOrFatal(t, filepath.Join(repoRoot, "README.md"))
    blocks := readmeSectionBlocks(doc, "Install")

    if len(blocks) == 0 { t.Fatal(...) }        // vacuity
    if len(blocks) < 3 { t.Fatalf(...) }        // floor, measured 3

    ctx, cancel := context.WithTimeout(context.Background(), 10*time.Minute)
    defer cancel()

    executed := 0
    sawReleasedVersion := false
    for _, b := range blocks {
        if b.lang != "bash" && b.lang != "sh" {
            t.Errorf("README.md:%d: fence language %q under '## Install' — a block here is either an executable bash command or it does not belong in the Install section", b.line, b.lang)
            continue
        }
        dir := t.TempDir()
        script := filepath.Join(dir, "block.sh")
        os.WriteFile(script, []byte(b.body), 0o600)

        cmd := exec.CommandContext(ctx, "bash", "-euo", "pipefail", script)
        cmd.Dir = dir
        cmd.Env = append(os.Environ(), "GOBIN="+filepath.Join(dir, "bin"))
        out, err := cmd.CombinedOutput()
        executed++
        if err != nil {
            t.Errorf("README.md:%d: install block failed: %v\n--- block ---\n%s\n--- output ---\n%s", b.line, err, b.body, out)
            continue
        }
        if releasedVersionRE.Match(out) { sawReleasedVersion = true }
    }

    if executed != len(blocks) { t.Errorf(...) }
    if !sawReleasedVersion {
        t.Error("no install block produced a binary reporting a released version " +
            "(want `curlew X.Y.Z`, not X.Y.Z-dev) — the download-and-run path is gone")
    }
}

// releasedVersionRE matches a real release version only: 0.1.0-dev and
// 0.1.1-snapshot must not satisfy it.
var releasedVersionRE = regexp.MustCompile(`(?m)^curlew [0-9]+\.[0-9]+\.[0-9]+$`)
```

The `sawReleasedVersion` check is how DoD item "A download-and-run path is
documented and works" is enforced without hand-naming which block is the
download one: it is derived from what the blocks actually printed.

#### Impact on Existing Tests

- None directly. Note the name-space overlap flagged in exploration: with

## Risks and Edge Cases

- **Risk: the gate becomes network-dependent.** → **Mitigation:** the executing
  test is tagged, so `go test ./...` stays offline-capable; only the `--go`
  gate needs network, which was already true (goreleaser's `go mod download`
  before-hook). Stated in D3 rather than hidden.

- **Risk: `gh` or git credentials absent on another machine.** → **Mitigation:**
  probe-and-fail with an install message, mirroring `lint_cmd`/`goreleaser_cmd`
  (`ci-local.sh:125-160`). Deliberately **not** a skip (D3).

- **Risk: symbol collision under golangci-lint**, which sets `release_artifacts`
  and `readme_install` simultaneously and compiles both tagged files together.
  → **Mitigation:** every new symbol carries a `readme*` prefix; a fresh
  `readmeArchiveConfig` is defined rather than reusing `releaseConfig`.

- **Risk: `go install` clobbers the developer's `~/go/bin/curlew`.** →
  **Mitigation:** `GOBIN` redirected to the block's `t.TempDir()` (D6).
  `GOMODCACHE` stays shared, which is what keeps the install at the measured 7s.

- **Risk: the `-list` guard's count drifts.** A fourth `TestReadme_*` under the
  tag would fail the hardcoded `3`. → **Mitigation:** accepted, and identical to
  the existing `!= "3"` guard at `ci-local.sh:353`; the failure is loud and the
  fix is one line.

- **Edge case: a future author adds a non-bash fence under `## Install`.** →
  **Handling:** hard failure with a message saying the block is either an
  executable bash command or does not belong there (D4). No silent exemption.

- **Edge case: `name_template` grows a new goreleaser action.** → **Handling:**
  `renderNameTemplate` returns `unknown` for any `{{ … }}` it did not substitute
  and the test fails, rather than comparing a half-rendered string.

- **Edge case: multi-line stateful block (`cd curlew`).** → **Handling:** blocks
  run as whole scripts under `bash -euo pipefail`, verified by measurement 6.

- **Edge case: the section is renamed away from `## Install`.** → **Handling:**
  `readmeSectionBlocks` returns nothing and the vacuity guard fires with
  "the extraction is broken, not the README".

- **Open risk, out of scope: the repository is private**, so the product M25
  calls "a deliverable that exists" cannot be obtained by anyone outside the
  account. This task makes the README *honest* about that; it does not change
  it. Changing repository visibility is a consequential real-world action and
  belongs in its own task with explicit approval.

- **Open risk, out of scope: `go install` yields `0.1.0-dev`** (D8). Documented
  and measured here, fixed elsewhere.
