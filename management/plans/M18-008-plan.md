# Implementation Plan: M18-008

## Overview

Adds a new `internal/telemetry` Go package and `curlew telemetry` subcommand implementing the CLI side of the v4-8 persistent-install-ID telemetry model. Persists an opt-in `install_id` (UUIDv4, mode 0600) under `~/.config/curlew/`, ships a dedicated HTTP client with per-event `Idempotency-Key` headers (no `internal/backend` reuse per v4-11), wires a fire-and-forget `run.completed` emission into the existing run-end path in `cmd/curlew/main.go`, and updates the spec's Telemetry Phase 3 CLI section to reflect the persistent-install-ID model (supersedes `:6374`).

## Architectural Decisions

1. **Package boundary.** The package lives at `internal/telemetry/` and imports only `crypto/rand`, `encoding/json`, `net/http`, `os`, `path/filepath`, `sync`, `time`, plus `internal/license` (for `ResolveConfigDir`) and `internal/output/events` (to register a `TelemetrySink` that the run-end path invokes). It MUST NOT import `internal/backend` — enforced via CI grep guard added in `scripts/ci-local.sh`.

2. **Config dir resolution.** Reuse `license.ResolveConfigDir()` (already honours `CURLEW_CONFIG_DIR` and `os.UserConfigDir`/`curlew`). Storage paths:
   - `<configDir>/install_id` — raw UUIDv4 string, mode 0600
   - `<configDir>/telemetry.json` — JSON: `{ "enabled": bool, "endpoint": "<override or empty>", "last_emissions": [{ "at": "RFC3339", "event_type": "...", "status": "ok|error|disabled", "error": "..." }] }` (mode 0600). The recent-emissions ring buffer powers `telemetry export` (most recent 10 attempts kept).

3. **UUID generation.** A private `newUUIDv4()` mirrors `internal/variable/dynamic.go:makeUUID` (crypto/rand, sets v4 + variant bits). No new dependency. Centralised in `internal/telemetry/uuid.go` with its own table-driven test.

4. **HTTP client.** Standalone `http.Client{Timeout: 2 * time.Second}` — chosen tight so a hanging endpoint cannot delay user-visible exit. The emit code is invoked from a deferred goroutine with a `sync.WaitGroup` that we drain with a 2-second cap before returning from `runCmdWithWriters`; failures are silently swallowed and recorded only in the ring buffer.

5. **Endpoint resolution.** Precedence:
   1. `CURLEW_TELEMETRY_ENDPOINT` env var (tests, self-hosted).
   2. `telemetry.json` → `endpoint` field (set via `curlew telemetry enable --endpoint=...` — not required for M18-008's observable but included for self-hosters and tests).
   3. Default: `https://api.curlew.org/telemetry/events`.

6. **Session UUID.** Each `curlew run` invocation generates one ephemeral session UUID (independent of `runID`/`install_id`) and nests it in the `run.completed` event payload as `session_id`. This preserves the prior `:6374` per-execution identity as a nested sub-identifier per v4-8.

7. **Event-emission integration.** The existing `--events` NDJSON stream remains a local-file artefact; telemetry is a separate concern. The runner-side hookup is a new `TelemetrySink` interface populated when telemetry is enabled, invoked once from the `defer eventsEmitter.EmitRunEnd(...)` block in `runCmdWithWriters` with the summary counters. Hooking from the same defer (rather than `internal/output/events`) keeps `internal/output/events` free of HTTP imports and matches the spec's emit-once-per-run model.

8. **`telemetry.json` schema-version field.** Single integer `schema_version: 1`, allowing future shape changes.

9. **`delete-request` final POST.** Issues one synchronous POST (5-second timeout) with `event_type=telemetry.delete_request` before removing local files. If the POST fails (offline), files are still removed locally; stdout reports "telemetry: local files removed; backend delete POST failed (offline). Re-run when online to send the delete request." with exit 0 — local cleanup must always succeed.

10. **Spec correction.** `docs/SPECIFICATION.md §6320–6595` (the v3 Telemetry Phase 3 section) is updated in this slice with a new sub-section "Persistent Install ID Model (v4-8)" placed above the legacy Session-Level Data table, plus an explicit cross-reference at `:6374` noting supersession. The wire contract at `:11382` already reflects v4-8; we only need to align the prose section.

```go
// internal/telemetry/uuid.go
package telemetry

import (
	"crypto/rand"
	"fmt"
)

// newUUIDv4 returns a freshly-generated UUID v4 string in canonical 8-4-4-4-12 form.
// Mirrors internal/variable/dynamic.go:makeUUID; lives here so internal/telemetry
// does not depend on internal/variable.
func newUUIDv4() (string, error) {
	var b [16]byte
	if _, err := rand.Read(b[:]); err != nil {
		return "", fmt.Errorf("telemetry: read random bytes: %w", err)
	}
	b[6] = (b[6] & 0x0f) | 0x40 // version 4
	b[8] = (b[8] & 0x3f) | 0x80 // variant 10
	return fmt.Sprintf("%08x-%04x-%04x-%04x-%012x", b[0:4], b[4:6], b[6:8], b[8:10], b[10:16]), nil
}
```

```go
// internal/telemetry/client.go
package telemetry

import (
	"bytes"
	"context"
	"encoding/json"
	"fmt"
	"net/http"
	"time"
)

// Client posts telemetry events to the ingest endpoint. Dedicated to
// internal/telemetry (does NOT reuse internal/backend) per v4-11.
type Client struct {
	httpClient *http.Client
	endpoint   string
}

// ClientOptions configures Client. Timeout defaults to 2 seconds.
type ClientOptions struct {
	Endpoint   string
	Timeout    time.Duration
	HTTPClient *http.Client // override for tests
}

// NewClient builds a Client.
func NewClient(opts ClientOptions) *Client { /* ... */ }

// Emit posts one event. Errors are returned but callers MUST NOT surface them
// to the user — telemetry failures are silent (per v4-9 spec :11479).
// On success or on a 202 replay, returns nil. On non-2xx or transport error,
// returns a wrapped error suitable for store.RecordEmission.
func (c *Client) Emit(ctx context.Context, installID, eventType string, payload map[string]any) error {
	body, err := json.Marshal(map[string]any{
		"install_id":    installID,
		"event_type":    eventType,
		"event_payload": payload,
	})
	if err != nil {
		return fmt.Errorf("telemetry: marshal: %w", err)
	}
	idemKey, err := newUUIDv4()
	if err != nil {
		return fmt.Errorf("telemetry: gen idempotency key: %w", err)
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, c.endpoint, bytes.NewReader(body))
	if err != nil {
		return fmt.Errorf("telemetry: build request: %w", err)
	}
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Idempotency-Key", idemKey)
	resp, err := c.httpClient.Do(req)
	if err != nil {
		return fmt.Errorf("telemetry: post: %w", err)
	}
	defer resp.Body.Close()
	if resp.StatusCode == http.StatusAccepted || resp.StatusCode == http.StatusTooManyRequests {
		// 429 is non-fatal per spec :11479 (debug-only logging).
		return nil
	}
	return fmt.Errorf("telemetry: unexpected status %d", resp.StatusCode)
}
```

```go
// internal/telemetry/emit.go
package telemetry

import (
	"context"
	"time"
)

// Emitter is the high-level entry point. Wraps Store and Client.
type Emitter struct {
	store  *Store
	client *Client
}

// NewEmitter builds an Emitter rooted at configDir. Endpoint precedence:
// CURLEW_TELEMETRY_ENDPOINT > telemetry.json.Endpoint > default.
func NewEmitter(store *Store, client *Client) *Emitter { /* ... */ }

// Emit fires a single event when telemetry is enabled. When disabled or when
// install_id is absent, returns nil without contacting the network. All errors
// are recorded to the ring buffer; callers MUST NOT surface them.
func (e *Emitter) Emit(ctx context.Context, eventType string, payload map[string]any) {
	enabled, installID, _, err := e.store.Status()
	if err != nil || !enabled {
		_ = e.store.RecordEmission(Emission{
			At: time.Now().UTC().Format(time.RFC3339), EventType: eventType, Status: "disabled",
		})
		return
	}
	if emitErr := e.client.Emit(ctx, installID, eventType, payload); emitErr != nil {
		_ = e.store.RecordEmission(Emission{
			At: time.Now().UTC().Format(time.RFC3339), EventType: eventType, Status: "error", Error: emitErr.Error(),
		})
		return
	}
	_ = e.store.RecordEmission(Emission{
		At: time.Now().UTC().Format(time.RFC3339), EventType: eventType, Status: "ok",
	})
}
```

```go
		return 0

	case "delete-request": return telemetryDeleteRequest(store, stdout, stderr)

		_, _ = fmt.Fprintf(stderr, "Unknown telemetry subcommand: %s\n", args[0])
		printTelemetryHelpTo(stderr)
		return 1
	}
```

```go
func emitTelemetryRunCompleted(sessionID string, started time.Time, summary *runner.Summary, exitCode int) {
    configDir, _, err := license.ResolveConfigDir()
    if err != nil {
        return
    }
    store, err := telemetry.NewStore(configDir)
    if err != nil {
        return
    }
    enabled, _, endpoint, statusErr := store.Status()
    if statusErr != nil || !enabled {
        return
    }
    client := telemetry.NewClient(telemetry.ClientOptions{Endpoint: endpoint, Timeout: 2 * time.Second})
    emitter := telemetry.NewEmitter(store, client)
    ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
    defer cancel()
    payload := map[string]any{
        "session_id":     sessionID,
        "duration_ms":    time.Since(started).Milliseconds(),
        "exit_code":      exitCode,
    }
    if summary != nil {
        payload["collection_size"] = summary.Total
        payload["success_count"]   = summary.Passed

    }

}
```

## Risks and Edge Cases

- **Risk:** Stray network calls in CI from accidental telemetry emission. → **Mitigation:** Telemetry is disabled by default; the emit path is a guaranteed no-op when `telemetry.json` is absent. Step 4 test pins this property; the helper short-circuits before constructing the HTTP client.
- **Risk:** `runCmdWithWriters` exit time regression. → **Mitigation:** 2-second bounded context on the telemetry emit; the helper is invoked at the very end of the defer and the inflight goroutine pattern is not needed (Emit is synchronous but cheap; if slow, the context kills it). Test `TestRunDoesNotBlockOnSlowTelemetryEndpoint` proves the bound.
- **Risk:** Concurrent `curlew telemetry` invocations corrupting `telemetry.json`. → **Mitigation:** `Store.mu sync.Mutex` for in-process safety; atomic rename for crash safety. Cross-process concurrency is rare (single user, single config dir) and acceptable to leave on last-writer-wins.
- **Risk:** `delete-request` POST hanging at exit. → **Mitigation:** Synchronous with 5-second deadline; we then proceed to local-file deletion regardless of POST outcome. Failure is reported in stdout but exit is 0.
- **Edge case:** `CURLEW_TELEMETRY_ENDPOINT` set to an invalid URL. → **Handling:** `http.NewRequestWithContext` returns an error; `Emit` records `status=error` and returns nil to caller; user-facing flow unaffected.
- **Edge case:** Disk full during `RecordEmission`. → **Handling:** Returned error is logged via emission ring (irony noted) but swallowed; never blocks the run.
- **Edge case:** `os.UserConfigDir` fails (no `HOME` set). → **Handling:** `license.ResolveConfigDir` returns the error already; subcommand exits 1 with the error message. `emitTelemetryRunCompleted` silently no-ops.
- **Edge case:** Symlinked `install_id` to a path the user does not own. → **Handling:** `os.WriteFile` honours O_TRUNC|O_CREATE — symlinks dereferenced; mode 0600 enforced via explicit `os.Chmod` after rename.
- **Edge case:** Schema-version bump in `telemetry.json`. → **Handling:** `Store.readState` ignores unknown fields and treats `schema_version > 1` as readable (forward-compat); writes back at current version on next mutation.
