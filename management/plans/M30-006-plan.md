# Implementation Plan: M30-006

## Overview

Repair the platform foundations that prevent reliable native Windows development:
portable tests and fixtures, hermetic test traffic, plugin/editor behavior, display
paths, process lifecycle, and repeatable native verification. Preserve the existing
POSIX gate as the authoritative repository gate.

## Task Details

- **ID:** M30-006
- **Title:** Repair native Windows foundations and verification gates
- **Phase:** M30: Local product usability
- **Priority:** 1
- **Complexity:** high

## Dependencies

| Task | Title | Status |
| --- | --- | --- |
| M30-003 | Install and maintain a portable Curlew agent skill | done |

M30-004 remains in progress and consumes this task's gate repairs. M30-005 remains
backlog and consumes the native scripts/evidence for clean-host and packaged-app
acceptance. M30-006 does not change command/vault behavior owned by M30-004.

## Current Constraints

- `cmd/curlew` tests do not compile on Windows because `perf_test.go` calls Unix
  `syscall.Kill`; several test helpers build extensionless executables.
- Telemetry tests execute a collection targeting example.com. POSIX smoke already
  has a local HTTPBin fixture, but one conditional fixture still calls public HTTPBin.
- Windows checkout conversion changes byte-exact goldens and embedded templates.
- Several failure-path tests depend on Unix permissions, `/dev/*`, Bash or shebangs.
- Plugin discovery still requires Unix execute bits on Windows, and plugin shutdown
  does not contain descendants.
- UI editor launch splits quoted commands with `strings.Fields` and starts `.cmd`
  wrappers directly. Display labels split paths only on `/`.
- No native PowerShell verification/smoke entry points exist. Existing Bash smoke
  owns fixed ports and can kill processes it did not start.

Already-correct behavior must remain unchanged: release tests expect `curlew.exe`,
`filepath.ListSeparator` is portable, production perf uses `signal.NotifyContext`,
release targets include Windows, and the primary smoke fixture is already local.

## Risks And Edge Cases

- **Console signaling:** broadcasting Ctrl+C can terminate VS Code. **Mitigation:**
  private hidden console, exact process allowlist and retained handles.
- **Batch quoting:** CMD has multiple parse passes. **Mitigation:** real argv recorder,
  metacharacter/quote matrices and the already-proven transport design.
- **Plugin descendants:** killing only the direct process leaks work. **Mitigation:**
  Job Object/process-group ownership and success only when descendants exit.
- **Checkout normalization:** broad rules create noisy or incorrect diffs.
  **Mitigation:** targeted attributes and byte assertions; preserve wire captures.
- **Editor lifetime:** request cancellation must not kill a persistent editor.
  **Mitigation:** launch/reap semantics separate from command/provider containment.
- **Gate equivalence:** native scripts can accidentally become a weaker substitute.
  **Mitigation:** document supplementary status and require final auto-scoped POSIX gate.
- **Public traffic:** documentation URLs can look like runtime calls. **Mitigation:**
  assert actual request paths; change only executing fixtures.
- **Tool mismatch:** pinned linter cannot read Go 1.27 export data. **Mitigation:**
  choose and document one reproducible compatible verification combination before
  whole lint; do not silently downgrade the installed toolchain.
- **Unavailable arm64 host/race:** cross-build is not native evidence. **Mitigation:**
  leave architecture rows BLOCKED/NOT RUN and defer support claims to M30-005.
