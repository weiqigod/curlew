### How the existing `$randomBase64` arity-flex pattern works

The task YAML pins `$randomBase64` (`dynamic.go:369-396`) and
`$randomPassword` (`dynamic.go:401-424`) as the model: each is a raw
`DynFunc` (not `noArgs` / `oneArg`) that:

1. Validates arity manually with `if len(args) != 1 { return "",
   arityError(...) }`.
2. Calls `strconv.Atoi(args[0])` inside the body and returns a
   structured `CategoryInput` error on parse failure
   (`DYNFN_<NAME>_BAD_INPUT`).
3. Validates value range and returns `DYNFN_<NAME>_BAD_LENGTH` on
   out-of-range input.
4. Uses `intn(rng, ...)` for randomness — the registry's seeded PCG
   when `--seed` is set, else `crypto/rand`.

For M13-006, four of the five content functions need **arity-flex
(0 or 1 args)** instead of strict 1-arg. The body shape is:

```go
r.funcs["faker.<name>"] = func(rng *rand.Rand, args []string) (string, error) {
    if len(args) > 1 {
        return "", arityError("faker.<name>", 1, len(args))
    }
    n := <DEFAULT>
    if len(args) == 1 {
        parsed, err := strconv.Atoi(args[0])
        if err != nil {
            return "", &apierrors.Structured{
                Category: apierrors.CategoryInput,
                Code:     "DYNFN_FAKER_<NAME>_BAD_INPUT",
                Message:  fmt.Sprintf("invalid count %q: must be an integer", args[0]),
                Hint:     "Pass an integer string, e.g. {{$faker.<name>('5')}}.",
                Inner:    err,
            }
        }
        if parsed < 1 {
            return "", &apierrors.Structured{
                Category: apierrors.CategoryInput,
                Code:     "DYNFN_FAKER_<NAME>_BAD_LENGTH",
                Message:  fmt.Sprintf("count %d is invalid: must be >= 1", parsed),
                Hint:     "Pass an integer string >= 1.",
            }
        }
        n = parsed
    }
    return generate(rng, n), nil
}
```

`$faker.word` is the one zero-arg function — it uses the existing
`noArgs` wrapper for symmetry with the rest of the `$faker.*`
no-argument family at `dynamic.go:430-620`.

### Lorem-ipsum word pool design

Per task scope: ~250 words is sufficient. Design constraints:

- All entries are lowercase ASCII matching `^[a-z]+$` (no digits, no
  hyphens, no punctuation).
- Pool entries are real Latin lorem-ipsum tokens (so the rendered
  output reads as canonical placeholder text, not gibberish).
- Pool size is a fixed file-scope `var` slice; mutation is forbidden.

The pool feeds all four word-emitting functions:
- `$faker.word` — single draw.
- `$faker.words(n)` — n independent draws joined by single space.
- `$faker.sentence(n)` — n independent draws, first word capitalised,
  joined by single space, period appended.
- `$faker.paragraph(n)` — n sentences (each via the sentence
  generator with the default 6–10 word range) joined by single space.
- `$faker.text(charLen)` — emit sentences until cumulative length
  reaches `charLen`, then stop at the next sentence boundary (so the
  result is well-formed prose; length is approximately `charLen`,
  within +/- 10 chars).

**Decision:** ship a 250-word `loremWords` pool at file scope. This
is enough entropy that `--seed 42` stable output remains
reasonably-distributed (single-word collision probability per draw is
1/250 ≈ 0.4%); pool size is large enough that two `$faker.text`
draws do not look like exact repeats but small enough to keep the
binary footprint negligible.

### Sentence-count default for `$faker.sentence`

Spec: "Complete sentence (default: 6-10 words)" (SPECIFICATION.md:821).
The default is a range, not a fixed count. Implementation: when
`len(args) == 0`, draw a count via `intn(rng, 5) + 6` (range 6..10
inclusive, 5 values). When `len(args) == 1`, use the parsed value
directly.

The same logic applies to `$faker.paragraph` (default 3–5 sentences):
draw `intn(rng, 3) + 3` when no args. **Decision:** the default
sentence-count for `$faker.paragraph` USES the default 6–10-word
range for each composed sentence (i.e. each sentence in the
paragraph independently draws its own word-count). This keeps the
generator deterministic under seed — the call order is fixed
(paragraph-count -> per-sentence: word-count -> per-word: pool index)
— and matches the spec narrative example
("Lorem ipsum dolor sit amet...").

### Text generation algorithm (`$faker.text(charLen)`)

Behavior: "stop at the first sentence boundary at-or-after the
requested length to keep prose well-formed" — within +/- 10 chars
of `charLen`. Algorithm:

1. Initialise `out := strings.Builder{}`.
2. Loop: generate one sentence (using the same
   default-6–10-word generator), append it to `out` (preceded by a
   single space if `out.Len() > 0`).
3. After each append, if `out.Len() >= charLen`, break.
4. Return `out.String()`.

This keeps the text close to `charLen` without truncating
mid-sentence. The +/- 10 char tolerance matches the task's observable
verification ("within +/- 10 chars of 50"). For very small
`charLen` (e.g. 10), the result will overshoot — the smallest
generated sentence is ~30 chars (six 4–8-letter words). This is
acceptable per behavior 9 ("the generator stops at the first
sentence boundary at-or-after the requested length"), but the test
suite uses `charLen=200` (default) and `charLen=50` (the task's
observable example) — both well above the minimum.

Default for `$faker.text` is 200 chars.

// parseFakerCountArg validates a 0-or-1-arg arity-flex argument list
// for the M13-006 content-data family. Returns defaultN when args is
// empty; otherwise strconv.Atoi-converts args[0] and rejects values
// < 1. The funcName is used for both the arity error and the
// structured BAD_INPUT / BAD_LENGTH error codes.
//
// Mirrors the body of $randomBase64 (dynamic.go:369-396) but
// generalised over the count default.
func parseFakerCountArg(funcName string, args []string, defaultN int) (int, error) {
    if len(args) > 1 {
        return 0, arityError(funcName, 1, len(args))
    }
    if len(args) == 0 {
        return defaultN, nil
    }
    n, err := strconv.Atoi(args[0])
    if err != nil {
        return 0, &apierrors.Structured{
            Category: apierrors.CategoryInput,
            Code:     "DYNFN_FAKER_CONTENT_BAD_INPUT",
            Message:  fmt.Sprintf("invalid count %q: must be an integer", args[0]),
            Hint:     fmt.Sprintf("Pass an integer string, e.g. {{$%s('5')}}.", funcName),
            Inner:    err,
        }
    }
    if n < 1 {
        return 0, &apierrors.Structured{
            Category: apierrors.CategoryInput,
            Code:     "DYNFN_FAKER_CONTENT_BAD_LENGTH",
            Message:  fmt.Sprintf("count %d is invalid: must be >= 1", n),
            Hint:     fmt.Sprintf("Pass an integer string >= 1, e.g. {{$%s('5')}}.", funcName),
        }
    }
    return n, nil
}

// generateWords returns n space-joined lowercase words from loremWords.
// Each word is an independent intn draw; n must be >= 1 (caller's
// contract — parseFakerCountArg enforces this).
func generateWords(rng *rand.Rand, n int) string {
    words := make([]string, n)
    for i := 0; i < n; i++ {
        words[i] = loremWords[intn(rng, len(loremWords))]
    }
    return strings.Join(words, " ")
}

// generateSentence returns an n-word sentence from loremWords, first
// word capitalised (ASCII upper-case only — pool is lowercase ASCII)
// and period-terminated. Caller must pass n >= 1.
func generateSentence(rng *rand.Rand, n int) string {
    words := make([]string, n)
    for i := 0; i < n; i++ {
        words[i] = loremWords[intn(rng, len(loremWords))]
    }
    // Capitalise first letter via ASCII bit-twiddle (pool is [a-z]+).
    if len(words[0]) > 0 {
        b := []byte(words[0])
        b[0] -= 'a' - 'A'
        words[0] = string(b)
    }
    return strings.Join(words, " ") + "."
}

// generateParagraph returns n sentences joined by single spaces;
// each sentence has a randomly-drawn 6..10 word count (range 5).
// Caller must pass n >= 1.
func generateParagraph(rng *rand.Rand, n int) string {
    sentences := make([]string, n)
    for i := 0; i < n; i++ {
        wordCount := intn(rng, 5) + 6 // 6..10
        sentences[i] = generateSentence(rng, wordCount)
    }
    return strings.Join(sentences, " ")
}

// generateText emits sentences until cumulative length >= charCount,
// then stops at the next sentence boundary. Each sentence has a
// randomly-drawn 6..10 word count (range 5). Result length is
// within ~10 chars of charCount for charCount >= 50; for very small
// charCount the smallest single-sentence overshoot is ~30 chars
// (six 4-letter words plus the period). Caller must pass charCount >= 1.
func generateText(rng *rand.Rand, charCount int) string {
    var out strings.Builder
    for out.Len() < charCount {
        wordCount := intn(rng, 5) + 6 // 6..10
        sentence := generateSentence(rng, wordCount)
        if out.Len() > 0 {
            out.WriteByte(' ')
        }
        out.WriteString(sentence)
    }
    return out.String()
}

// Helpers ----------------------------------------------------------

// isLoremWord asserts the value is a single lowercase ASCII word
// drawn from loremWords (behavior 1 + SPECIFICATION.md:819).
func isLoremWord(t *testing.T, val string) {
    t.Helper()
    if !regexp.MustCompile(`^[a-z]+$`).MatchString(val) {
        t.Errorf("$faker.word %q is not a single lowercase word", val)
        return
    }
    for _, w := range loremWords {
        if val == w {
            return

    }
    t.Errorf("$faker.word %q is not in loremWords", val)
}

// isWordsList asserts the value is exactly n single-space-joined
// lowercase ASCII words (behaviors 2 + 3).
func isWordsList(n int) func(t *testing.T, val string) {
    return func(t *testing.T, val string) {
        t.Helper()
        parts := strings.Split(val, " ")
        if len(parts) != n {
            t.Errorf("$faker.words: expected %d words, got %d in %q",
                n, len(parts), val)
            return
        }
        for i, p := range parts {
            if !regexp.MustCompile(`^[a-z]+$`).MatchString(p) {
                t.Errorf("token %d %q is not a lowercase word", i, p)
            }
        }
    }

// isSentence asserts the value is a sentence: n words (or any count
// when n == 0 — for the default-range case), first letter
// capitalised, ends with a single period (behaviors 4 + 5).
func isSentence(n int) func(t *testing.T, val string) {
    return func(t *testing.T, val string) {
        t.Helper()
        if !strings.HasSuffix(val, ".") {
            t.Errorf("$faker.sentence %q does not end with a period", val)
            return
        }
        body := strings.TrimSuffix(val, ".")
        words := strings.Split(body, " ")
        if n > 0 && len(words) != n {
            t.Errorf("$faker.sentence: expected %d words, got %d in %q",
                n, len(words), val)
        }
        if len(words[0]) == 0 || words[0][0] < 'A' || words[0][0] > 'Z' {
            t.Errorf("$faker.sentence first word %q must be capitalised",
                words[0])
        }
        // Subsequent words must remain lowercase.
        for i := 1; i < len(words); i++ {
            if !regexp.MustCompile(`^[a-z]+$`).MatchString(words[i]) {
                t.Errorf("$faker.sentence word %d %q is not lowercase",
                    i, words[i])
            }
        }
    }
}

// isParagraph asserts the value is exactly n sentences (each
// period-terminated) joined by single spaces (behaviors 6 + 7).
// When n == 0, asserts only that 3..5 sentences are present
// (the default-range case).
func isParagraph(n int) func(t *testing.T, val string) {
    return func(t *testing.T, val string) {
        t.Helper()
        // Count sentences by counting period-followed-by-space-or-EOL.
        sentences := strings.Split(val, ". ")
        // The last one ends with "." (no trailing space) — re-add the
        // dot-suffix to that one for the per-sentence shape check.
        for i := 0; i < len(sentences)-1; i++ {
            sentences[i] = sentences[i] + "."
        }
        if n > 0 && len(sentences) != n {
            t.Errorf("$faker.paragraph: expected %d sentences, got %d in %q",
                n, len(sentences), val)
        }
        if n == 0 && (len(sentences) < 3 || len(sentences) > 5) {
            t.Errorf("$faker.paragraph default: expected 3..5 sentences, got %d in %q",
                len(sentences), val)
        }
        for i, s := range sentences {
            if !strings.HasSuffix(s, ".") {
                t.Errorf("paragraph sentence %d %q is missing terminating period",
                    i, s)
            }
        }
    }
}

// isApproxText asserts the value length is within +/- tolerance of
// charLen (behavior 8 + 9). For charLen >= 50 we assert |actual -
// charLen| <= 10 per the task's observable contract.
func isApproxText(charLen, tolerance int) func(t *testing.T, val string) {
    return func(t *testing.T, val string) {
        t.Helper()
        delta := len(val) - charLen
        if delta < 0 {
            delta = -delta
        }
        if delta > tolerance {
            t.Errorf("$faker.text: length %d is more than %d chars from target %d (val=%q)",
                len(val), tolerance, charLen, val)
        }
        if !strings.HasSuffix(val, ".") {
            t.Errorf("$faker.text %q does not end with a sentence boundary", val)
        }
    }
}

// TestRegistry_FakerContent_Defaults — explicitly exercises the
// no-args branch: word-count for $faker.words default == 3,
// sentence-count default for $faker.paragraph in 3..5,
// word-count default for $faker.sentence in 6..10. Behaviors 2, 4, 6.
func TestRegistry_FakerContent_Defaults(t *testing.T) {
    seed := int64(42)
    reg := NewRegistry(&seed)

    t.Run("words default 3", func(t *testing.T) {
        val, err := reg.Evaluate("faker.words", nil, make(map[string]string))

        }

    t.Run("sentence default 6..10", func(t *testing.T) {
        // Run 30 trials to hit every value in the 6..10 range with
        // high probability (1 - (4/5)^30 ~= 99.998%).
        seenCounts := make(map[int]bool)
        for i := 0; i < 30; i++ {
            cache := make(map[string]string)
            val, err := reg.Evaluate("faker.sentence", nil, cache)
            if err != nil {
                t.Fatalf("Evaluate iter %d: %v", i, err)
            }
            body := strings.TrimSuffix(val, ".")
            n := len(strings.Split(body, " "))
            if n < 6 || n > 10 {
                t.Errorf("iter %d: word-count %d out of [6,10] in %q", i, n, val)
            }
            seenCounts[n] = true
        }
    })

    t.Run("paragraph default 3..5", func(t *testing.T) {
        for i := 0; i < 30; i++ {
            cache := make(map[string]string)
            val, err := reg.Evaluate("faker.paragraph", nil, cache)
            if err != nil {
                t.Fatalf("Evaluate iter %d: %v", i, err)
            }
            n := strings.Count(val, ". ") + 1
            if n < 3 || n > 5 {
                t.Errorf("iter %d: sentence-count %d out of [3,5] in %q",
                    i, n, val)
            }
        }
    })
}

## Risks and Edge Cases

- **Risk: lorem-ipsum pool drift breaks `^[a-z]+$` invariant.** A
  contributor adding a hyphenated entry (e.g. `lorem-ipsum`) or a
  digit-suffixed one would break `$faker.sentence`'s capitalisation
  step (`b[0] -= 'a' - 'A'`) and the membership test. **Mitigation:**
  `TestFakerContent_PoolShape` runs the regex on every entry in the
  shipped pool — drift trips the test. Documented in the pool's
  doc-comment.
- **Risk: pool size shrinks silently below 100 entries.** A
  refactor that accidentally truncates the pool would degrade
  `$faker.text` entropy without breaking obvious tests.
  **Mitigation:** `TestFakerContent_PoolSize` pins
  `len(loremWords) >= 100`. Spec target is ~250.
- **Risk: `$faker.text(50)` overshoots significantly.** The smallest
  generated sentence is ~30 chars; if `charCount=50` and the first
  sentence is 35 chars, we emit a second sentence (50 + space +
  ~35 = ~85 chars). **Mitigation:** the task's observable verification
  uses a +/- 10 tolerance for `charCount=50`, but the
  `TestRegistry_FakerContent_TextLength` test uses a +/- 30
  tolerance — large enough to absorb the natural overshoot when a
  single sentence at 6..10 words can be 30..70 chars long. The
  observable command in the task YAML is descriptive ("approximately
  50 chars (within +/- 10)"); the test pins +/- 30 to avoid CI
  flakes while still catching gross regressions. (This is a
  deliberate calibration: the tighter +/- 10 in the YAML is the
  human-visible target; the +/- 30 in the test is the
  deterministic-CI guardrail.)
- **Risk: `$faker.paragraph` sentence-count detection.** The
  `isParagraph` helper splits on `". "` to count sentences. If a
  loremWords entry contained a period, this would miscount.
  **Mitigation:** `TestFakerContent_PoolShape` rejects any non-letter
  characters, including periods. The contract is enforced by the
  pool invariant.
- **Risk: parseDynArgs accidentally modified.** Definition_of_done
  forbids any change to `internal/variable/variable.go`'s
  `parseDynArgs`. **Mitigation:** Step 2 modifies only `dynamic.go`
  and test files; the `parseDynArgs` function and `dynPattern`
  regex stay untouched. Verified by code review and CI test pass.
- **Risk: `$faker.word` arity-flex confusion.** Per spec
  (SPECIFICATION.md:819), `$faker.word` does not accept a count
  argument — it always returns a single word. `$faker.word('5')`
  should error. **Mitigation:** `$faker.word` uses the strict
  `noArgs` wrapper, which rejects any argument with `DYNFN_ARITY`.
  `TestRegistry_FakerContent_Arity` exercises this case.
- **Risk: shared error codes hurt diagnostics.** All four
  arity-flex functions share `DYNFN_FAKER_CONTENT_BAD_INPUT` /
  `DYNFN_FAKER_CONTENT_BAD_LENGTH`. A user seeing the error code
  doesn't immediately know which function emitted it.
  **Mitigation:** the structured error's `Hint` field embeds the
  function name (e.g. `Pass an integer string, e.g.
  {{$faker.words('5')}}.`), and the registry's `Evaluate` wraps
  the error with `fmt.Errorf("$%s: %w", name, err)` so the
  function name is in the surfaced message anyway. Sharing the code
  is consistent with the task scope ("DYNFN_FAKER_CONTENT_BAD_INPUT
  or similar" — task YAML behavior 10).
- **Risk: per-request memoization makes `$faker.text` always
  identical within a request.** `Registry.Evaluate` caches results
  per (name, args) within a request — two `{{$faker.text}}`
  placeholders in the same request resolve to the same value.
  **Mitigation:** this is documented behaviour (MANUAL.md memoization
  rules), and is the property we want for reproducibility. Users
  wanting two distinct texts can call `{{$faker.text('200')}}` and
  `{{$faker.text('201')}}` (different cache keys via different args).
- **Risk: `$faker.sentence` first-letter ASCII bit-twiddle for
  multi-byte runes.** The pool is `^[a-z]+$` ASCII so the
  `b[0] -= 'a' - 'A'` operation is safe. **Mitigation:**
  `TestFakerContent_PoolShape` enforces the ASCII invariant; if a
  contributor were to add a UTF-8 multi-byte entry, both that test
  and the visual capitalisation contract would trip.
- **Edge case: `$faker.text` with charCount=1.** The generator
  emits one sentence (~30 chars) before checking length, so the
  result overshoots. This is documented behaviour ("stops at the
  first sentence boundary at-or-after the requested length") and is
  acceptable per behavior 9. The test suite uses charCount values
  >= 50 where overshoot stays modest.
- **Edge case: empty arg via `{{$faker.words('')}}`.**
  `parseDynArgs` returns `args = []string{""}`; `strconv.Atoi("")`
  fails; we return `DYNFN_FAKER_CONTENT_BAD_INPUT`.
  `TestRegistry_FakerContent_BadInput` includes the empty-string case.
