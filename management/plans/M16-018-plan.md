## Open Decisions Resolved Up-Front

- **Exit code on gate failure.** The task observable says "exit code 5"; the spec at line 5691 also says "exit code 5". However the existing CLI uses **exit code 6** uniformly for `auth.GateError` (see `cmd/apitest/main.go:1374`, `1148-1170`, `1241-1248`, `3543`; spec line 5223 and 5501 also explicitly state "Exit code: 6 (feature gate)"). The existing test `TestRunCmd_TeamSecrets_FreeTierBlocked` at `cmd/apitest/run_test.go:648` asserts `code == 6`. I'm building **exit code 6** because (a) the test fixture is the strongest source of truth, (b) re-routing one feature gate to a different exit code would be a regression in the CLI's exit-code contract, and (c) spec internally contradicts itself between line 5223/5501 (says 6) and line 5691 (says 5). The plan's observable verification reflects this — the CLI emits the standard `feature_gated` error and exits with code 6. I'll flag this in the task verification report so the human can revise the spec.
- **OrgID source.** `Claims` (in `internal/license/jwt.go`) has no `org_id` field today, but the spec (line 8129) lists it as a License JWT claim. The plan adds `OrgID string \`json:"org_id,omitempty"\`` to `license.Claims` and resolves it via `license.ParseToken(rec.AccessToken).Claims.OrgID`. When OrgID is empty (e.g. free-tier user), `GetTeamVault` is skipped — the team-vault cache simply isn't fetched.
- **Cache template payload shape.** The backend GET returns `{template (string YAML), version (int), updated_at, updated_by_email}`. The cache envelope per spec line 5695 is `{fetched_at (unix int), version (int), template (object)}`. The cache stores `template` as the **raw YAML string** (not parsed) because the CLI parses it on every load via the existing `teamtemplate.Parse` — keeping it as a string preserves comments and avoids round-trip ambiguity. The JSON field is named `template` for spec-fidelity.
- **Overlay precedence.** Spec line 5701-5703: "1) backend cache (base), 2) `APITEST_TEAM_CONFIG` (overlay; per-key merge — local file's keys replace backend's at the same path), 3) `--team-vault-key key=value` flags." The plan ships (1) + (2) only; (3) is out of scope. Overlay is done at the `TeamTemplate` level by merging environment-by-environment, key-by-key (local wins on collision).
- **`apitest license --refresh` integration.** Spec line 5711: "implicit `GET /api/v1/organizations/{orgId}/vault-config` after `/auth/refresh` — Single round-trip refresh of all org-scoped state." After the existing refresh path succeeds, the new code attempts `GetTeamVault` and writes the cache. Failure is non-fatal and a stderr warning surfaces (the refresh itself remains exit 0). Network/server errors here do **not** override the refresh exit code.
- **Worker integration.** Spec line 6044: "On startup, the worker fetches `/api/v1/organizations/{orgId}/vault-config` and caches the template per the standard 5-minute TTL." The plan adds `--refresh-vault` parsing to `apitest worker` and wires it through to the same fetch helper. The schedule-pull worker is the surface that benefits (since it executes collections); coordinator-mode workers don't run collections in-process and don't need it. We add the flag to both paths but wire the fetch only into the schedule-pull setup.
- **Cache file mode.** `0600` per the JWKS-cache precedent. `~/.config/apitesttool/` is `0700` per `backend.RefreshTokens` line 43.
- **Flock reuse.** The lock file is the same `refresh.lock` that the License-JWT refresh uses; spec line 5697 explicitly calls this out as the intended behavior so concurrent CI workers don't trample each other.
- **Stale-while-revalidate timing.** "≤2s blocking" per the task — we set a 2-second timeout context around the fetch. On timeout we return the stale cache and emit a stderr warning. On 5-min freshness we never touch the network. On stale + reachable we fetch in foreground (no goroutine — keeps the lifecycle predictable). On stale + unreachable we use the stale cache with a warning.

```go
// internal/backend/teamvault.go (new)
package backend

import (
    "context"
    "errors"
    "fmt"
    "net/http"
)

// ErrTeamVaultNotFound is returned when the backend has no vault-config row for
// the given orgId (HTTP 404). Callers treat this as "team vault not provisioned
// yet" — not an error to surface to the user.
var ErrTeamVaultNotFound = errors.New("backend: team vault not configured for organization")

// TeamVaultResponse is the decoded body of GET /api/v1/organizations/{orgId}/vault-config.
// The Template field is the raw YAML string the backend stored; the CLI parses
// it via teamtemplate.Parse downstream.
type TeamVaultResponse struct {
    Template       string `json:"template"`
    Version        int64  `json:"version"`
    UpdatedAt      string `json:"updated_at,omitempty"`
    UpdatedByEmail string `json:"updated_by_email,omitempty"`
}

// GetTeamVault fetches the Team-tier shared vault configuration for orgId.
// Returns ErrTeamVaultNotFound on 404; passes other transport/problem-details
// errors through unchanged so callers can errors.Is/As them with the existing
// sentinels (ErrNetworkFailure, ErrServerError, *ProblemDetails).
func (c *Client) GetTeamVault(ctx context.Context, orgId, accessToken string) (*TeamVaultResponse, error) {
    if orgId == "" {
        return nil, errors.New("backend: orgId is required")
    }
    path := fmt.Sprintf("/api/v1/organizations/%s/vault-config", orgId)
    var out TeamVaultResponse
    err := c.GetJSON(ctx, path, accessToken, &out)
    if err != nil {
        var pd *ProblemDetails
        if errors.As(err, &pd) && pd.Status == http.StatusNotFound {
            return nil, ErrTeamVaultNotFound
        }
        return nil, err
    }
    return &out, nil
}
```

```go
package teamtemplate

import (
    "context"
    "encoding/json"
    "errors"
    "fmt"
    "os"
    "path/filepath"
    "time"

    "github.com/gofrs/flock"
)

// CacheTTL is the default freshness window. 5 minutes per SPECIFICATION.md:5696.
const CacheTTL = 5 * time.Minute

// FetchTimeout caps a foreground stale-while-revalidate fetch. Per task: "≤2s blocking".
const FetchTimeout = 2 * time.Second

// cacheFileName is the on-disk envelope per SPECIFICATION.md:5695.
const cacheFileName = "team_vault.json"

// lockFileName re-uses the License-JWT refresh lock per SPECIFICATION.md:5697.
const lockFileName = "refresh.lock"

// CacheEnvelope mirrors the JSON shape stored on disk per SPECIFICATION.md:5695.
type CacheEnvelope struct {
    FetchedAt int64  `json:"fetched_at"`
    Version   int64  `json:"version"`
    Template  string `json:"template"` // raw YAML — parsed by teamtemplate.Parse downstream
}

// Fetcher is the minimal contract the cache requires of its backend client.
// Decouples this package from internal/backend to keep tests hermetic.
type Fetcher interface {
    GetTeamVault(ctx context.Context, orgId, accessToken string) (*FetchResult, error)
}

// FetchResult is the cache-layer view of a transport response.
type FetchResult struct {
    Template string
    Version  int64
}

// Cache wraps the on-disk team_vault.json envelope and the refresh lock.
type Cache struct {
    cfgDir string
    now    func() time.Time
}

// NewCache constructs a Cache rooted at cfgDir (typically ~/.config/apitesttool).
func NewCache(cfgDir string) *Cache {
    return &Cache{cfgDir: cfgDir, now: time.Now}
}

// Read returns the on-disk envelope, or (nil, os.ErrNotExist) when absent.
func (c *Cache) Read() (*CacheEnvelope, error) {
    data, err := os.ReadFile(filepath.Join(c.cfgDir, cacheFileName))
    if err != nil {
        return nil, err
    }
    var env CacheEnvelope
    if err := json.Unmarshal(data, &env); err != nil {
        return nil, fmt.Errorf("decode team_vault.json: %w", err)
    }
    return &env, nil
}

// Write persists env to disk with mode 0600. Atomic via os.Rename of a temp file.
func (c *Cache) Write(env *CacheEnvelope) error { /* mkdir 0700; atomic write 0600 */ }

// Load returns a fresh-enough template, fetching when necessary per task
// stale-while-revalidate semantics:
//   - no cache + refresh=true OR force=true => fetch under flock; persist; return
//   - cache age < TTL                     => return cached; no network
//   - cache stale, fetcher reachable      => fetch (≤2s, under flock); persist; return new
//   - cache stale, fetcher unreachable    => return cached with warning sentinel
//   - no cache + fetcher unreachable      => return nil + the underlying error
//
// warnW receives a one-line stderr message when stale-cache is served (nil to discard).
func (c *Cache) Load(ctx context.Context, fetcher Fetcher, orgId, accessToken string, force bool, warnW io.Writer) (*CacheEnvelope, error) { /* ... */ }

// Refresh always fetches (TTL-bypass) and persists. Used by --refresh-vault and
// by apitest license --refresh after a successful /auth/refresh round-trip.
// Errors are non-fatal for the caller — they may proceed with whatever cache
// exists; warnW receives the error message.
func (c *Cache) Refresh(ctx context.Context, fetcher Fetcher, orgId, accessToken string, warnW io.Writer) error { /* ... */ }

// lock acquires the shared refresh.lock with a bounded timeout matching
// backend.DefaultLockTimeout. Returns a release function or an error.
func (c *Cache) lock(ctx context.Context) (release func(), err error) { /* flock.New + TryLockContext */ }
```

## Risks and Edge Cases

- **Risk: License JWT lacks `org_id` (free-tier user / older issuer).** → **Mitigation:** Loader treats empty `OrgID` as "skip backend fetch". The local `APITEST_TEAM_CONFIG` path remains available, gated as today. Free-tier users with no local file get no template — same as today.
- **Risk: Backend returns a stale-cache 304 with no body.** → **Mitigation:** `GetTeamVault` uses `GetJSON` (not `GetJSONOptional`). The backend's `BuildGetResponse` writes 304 only when `If-None-Match` matches; the CLI doesn't send `If-None-Match` in this slice, so 304 is unreachable. If a future slice adds ETag, we'll move to `GetJSONOptional` and treat 204/304 as "use existing cache."
- **Risk: Concurrent refresh thrash on a cold cache (10 CI workers, no `team_vault.json` yet).** → **Mitigation:** The shared `refresh.lock` serializes them. After the first writer persists, the rest fall through the "ttl_hit" path on their next iteration. Test: `TestCache_Concurrent_OneNetworkCallUnderFlock` mirrors `TestRefreshTokens_Concurrent_OnlyOneNetworkCall`.
- **Risk: Cache file corruption (manual edit, partial write).** → **Mitigation:** `Cache.Read` returns the JSON-decode error; `Cache.Load` treats this as "no cache" and refreshes. Atomic write via `os.Rename` of a temp file in the same dir prevents partial writes.
- **Edge case: `team_vault.json` exists but the user downgraded.** This is the revenue-leak case in the task observable. The loader runs `Load` → cache produces a template → gate fires because `tier=free` and no trial. Exit code 6.
- **Edge case: `APITEST_TEAM_CONFIG` set, cache present, free tier, no trial.** Both sources contribute; loader merges; gate fires on the merged result. Exit code 6.
- **Edge case: Fetch returns 402 Payment Required (tier downgrade detected server-side).** Returns a `*ProblemDetails` to `Cache.Refresh`. Refresh logs a warning, leaves the existing cache untouched. The next `Cache.Load` call serves the stale cache and the load-site gate then catches the tier mismatch. Net effect: clean exit 6 with the correct GateError message, regardless of which side noticed first.
- **Edge case: `apitest license --refresh` succeeds but team-vault fetch fails.** Non-fatal: the License JWT refresh has already succeeded; we don't penalise the user. Stderr warning is emitted. Exit code remains 0.
- **Edge case: Path traversal in `orgId`.** `org_id` is sourced from a signed JWT claim, not user input, so injection is bounded. We still escape via `fmt.Sprintf("/api/v1/organizations/%s/vault-config", orgId)` — orgId is a UUID-shaped string per spec. We do not URL-encode; the orgId is hex+dashes only. Add a basic regex check in `GetTeamVault` similar to `featureSlugRE`: `^[a-zA-Z0-9_-]+$`.
- **Edge case: Cache file written by an older CLI version (missing `version` field).** `CacheEnvelope` field decode: `version` defaults to 0. Cache logic treats version=0 as "no version" — refresh on next stale check produces a real version. Forward-compatible.
