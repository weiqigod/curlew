### Step 4: Update CLI gate tests (two inversions)

**Rationale:** Both `TestRunFromCommand_gate_returns_exit_6` and
`TestRunFromCommand_gate_json_returns_exit_6` at `cmd/apitest/main_test.go:5749`
and `:5772` will fail post-Step-2: at default Free tier the run no longer
gates, so it tries to perform an HTTP request to `https://httpbin.org/get`
which is forbidden in unit tests (and slow / flaky). We replace each with a
test that:

(a) confirms the gate is **no longer** triggered at Free tier — exit code
≠ 6 and no `feature_gated` token in any output, and

(b) does not depend on real network. The simplest approach is to point the
URL at a local httptest server inside the test (mirroring the runner-level
pattern) — but `captureRun` invokes the binary via main, which runs the
real HTTP client. Two lower-touch options:

1. Use `127.0.0.1:1` (localhost, port 1) — guaranteed connect-refused; exit
   code 4 (execution error) on Free tier, **not** 6. We assert `exitCode != 6`
   and `! strings.Contains(stdout, "feature_gated")`.

2. Spin up an `httptest.NewServer` in the test, pass its `.URL` into the
   collection YAML. Cleaner, self-contained, exit 0.

Option 2 is preferred — it gives us a positive happy-path assertion (exit
0) and keeps the test fully hermetic. Option 1 is the fallback if any
captureRun harness specific to these tests resists URL substitution.

**Decision recorded:** use Option 2 (httptest server). Each subtest stands
up a local server that returns 200 OK, writes the YAML pointing the request
URL at the server's URL, runs the binary, asserts exit 0 (text variant) or
asserts exit 0 + valid JSON without `feature_gated` (JSON variant).

```go
func TestRunFromCommand_at_free_tier_no_longer_gated(t *testing.T) {
    srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, _ *http.Request) {
        w.WriteHeader(http.StatusOK)
    }))
    t.Cleanup(srv.Close)

    tmpDir := t.TempDir()
    col := filepath.Join(tmpDir, "col.yaml")
    body := fmt.Sprintf(`name: free tier from_command
variables:
  secret:
    from_command: "echo secret123"
requests:
  - name: test
    request:
      method: GET
      url: "%s/{{secret}}"
`, srv.URL)
    if err := os.WriteFile(col, []byte(body), 0o644); err != nil {
        t.Fatal(err)
    }

    stdout, stderr, exitCode := captureRun(t, "run", col)
    if exitCode == 6 {
        t.Errorf("exit code = 6 (gated); want non-gate; stderr: %s", stderr)
    }
    if exitCode != 0 {
        t.Errorf("exit code = %d, want 0; stderr: %s", exitCode, stderr)
    }
    if strings.Contains(stdout, "feature_gated") {
        t.Errorf("stdout %q unexpectedly contains 'feature_gated'", stdout)
    }
}
```

```bash
echo ""
echo "--- from_command at Free tier (M15-003: now allowed at every tier) ---"
FROM_CMD_DIR="$(mktemp -d)"
trap 'rm -rf "$FROM_CMD_DIR"' EXIT
cat > "$FROM_CMD_DIR/from_cmd.yaml" <<'YAML'
name: from_command-free-tier
variables:
  GREETING: { from_command: "echo hello-from-free-tier" }
requests:
  - name: echo-back
    request:
      method: GET
      url: "https://httpbin.org/get?msg={{GREETING}}"
YAML

set +e
"$BINARY" run "$FROM_CMD_DIR/from_cmd.yaml" >"$FROM_CMD_DIR/out.txt" 2>&1
FROM_CMD_EXIT=$?
set -e

if [ "$FROM_CMD_EXIT" -eq 0 ]; then
  echo "PASS: from_command runs at Free tier (exit 0)"
elif grep -q "Solo tier" "$FROM_CMD_DIR/out.txt"; then
  echo "FAIL: from_command still gated at Free tier (output mentions 'Solo tier')"
  cat "$FROM_CMD_DIR/out.txt"
  exit 1
else
  # Network flakiness against httpbin.org should not fail this test as a
  # tier-gating regression; it is a smoke for tier-gating, not for httpbin.
  # We accept exit codes that indicate execution-time problems (4) but
  # explicitly reject exit 6 (feature_gated).
  if [ "$FROM_CMD_EXIT" -eq 6 ]; then
    echo "FAIL: from_command at Free tier returned exit 6 (still gated)"
    cat "$FROM_CMD_DIR/out.txt"
    exit 1
  fi
  echo "SKIP: from_command exited $FROM_CMD_EXIT (network or upstream issue, not tier gate)"
fi
unset FROM_CMD_DIR FROM_CMD_EXIT
trap - EXIT
```

The smoke contract is "no longer exit 6 at Free tier"; HTTP-level flakiness
against `httpbin.org` is not the property under test. The block tolerates
network errors but refuses an exit-6 regression — exactly what M15-003
must guarantee.
