### F5 — Blast radius is confined to `internal/schema` and editors

Only call sites of `schema.CollectionSchema` / `schema.ProjectSchema`:

- `cmd/curlew/main.go:2655,2657` — `schemaCmdOut`, prints bytes.
- `internal/schema/*_test.go` — tests.

`curlew validate` uses `internal/validator` (`main.go:2268`, `validator.ValidateAuto`), not the JSON Schema. The parser uses plain `yaml.Unmarshal` (`parser.go:171`) — **non-strict**, so unknown keys are silently ignored at parse time. `smoke/run.sh:1098-1105` only asserts the output is valid JSON. **No runtime behaviour changes.**

### F6 — Governing principle for every new fragment

Because the parser ignores unknown keys and the schema is the *only* place a typo is flagged, `additionalProperties: false` is the schema's entire value proposition and **must be kept** (MANUAL §1.5 advertises it; `TestProjectSchema/additional_properties_false` asserts it; `CLI_SPECIFICATION.md:335-338` states it is deliberate). Keeping it makes the parity test mandatory, not optional.

The corollary constraint: **the schema must never be stricter than the parser.** Every `minimum`, `minLength`, `enum`, and `required` below was checked against the parser's actual validation. Concretely rejected as over-strict:

- `if: { minLength: 1 }` — no parse-time non-empty check exists (`runner.go:1789` and `validator.go:334` only guard `item.If != ""`).
- `heartbeat.interval_ms: { minimum: 1 }` — `parser.go:481` errors only when `Enabled && IntervalMs <= 0`; `interval_ms: 0` with `enabled: false` is valid.
- `websocketStep.count: { minimum: 1 }` — `parser.go:308` rejects only `Count < 0`.
- `signing.type: { enum: [...] }` — `signer.Register` is exported, `Registry` has no `Names()` lister, and an unknown type is a clean runtime error (`signer.go:91-94`). An enum here would be a new drift surface of exactly the kind this task exists to kill. Use `minLength: 1` (the parser *does* reject empty: `collection.go:73-75`).

Enums **are** used where the parser itself enforces a closed set: `protocol` (`parser.go:430`), websocket `action` (`parser.go:450`), `reconnect.backoff` (`parser.go:470`), `graphql.error_handling` (`parser.go:506`). Note `error_handling` accepts **fail | warn | ignore** — three values — even though the struct comment (`collection.go:586`) and `CLI_SPECIFICATION.md:1204` say two.

#### Design

Package `schema_test` (external test package, already used by `validate_test.go`). Import cycle check: `internal/parser` does **not** import `internal/schema` (its imports are assertion, errors, graphql/files, httpbody, websocket/templates, datadriven, output, retry, variable) — safe.

**Walker rules** (mirroring `gopkg.in/yaml.v3`):

- Deref `*T`, `[]T`, `[N]T` to the element type.
- Unexported fields are invisible to yaml.v3 → skipped (e.g. `SigningSpec.explicitNull`).
- `yaml:"-"` → skipped (`ExternalFiles`, `SourceFile`, `SourceLine`, `Slug`, `CompiledSchema`, `BodyFileContent`, `BodyBinaryFileContent`, `BodyFileContentType`).
- Tag options after the first comma (`omitempty`, `flow`) are stripped; `,inline` recurses and merges into the parent key set.
- Empty tag name → `strings.ToLower(field.Name)`.
- Map- and `any`-typed fields contribute their key only; the walk does not descend into them.
- Types whose YAML form is a free-form map or a scalar/sequence union are **opaque**: the walk stops, and the schema describes them without per-field `properties`.

```go
// yamlKeys returns the set of YAML mapping keys gopkg.in/yaml.v3 binds for t.
// Pointers, slices and arrays are dereferenced to their element type.
func yamlKeys(t *testing.T, typ reflect.Type) map[string]bool {
	for typ.Kind() == reflect.Pointer || typ.Kind() == reflect.Slice || typ.Kind() == reflect.Array {
		typ = typ.Elem()
	}
	keys := map[string]bool{}
	if typ.Kind() != reflect.Struct {
		t.Fatalf("yamlKeys: %s is not a struct", typ)
	}
	for i := 0; i < typ.NumField(); i++ {
		f := typ.Field(i)
		if f.PkgPath != "" { // unexported: invisible to yaml.v3
			continue
		}
		name, opts := splitYAMLTag(f)
		if name == "-" {
			continue
		}
		if opts["inline"] {
			if f.Type.Kind() == reflect.Map {
				t.Fatalf("yamlKeys: inline map on %s.%s is not modelled", typ, f.Name)
			}
			for k := range yamlKeys(t, f.Type) {
				keys[k] = true
			}
			continue
		}
		if name == "" {
			name = strings.ToLower(f.Name)
		}
		keys[name] = true
	}
	return keys
}

func splitYAMLTag(f reflect.StructField) (string, map[string]bool) {
	parts := strings.Split(f.Tag.Get("yaml"), ",")
	opts := make(map[string]bool, len(parts))
	for _, o := range parts[1:] {
		opts[o] = true
	}
	return parts[0], opts
}
```

**JSON-pointer-ish resolver** (numeric segments index arrays, so `oneOf` branches are addressable):

```go
// schemaObjectAt resolves a slash-separated path inside the decoded schema.
// "" is the document root; a numeric segment indexes a JSON array.
func schemaObjectAt(t *testing.T, doc map[string]any, path string) map[string]any {
	cur := any(doc)
	if path != "" {
		for _, seg := range strings.Split(path, "/") {
			switch node := cur.(type) {
			case map[string]any:
				next, ok := node[seg]
				if !ok {
					t.Fatalf("schema path %q: no key %q", path, seg)
				}
				cur = next
			case []any:
				i, err := strconv.Atoi(seg)
				if err != nil || i >= len(node) {
					t.Fatalf("schema path %q: bad array index %q", path, seg)
				}
				cur = node[i]
			default:
				t.Fatalf("schema path %q: %q is not traversable", path, seg)
			}
		}
	}
	m, ok := cur.(map[string]any)
	if !ok {
		t.Fatalf("schema path %q is not an object", path)
	}
	return m
}
```

## Risks and Edge Cases

- **Risk: the schema ends up stricter than the parser somewhere, reintroducing the bug this task fixes.** → **Mitigation:** the governing rule in F6, applied field by field. The four constraints explicitly rejected as over-strict (`if.minLength`, `heartbeat.interval_ms.minimum`, `count.minimum`, `signing.type.enum`) are each traced to a parser line. `TestSchema_examples` re-validates every fixture, and Step 6's fixtures cover the boundary values (`count: 0`, no `method:`, `signing: ~`, `query_file` without `query`).
- **Risk: `"type": ["object", "null"]` on `$defs/signing` is mishandled by an editor.** → **Mitigation:** it is plain Draft 2020-12 (`required`/`properties`/`additionalProperties` apply to object instances only), supported by both `santhosh-tekuri/jsonschema/v6` (the test compiler) and `redhat.vscode-yaml`'s ajv-based validator. `TestSchema_accepts_null_signing` pins both levels. Fallback if an editor misbehaves: `{"oneOf": [{"$ref": "#/$defs/signing"}, {"type": "null"}]}` at each use site.
- **Risk: `$id` still 404s after the change.** → **Mitigation:** the org and branch are verified from `git remote -v` and `origin/HEAD -> origin/main`, but resolution also requires the repo to be public. Verify with `curl -sI https://raw.githubusercontent.com/weiqigod/curlew/main/schemas/collection-v1.json` **after pushing**. If it 404s because the repo is private, MANUAL §1.5's second snippet must say so rather than offering a dead URL — and `.markdown-link-check.json` will flag it in CI either way.
- **Risk: the duplicated `$defs.config` drifts between the two files.** → **Mitigation:** `TestSchema_config_defs_match`, semantically identical to the `$defs.output` guard that has held since M8-003. Cross-file `$ref` is rejected because it would force editors to fetch the `$id` URL.
- **Risk: the reflection walker mismodels a yaml.v3 rule.** → **Mitigation:** the walker `t.Fatal`s on the one case it does not model (`,inline` on a map field — none exist today), and the four hand-rolled decoders are handled by explicit key lists pinned to source by `go/ast`. The `yaml:"-,"` form (literal `-` key) is not modelled and does not appear in the codebase.
- **Risk: the `go/ast` guards break on an unrelated refactor of `UnmarshalYAML`.** → **Mitigation:** helpers fail with the receiver and method name in the message, so the fix is obvious. They read only `CaseClause` string literals inside a named method — stable under renames of locals, reordering, and added branches.
- **Risk: the DoD item "a test fails if the committed schema files drift from `curlew schema` output" is signed off on a tautology.** → **Mitigation:** state it in the CHANGELOG and the verification report. `TestSchema_published_path_matches_embed` already satisfies the literal wording; the parity test is what actually prevents recurrence. Do not add a second tautological test.
- **Edge case: `signing: ~` at collection level.** The parser leaves `Collection.Signing` nil (no custom `UnmarshalYAML` on `Collection`, so yaml.v3 skips the pointer) and treats it as "no default" — it is silently accepted. `"type": ["object","null"]` accepts it at both levels. **Handling:** covered by `TestSchema_accepts_null_signing/null at collection level`.
- **Edge case: `assertions.cel` mapping entry carrying an operator key.** The parser rejects it with `ErrCelAndOperatorMutuallyExclusive` (`collection.go:423-428`); `additionalProperties: false` on the mapping branch of `$defs/celAssertions` matches exactly. **Handling:** negative control row `cel entry with operator key`.
- **Edge case: a WebSocket `expect` step's `message:` is a `BodyAssertions` map while a `send` step's is a literal JSON object.** Both are JSON objects, so one `{"type": "object"}` covers the overload without an `if`/`then` on `action`. **Handling:** the `gap_12` fixture uses both forms in one steps list.
- **Edge case: external request files (§5.2) have no published schema.** A user who maps `yaml.schemas` at `requests/**/*.yaml` gets errors on every file (no `name`+`requests` root). Out of scope; MANUAL §1.5's rewritten caveat says so explicitly.
- **Edge case: `curlew.yaml`'s `defaults:`, `secrets:`, `auth_profiles:` are untyped `{"type": "object"}`.** The project parity test compares root property *names* only, so those stay permissive. Typing them is a separate task.
