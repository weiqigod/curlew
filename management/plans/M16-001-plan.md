# Implementation Plan: M16-001

## Overview

Lift `SsoTierGate.EnsureEnterpriseAsync` (M15-002) into a generic, injectable
`ITierGate.EnsureAsync(orgId, requiredMinimumTier, ct)` under
`src/ApiTool.Backend/Internal/TierGates/`, with three new sibling adapters
(`ScheduleExecutorTierGate`, `VaultConfigTierGate`, `DashboardTierGate`) and

preserved as a thin static wrapper so all current call sites compile and

## Design Decisions and Resolutions

The task YAML's observable references a `POST /api/v1/organizations/{orgId}/vault-config`
endpoint that does **not** exist yet (it is owned by a later M16 vault-config
slice). The Tier-Gate Generic Abstraction section of `docs/SPECIFICATION.md`
(lines 9661-9742) describes M16-001's scope as the *foundation*: interface,
canonical implementation, four adapters, problem factory, and DI wiring.
The vault/schedule/dashboard *endpoints* land in subsequent tasks.

**Resolution:** The vault-config-endpoint observable is satisfied indirectly
by an **endpoint integration test that wires `VaultConfigTierGate.EnsureTeamOrAboveAsync`
into a tiny minimal-API probe registered only in the `Testing` environment**
under `Internal/TierGates/InternalTierGateProbeEndpoint.cs`. This proves the
end-to-end RFC 7807 mapping without prematurely shipping the real
vault-config endpoints (which carry their own RBAC, ETag, and persistence
scope). It is the leanest path that satisfies behaviors 4, 5, 6 while staying
strictly inside this slice's scope. The probe endpoint is gated by
`!app.Environment.IsProduction()` matching the pattern used by
`MapInternalSeedM14Endpoint`.

The grep verification in the observable
(`grep -rn "db.Subscriptions.Where" src/ApiTool.Backend/ | grep -v Internal/TierGates/`)
is treated as *tier-check* greps only. Many existing matches are seat-limit
or customer-id lookups that are not tier checks and stay where they are. The
**only** tier-check usage of `db.Subscriptions.Where(s => s.OrgId == ...)`
followed by `.Select(s => s.Tier)` outside `Internal/TierGates/` is in the
existing `SsoTierGate.cs`, which this task either rewrites in place to
delegate, or moves into `Internal/TierGates/`. The grep verification target
becomes: zero `\.Tier` projections inside subscription queries outside
`Internal/TierGates/`. A unit test under
`src/ApiTool.Backend.Tests/Internal/TierGates/TierCheckLocalityTests.cs`
codifies this with a `Directory.GetFiles` + regex sweep so the invariant is
enforced by CI, not by manual greps.

**SsoTierGate refactor strategy:** keep the static
`SsoTierGate.EnsureEnterpriseAsync(AppDbContext db, Guid orgId, CancellationToken ct)`
signature unchanged. The seven call sites in `SsoService.cs:37,141,186,221`
and `OidcService.cs:33,142,193` keep their exact two-line shape. Internally
the static method now does
`return await new TierGate(db).EnsureAsync(orgId, SubscriptionTier.Enterprise, ct) switch { ... }`.
This satisfies the spec's "Every existing call site keeps the same signature"
guarantee at line 9742 and means **no edit to SsoService.cs or OidcService.cs**
is required. The seven existing test cases that assert `SsoError.TierIneligible`
continue to pass because the public output is unchanged.

The `SubscriptionTier` enum currently defines `Free=0, Professional=1, Team=2,
Enterprise=3` (no `Solo`). Spec line 9703 mentions `Free < Solo < Professional <
Team < Enterprise` as aspirational; the `>=` ordinal comparison still works on
the live enum and `Solo` is registered as M15-003 territory. The plan treats
the enum as the source of truth and uses the integer ordinal directly.

```csharp
// src/ApiTool.Backend/Internal/TierGates/ITierGate.cs
namespace ApiTool.Backend.Internal.TierGates;

using ApiTool.Backend.Data.Entities;

/// <summary>
/// Single canonical tier-gate seam (v4.3). Per-feature adapters
/// (<c>SsoTierGate</c>, <c>VaultConfigTierGate</c>, <c>ScheduleExecutorTierGate</c>,
/// <c>DashboardTierGate</c>) all delegate here so the EF subscription-tier query
/// exists in exactly one place.
/// </summary>
public interface ITierGate
{
    /// <summary>
    /// Returns <see cref="TierGateResult.Allowed"/> when the organisation's current
    /// subscription tier is greater-than-or-equal to <paramref name="requiredMinimumTier"/>;
    /// <see cref="TierGateResult.OrgNotFound"/> when the org does not exist;
    /// <see cref="TierGateResult.TierIneligible"/> otherwise.
    /// A missing subscription row is treated as <see cref="SubscriptionTier.Free"/>.
    /// </summary>
    Task<TierGateResult> EnsureAsync(
        Guid orgId,
        SubscriptionTier requiredMinimumTier,
        CancellationToken ct);
}
```

```csharp
// src/ApiTool.Backend/Internal/TierGates/TierGate.cs
namespace ApiTool.Backend.Internal.TierGates;

using ApiTool.Backend.Data;
using ApiTool.Backend.Data.Entities;
using Microsoft.EntityFrameworkCore;

/// <summary>
/// Canonical <see cref="ITierGate"/> implementation backed by <see cref="AppDbContext"/>.
/// Lifted verbatim from <c>SsoTierGate.EnsureEnterpriseAsync</c> (M15-002) and generalised
/// over the required minimum tier. The single source of truth for tier checks.
/// </summary>
internal sealed class TierGate(AppDbContext db) : ITierGate
{
    /// <inheritdoc />
    public async Task<TierGateResult> EnsureAsync(
        Guid orgId,
        SubscriptionTier requiredMinimumTier,
        CancellationToken ct)
    {
        var orgExists = await db.Organizations.AnyAsync(o => o.Id == orgId, ct);
        if (!orgExists) return TierGateResult.OrgNotFound;

        var current = await db.Subscriptions
            .Where(s => s.OrgId == orgId)
            .OrderByDescending(s => s.UpdatedAt)
            .Select(s => (SubscriptionTier?)s.Tier)
            .FirstOrDefaultAsync(ct) ?? SubscriptionTier.Free;

        return current >= requiredMinimumTier
            ? TierGateResult.Allowed
            : TierGateResult.TierIneligible;
    }
}
```

```csharp
/// <summary>
```

```csharp
// src/ApiTool.Backend/Internal/TierGates/TierGateProblemFactory.cs
namespace ApiTool.Backend.Internal.TierGates;

using ApiTool.Backend.Data.Entities;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Mvc;

/// <summary>
/// Builds RFC 7807 responses for tier-gate denials (v4.3). Mirrors
/// <c>SubscriptionsProblem</c> shape and conventions.
/// </summary>
public static class TierGateProblemFactory
{
    private const string BaseType = "https://api.apitool.dev/errors";

    /// <summary>
    /// Authenticated org-scoped endpoint denial: 402 Payment Required with the
    /// org's current tier and the required minimum embedded.
    /// </summary>
    public static IResult AuthenticatedTierIneligible(
        HttpContext http,
        SubscriptionTier currentTier,
        SubscriptionTier requiredMinimumTier,
        string featureCode)
    {
        var requestId = http.TraceIdentifier;
        http.Response.Headers["X-Request-Id"] = requestId;

        var problem = new ProblemDetails
        {
            Type   = $"{BaseType}/tier-ineligible",
            Title  = "Tier ineligible",
            Status = StatusCodes.Status402PaymentRequired,
            Detail = $"This feature requires the {requiredMinimumTier.ToString().ToLowerInvariant()} tier or above.",
            Extensions =
            {
                ["code"]            = $"{featureCode}_tier_ineligible",
                ["request_id"]      = requestId,
                ["current_tier"]    = currentTier.ToString().ToLowerInvariant(),
                ["required_tier"]   = requiredMinimumTier.ToString().ToLowerInvariant(),
            },
        };

        return Microsoft.AspNetCore.Http.Results.Json(
            problem,
            contentType: "application/problem+json",
            statusCode: StatusCodes.Status402PaymentRequired);
    }

    /// <summary>
    /// Authenticated org-scoped endpoint where the org does not exist:
    /// 404 Not Found, plain ProblemDetails, no cache-suppression header (still
    /// behind auth, no info-leak class).
    /// </summary>
    public static IResult AuthenticatedOrgNotFound(HttpContext http)
    {
        var requestId = http.TraceIdentifier;
        http.Response.Headers["X-Request-Id"] = requestId;
        var problem = new ProblemDetails
        {
            Type   = $"{BaseType}/organization-not-found",
            Title  = "Organization not found",
            Status = StatusCodes.Status404NotFound,
            Extensions = { ["code"] = "organization_not_found", ["request_id"] = requestId },
        };
        return Microsoft.AspNetCore.Http.Results.Json(
            problem, contentType: "application/problem+json", statusCode: 404);
    }

    /// <summary>
    /// Public-flow endpoint denial (mirrors <c>SsoNotFoundResult</c>): 404 with
    /// <c>Cache-Control: no-store</c> and no body — indistinguishable from a
    /// non-existent org so external probes cannot infer tier metadata.
    /// </summary>
    public static IResult PublicFlowNotFound() => new PublicFlowNotFoundResult();

    private sealed class PublicFlowNotFoundResult : IResult
    {
        public Task ExecuteAsync(HttpContext httpContext)
        {
            httpContext.Response.StatusCode = StatusCodes.Status404NotFound;
            httpContext.Response.Headers.CacheControl = "no-store";
            httpContext.Response.ContentLength = 0;
            return Task.CompletedTask;
        }
    }
}
```

```csharp
/// <summary>
/// Per-feature adapter for shared-vault template endpoints. Requires Team tier or above.
/// Spec: docs/SPECIFICATION.md "Tier-Gate Generic Abstraction (v4.3)" line 9708.

public static class VaultConfigTierGate
{

    public const SubscriptionTier RequiredMinimum = SubscriptionTier.Team;

            TierGateResult.OrgNotFound    => VaultConfigError.OrgNotFound,
            TierGateResult.TierIneligible => VaultConfigError.TierIneligible,
            _ => throw new UnreachableException(),
        };
```

```csharp
using Microsoft.EntityFrameworkCore;

/// <summary>
/// Testing/Development-only probe endpoint that exercises the Tier-Gate plumbing
/// end-to-end before the real vault-config / schedule / dashboard endpoints land.
/// Mirrors the gating pattern of <c>InternalSeedM14Endpoint</c>.
/// </summary>
internal static class InternalTierGateProbeEndpoint
{
    public static void MapInternalTierGateProbeEndpoint(this IEndpointRouteBuilder app, IWebHostEnvironment env)
    {
        if (env.IsProduction()) return;

        app.MapPost("/internal/test/tier-gate-probe/{orgId}/vault-config",
            async (Guid orgId, ITierGate gate, AppDbContext db, HttpContext http, CancellationToken ct) =>
            {
                var result = await VaultConfigTierGate.EnsureTeamOrAboveAsync(gate, orgId, ct);
                if (result == VaultConfigError.None) return Results.Ok();

                if (result == VaultConfigError.OrgNotFound)
                    return TierGateProblemFactory.AuthenticatedOrgNotFound(http);

                // Resolve the org's current tier for the 402 problem detail.
                var current = await db.Subscriptions
                    .Where(s => s.OrgId == orgId)
                    .OrderByDescending(s => s.UpdatedAt)
                    .Select(s => (SubscriptionTier?)s.Tier)
                    .FirstOrDefaultAsync(ct) ?? SubscriptionTier.Free;

                return TierGateProblemFactory.AuthenticatedTierIneligible(
                    http, current, VaultConfigTierGate.RequiredMinimum, "vault_config");
            });

        app.MapGet("/internal/test/tier-gate-probe/{orgId}/sso-login",
            async (Guid orgId, ITierGate gate, CancellationToken ct) =>
            {
                var result = await gate.EnsureAsync(orgId, SubscriptionTier.Enterprise, ct);
                if (result == TierGateResult.Allowed) return Results.Ok();
                return TierGateProblemFactory.PublicFlowNotFound();
            });
    }
}
```

The grep `db.Subscriptions.Where` *projection-of-tier* in this file is
allowed because the file lives under `Internal/TierGates/`, satisfying the
Step 5 locality test.

## Risks and Edge Cases

- **Risk: The locality regex misses a tier-check formulation.**
  → **Mitigation:** the regex matches `db.Subscriptions.Where(...).Select(s.Tier)` chains
  with up to 400 chars between Where and Select to absorb inline
  ordering/filtering. Run the regex against the current tree and confirm it
  matches the existing `SsoTierGate` (which is on the allow-list). If a
  future engineer writes the check differently (e.g., raw SQL, or projecting
  into an anonymous type), the test will not catch it — at which point we
  add additional patterns. Documenting this as a known limitation.

- **Risk: `new TierGate(db)` allocation per call inside the static
  `SsoTierGate` adapter.** → **Mitigation:** the allocation is a single
  4-byte reference + the `AppDbContext` already on the stack; equivalent to
  the current `db.Organizations.AnyAsync` allocation cost, which we accept.
  Premature optimisation to make `TierGate` a struct is rejected; keeping
  it a class lets DI replace it with a fake.

- **Edge case: organisation exists but has multiple subscription rows.**
  → **Handling:** preserved by the existing `OrderByDescending(s.UpdatedAt)`
  semantics; explicit unit test (TierGateTests case 5) asserts the
  most-recent row wins.

- **Edge case: organisation row exists but no subscription row.**
  → **Handling:** treated as `SubscriptionTier.Free` via the
  `?? SubscriptionTier.Free` fallback. Existing semantics preserved; explicit
  unit test asserts this.

- **Edge case: pre-cancelled `CancellationToken`.**
  → **Handling:** EF Core's `AnyAsync` and `FirstOrDefaultAsync` honour the
  token natively; explicit unit test asserts an `OperationCanceledException`
  surfaces.

- **Edge case: `TierGateResult` widened in the future (new variant).**
  → **Handling:** every `switch` on `TierGateResult` includes a default
  `_ => throw new UnreachableException()` arm so a new variant produces a
  loud failure during refactor rather than a silent fall-through.

- **Edge case: Production environment must NOT expose probe endpoints.**
  → **Handling:** `if (env.IsProduction()) return;` at the top of
  `MapInternalTierGateProbeEndpoint`, mirroring the
  `MapInternalSeedM14Endpoint` guard. A unit test (extending the existing
  Swagger-surface tests) could be added if desired; explicit smoke test
  during `/verify` confirms the route 404s under
  `ASPNETCORE_ENVIRONMENT=Production`.

- **Risk: Changing `SsoTierGate` from a `db.Subscriptions.Where(...)`
  inliner to a delegate breaks query-plan caching / changes EF's compiled
  query identity.** → **Mitigation:** the lifted query in
  `TierGate.EnsureAsync` is byte-for-byte the same LINQ expression, just
  rooted at a different `internal sealed class`. EF Core's compiled-query
  cache keys by expression tree, not by class location, so plan caching
  is unaffected.
