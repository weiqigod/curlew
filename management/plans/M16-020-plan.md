# Implementation Plan: M16-020

## Overview

Ship a new SvelteKit page at `/org/[slug]/dashboard` that consumes the M16-019 `/results/stats` and `/results/failures` endpoints, rendering overview cards, a pass-rate trend line chart, a recent-runs table, and a top-10 frequently-failing-endpoints list — with a `?window=7d|30d|90d` selector that round-trips through the URL and an in-place tier-gate upgrade prompt for Free-tier orgs (catching the backend's 402 response without redirecting).

## Architectural Decisions Recorded

The Plan-exploration step surfaced several ambiguities; the resolutions below are committed in this plan and must be honoured by the executor.

1. **Tier-gate UX is in-place, not redirect.** Every existing tier-gated route (results, schedules, vault-config, gitlab) uses `requireTeamTier` from `$lib/server/guards.ts`, which **redirects** non-team orgs to `/org/[slug]?toast=team_tier_required`. The task observable explicitly says the dashboard should *render an upgrade prompt in place* for Free-tier ("As a Free-tier user… observe the tier-gate prompt rendered in place of the dashboard"). **Decision:** the loader does NOT call `requireTeamTier`. It calls `/results/stats` and catches `ApiError` with `status === 402`, returning a `tierGate` flag that the page renders as a new `TierGatePrompt` component. Org-tier client-side gate (`org.tier === 'free'`) is also short-circuited before the fetch so we don't issue a doomed call.

2. **No new chart library.** Task scope says "Use an existing chart library (e.g., `chart.js` already in dev deps, or `layercake`); minimum-viable visualization." Neither package is actually in `web/package.json` — chart.js is not a dep, layercake is not a dep. The existing `TrendChart.svelte` (M4-005) uses inline SVG. Adding a chart library is gold-plating against a minimum-viable spec. **Decision:** reuse the inline-SVG pattern. Build a new `PassRateTrendChart.svelte` that renders a line (polyline) over the M16-019 `trend` array (x = date, y = `pass_rate` 0–1), with axis labels. Zero new dependencies.

3. **Page route placement.** Task says `web/src/routes/(app)/org/[slug]/dashboard/`. Existing `/org/[slug]/results` (M4-005) also exists. The task observable navigates to `/org/<slug>/dashboard` — so the new route is additive, not a replacement. **Decision:** create the new route at `web/src/routes/(app)/org/[slug]/dashboard/`. The existing `/results` page is unchanged (its summary cards use legacy `Result[]` data, this one uses M16-019 stats schemas).

4. **Window-selector implementation.** Existing `TimeRangePicker.svelte` is hardcoded for `?range=24h|7d|30d|all` against the `/results` page. The dashboard uses `?window=7d|30d|90d`. **Decision:** build a new `DashboardWindowPicker.svelte` (sibling component under `lib/components/dashboard/`), matching the TimeRangePicker UX (anchor-link tab group) but with the dashboard-specific values. Each anchor href links back to the same `/dashboard` route with the new `?window=` param so SvelteKit's full-page navigation triggers a fresh server load (matching how TimeRangePicker works today).

5. **Recent-runs table on the dashboard.** Task scope lists "recent-runs table" but `/results/stats` does NOT return runs — it returns aggregated totals and a sparse daily trend. The existing `/results` page calls `GET /results` (list endpoint) to populate its `RecentRunsTable`. **Decision:** the loader calls **three** endpoints in parallel: `/results/stats?window=X`, `/results/failures?window=X&limit=10`, and `/results?limit=10` (existing M4-004 list). The recent-runs table reuses the existing `RecentRunsTable.svelte` component unchanged. Failure of the list endpoint degrades gracefully (empty table) — only `/results/stats` is load-blocking.

6. **Invalid `?window=` URL-hack handling.** Behavior 5: "Given the user passes `?window=14d` via URL hack… the dashboard shows the 400 error returned by the backend without crashing." **Decision:** the loader forwards the raw `window` param straight to the backend without client-side filtering. The backend returns `400 unsupported_window` with `application/problem+json`; the loader catches the `ApiError`, returns `{ windowError: <message> }`, and the page renders an `ErrorState` instead of the dashboard. Open Decision 10 from M16-019 — defer validation to the backend (single source of truth for allowed values).

7. **Sidebar nav entry.** Behavior 8 requires the dashboard link in the org sidebar nav. **Decision:** add a "Dashboard" link in `web/src/routes/(app)/+layout.svelte` between the "{currentOrg.name}" label and the existing "Test Results" link. Gated by `isTeamTier` only (NOT also `isAdmin`) — `dashboard.view` is the spec's permission and applies to all members, not just admins (per `Rbac/Permissions.cs:77` "Team Dashboard" / "Owner/Admin/Member ✓✓✓"). Test ID: `subnav-dashboard-link`.

8. **Failure-row "last_seen relative time."** Behavior 6 demands "last_seen_at relative time." **Decision:** add a small helper `formatRelativeTime(iso: string, now?: Date): string` to `web/src/lib/dashboard/format.ts` returning `"5m ago"`, `"3h ago"`, `"2d ago"`, etc. Unit-tested with frozen `now`. Avoids pulling in `date-fns`/`dayjs`.

9. **Empty-state copy.** Behavior 7 demands "No runs in this window" exactly. **Decision:** when `stats.totals.runs === 0`, render `EmptyState` with that copy, and HIDE the trend chart and failing-endpoints list. Recent-runs table is also hidden when zero runs.

10. **Pass-rate display.** Backend ships `pass_rate` as 0–1 fractional float (M16-019). Existing dashboard reads pass rate as 0–100 percent (legacy). **Decision:** the new SummaryCards renders `(pass_rate * 100).toFixed(2) + "%"`. No conversion at the API layer — keep types matching the backend wire format exactly.

11. **Duration display.** Task observable says "Avg Duration ms, p50/p95 Duration ms" — three values. **Decision:** ship 5 overview cards total: Total Runs, Pass Rate %, Avg Duration ms, p50 Duration ms, p95 Duration ms — laid out as `grid-cols-2 md:grid-cols-5`. Duration values formatted via the same `formatDuration(ms)` helper already used by `SummaryCards`/`RecentRunsTable` (`<1000 → "Nms"`, `≥1000 → "N.Ns"`).

12. **Pass-rate trend line — sparse data handling.** M16-019 returns a SPARSE trend (only days with ≥1 run). For a "daily-aggregation pass-rate trend line," gaps in days would visually mislead. **Decision:** the chart connects only the existing points (no zero-fill). Each `TrendEntry` becomes one `(x, y)` vertex; x = ordinal day index in the displayed range, y = `pass_rate`. Day-fill at the chart layer is out-of-scope for minimum-viable (per Open Decision 11 in M16-019).

// web/src/lib/api/dashboard.ts
import { api, type RequestOptions } from './client';
import type { StatsResponse, FailuresResponse } from '$lib/types/dashboard';

export const dashboardApi = {
  async getStats(
    orgId: string,
    opts: RequestOptions & { window?: string } = {}
  ): Promise<StatsResponse> {
    const { window, ...rest } = opts;
    return api.get<StatsResponse>(
      `/api/v1/organizations/${encodeURIComponent(orgId)}/results/stats`,
      { ...rest, params: { ...rest.params, ...(window !== undefined ? { window } : {}) } }
    );
  },

  async getFailures(
    orgId: string,
    opts: RequestOptions & { window?: string; limit?: number } = {}
  ): Promise<FailuresResponse> {
    const { window, limit, ...rest } = opts;
    return api.get<FailuresResponse>(
      `/api/v1/organizations/${encodeURIComponent(orgId)}/results/failures`,
      {
        ...rest,
        params: {
          ...rest.params,
          ...(window !== undefined ? { window } : {}),
          ...(limit !== undefined ? { limit } : {})
        }
      }
    );
  }
};

// web/src/lib/dashboard/format.ts

/** Formats an ISO 8601 instant as a coarse relative time ("5m ago", "3h ago", "2d ago"). */
export function formatRelativeTime(iso: string, now: Date = new Date()): string {
  const then = Date.parse(iso);
  if (Number.isNaN(then)) return iso;
  const diffSec = Math.floor((now.getTime() - then) / 1000);
  if (diffSec < 0) return 'just now';
  if (diffSec < 60) return `${diffSec}s ago`;
  if (diffSec < 3600) return `${Math.floor(diffSec / 60)}m ago`;
  if (diffSec < 86_400) return `${Math.floor(diffSec / 3600)}h ago`;
  return `${Math.floor(diffSec / 86_400)}d ago`;
}

/** Renders a 0–1 fractional pass rate as e.g. "98.83%". */
export function formatPassRate(rate: number): string {
  return `${(rate * 100).toFixed(2)}%`;
}

/** Renders a millisecond count compactly: <1000 → "300ms", ≥1000 → "1.2s". */
export function formatDuration(ms: number): string {
  if (ms < 1000) return `${ms}ms`;
  return `${(ms / 1000).toFixed(1)}s`;
}
```

<script lang="ts">
  import type { TrendEntry } from '$lib/types/dashboard';
  export let trend: TrendEntry[];
  const W = 600;
  const H = 160;
  const PAD = 24;
  $: points = trend.length === 0
    ? ''
    : trend.map((t, i) => {
        const x = PAD + (i * (W - 2 * PAD)) / Math.max(1, trend.length - 1);
        const y = H - PAD - t.pass_rate * (H - 2 * PAD);
        return `${x},${y}`;
      }).join(' ');
</script>
<div class="overflow-x-auto" data-testid="dashboard-trend-chart">
  <svg width={W} height={H} viewBox="0 0 {W} {H}" role="img" aria-label="Daily pass-rate trend">
    <!-- y-axis labels at 0/0.5/1, baseline, polyline of points, point circles -->
    <text x={4} y={PAD + 4} class="fill-gray-400" font-size="10">100%</text>
    <text x={4} y={H / 2 + 4} class="fill-gray-400" font-size="10">50%</text>
    <text x={4} y={H - PAD + 4} class="fill-gray-400" font-size="10">0%</text>
    <line x1={PAD} y1={H - PAD} x2={W - PAD} y2={H - PAD} stroke="#e5e7eb" />
    {#if trend.length > 0}
      <polyline fill="none" stroke="#3b82f6" stroke-width="2" points={points} />
      {#each trend as t, i}
        <circle
          cx={PAD + (i * (W - 2 * PAD)) / Math.max(1, trend.length - 1)}
          cy={H - PAD - t.pass_rate * (H - 2 * PAD)}
          r="3"
          fill="#3b82f6"
          data-date={t.date}
        />
      {/each}
    {/if}
  </svg>
</div>

// +page.server.ts
import type { PageServerLoad } from './$types';
import { requireAuth } from '$lib/server/guards';
import { organizationsApi } from '$lib/api/organizations';
import { dashboardApi } from '$lib/api/dashboard';
import { resultsApi } from '$lib/api/results';
import { ApiError } from '$lib/types/api-error';
import { error } from '@sveltejs/kit';
import type { StatsResponse, FailuresResponse } from '$lib/types/dashboard';
import type { Result } from '$lib/types/results';

export const load: PageServerLoad = async ({ locals, params, url, fetch }) => {
  const token = requireAuth(locals.accessToken, url.pathname + url.search);
  // Forward the raw window value to the backend — it owns the allow-list.
  const rawWindow = url.searchParams.get('window') ?? undefined;

  const org = await organizationsApi.findBySlug(params.slug, { token, fetch });
  if (!org) throw error(404, 'Organization not found');

  // Free-tier short-circuit: render upgrade prompt without making a doomed fetch.
  if ((org.tier ?? 'team') === 'free') {
    return {
      org,
      window: rawWindow ?? '30d',
      tierGate: true as const,
      stats: null,
      failures: null,
      recentRuns: [] as Result[],
      windowError: null as string | null,
      loadError: null as string | null
    };
  }

  let stats: StatsResponse | null = null;
  let failures: FailuresResponse | null = null;
  let recentRuns: Result[] = [];
  let tierGate = false;
  let windowError: string | null = null;
  let loadError: string | null = null;

  const [statsRes, failuresRes, runsRes] = await Promise.allSettled([
    dashboardApi.getStats(org.id, { token, fetch, window: rawWindow }),
    dashboardApi.getFailures(org.id, { token, fetch, window: rawWindow, limit: 10 }),
    resultsApi.list(org.id, { token, fetch, limit: 10 })
  ]);

  // Stats result governs the page state — tier gate or window error short-circuit.
  if (statsRes.status === 'fulfilled') {
    stats = statsRes.value;
  } else {
    const e = statsRes.reason;
    if (e instanceof ApiError && e.status === 402) {
      tierGate = true;
    } else if (e instanceof ApiError && e.status === 400) {
      windowError = e.message;
    } else {
      loadError = e instanceof Error ? e.message : 'Failed to load dashboard';
    }
  }

  if (failuresRes.status === 'fulfilled' && !tierGate && !windowError) {
    failures = failuresRes.value;
  }
  if (runsRes.status === 'fulfilled' && !tierGate && !windowError) {
    recentRuns = runsRes.value;
  }

  return {
    org,
    window: stats?.window ?? rawWindow ?? '30d',
    tierGate,
    stats,
    failures,
    recentRuns,
    windowError,
    loadError
  };
};
```

## Risks and Edge Cases

- **Risk:** Free-tier org's `tier` field is absent (transitional mode). `requireTeamTier` treats absent as team. → **Mitigation:** Loader uses `(org.tier ?? 'team') === 'free'` for the client-side short-circuit — matches the existing convention. If tier is absent and the backend still returns 402, the loader catches it.
- **Risk:** Recent runs endpoint is slow/down. → **Mitigation:** `Promise.allSettled` — recent-runs failure does NOT block the rest of the page. Empty table rendered.
- **Risk:** `?window=` query param is forwarded verbatim, including malicious values. → **Mitigation:** The backend's `DashboardProblem.UnsupportedWindow` 400 is caught and rendered as an error message. The raw `received` value flows into the error string via the backend's `Detail` text — no XSS surface because Svelte escapes interpolations by default.
- **Risk:** Trend chart x-axis with very long windows (90d sparse data). → **Mitigation:** Min-viable: scale ordinal index across full SVG width. No date labels on axis (avoids overlap with 90 ticks). Acceptable per Open Decision 11 ("minimum-viable working page — no visual polish required").
- **Risk:** RBAC check (`dashboard.view`) fails with 403 — not covered by current behavior list. → **Mitigation:** Loader catches generic `ApiError` and surfaces it via `loadError`. Permission-missing case renders an ErrorState — not perfect UX, but acceptable for min-viable. Future polish: dedicated 403 state.
- **Edge case:** Pass rate of NaN/Infinity if a backend bug emits unexpected values. → **Handling:** `formatPassRate` calls `toFixed(2)` which produces "NaN%" for NaN — visible but doesn't crash the page. Acceptable for minimum viable.
- **Edge case:** Failing-endpoints list with `limit_clamped: true` — the backend returns a Warning header that the SvelteKit fetch swallows. → **Handling:** Out of scope. The list is hard-capped at `limit=10` from the loader, so clamping never triggers from this UI.
- **Edge case:** Empty trend but non-zero totals (impossible per backend invariant, but defensive). → **Handling:** `PassRateTrendChart` renders an empty SVG (no polyline) — chart visible but flat. No crash.
