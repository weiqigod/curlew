## Overview
Implement the `curlew login` subcommand that drives the OAuth 2.0 Device
Authorization Grant (RFC 8628) against the curlew backend, persists the
returned `license_jwt`, `access_token`, `refresh_token`, and `device_id` via
the existing `internal/backend` storage layer, and ships a Go-based
`testdata/m14/stub-backend.sh` reusable by the rest of the M14 cluster.

## Architectural Decisions

The plan resolves the following design choices up front so execution stays
mechanical:

1. **Polling sentinel format.** RFC 8628 §3.5 errors (`authorization_pending`,
   `slow_down`, `expired_token`, `access_denied`) are returned as RFC 7807
   `application/problem+json` documents whose `code` field carries the
   sentinel UPPER_SNAKE_CASE form (`AUTH_DEVICE_AUTHORIZATION_PENDING`,
   `AUTH_DEVICE_SLOW_DOWN`, `AUTH_DEVICE_EXPIRED_TOKEN`,
   `AUTH_DEVICE_ACCESS_DENIED`). The existing `*backend.ProblemDetails`
   decoder already surfaces this via `errors.As`. We branch on `pd.Code`,
   never on `pd.Status` — matches the rest of the codebase.
2. **Backend URL source.** `CURLEW_BACKEND_URL` (matches the existing
   report-upload + worker conventions at `cmd/curlew/main.go:1793`). When
   unset, the production default is `https://api.apitool.dev`. Tests always
   set the env var to the `httptest.Server` URL so no network calls leak.
3. **Browser auto-open.** Detection via stdlib only:
   `(stat.Mode() & os.ModeCharDevice) != 0` against `os.Stdout.Fd()`.
   No new dependency on `mattn/go-isatty` or `golang.org/x/term`. The opener
   is a `func(url string) error`, with platform-specific defaults (`open` on
   darwin, `xdg-open` on linux, `cmd /c start` on windows) injectable via a
   package-level variable so tests can stub it.
4. **TTY override for tests.** Tests can force the non-TTY branch via
   `CURLEW_FORCE_NO_TTY=1` (project-internal env var, undocumented in help).
   The `--no-browser` flag also sets the same effect from a user POV. This
   keeps tests deterministic without parsing pty state.
5. **Sleep injection.** `func(d time.Duration)` package-level variable (default
   `time.Sleep`) so tests can run with millisecond-scale durations and not
   wait real seconds. Polling caps at the backend-supplied
   `expires_in` (defaulting to 900s) so a runaway loop is impossible.
6. **device.json layout.** New tiny package `internal/backend/device` that
   owns `~/.config/curlew/device.json` with mode 0600 and a single
   field `{"device_id":"...", "issued_at":"<RFC3339>"}`. Justification: keeps
   the `internal/backend` surface coherent (existing storage is for refresh
   tokens; the new file is unencrypted plaintext device id, intentionally
   distinct since `device_id` is not a secret per spec). Public functions
   `Read(cfgDir) (Record, error)` and `Write(cfgDir, Record) error`. Also
   reused by M14-006 (`curlew logout`) and M14-007 (`license --refresh`).
7. **license.json + access-token persistence.** The `license_jwt` is written
   via the existing `internal/license.Store.Save` (same path as the rest of
   the codebase). The `access_token` is dropped on the floor for the login
   step itself — short-lived, refreshable on demand by M14-007's
   `license --refresh`. This avoids leaking access tokens to disk;
   `license.LicenseRecord.AccessToken` already stores the **License JWT** per
   `internal/license/state.go:38`, not the API access token (despite the
   name, which is legacy from M5).
8. **Stub backend layout.** `testdata/m14/stub-backend.sh` is a thin wrapper
   that `exec`s `go run testdata/m14/stub_server.go`, mirroring the pattern
   at `testdata/team/mock-backend.sh`. The Go file uses `//go:build ignore`
   so it never participates in the production build. It supports a
   `STUB_BEHAVIOR` env var to script transitions (e.g.
   `pending,pending,success` returns two `AUTHORIZATION_PENDING` then a
   success on the third poll). Default behaviour when unset is
   `pending,success`.
9. **Output discipline.** All user-facing prompts (`First, copy your...`,
   `Then visit:`, `Authentication complete.`) go to **stdout**. Internal
   progress chatter (e.g. `Polling for confirmation...`) goes to **stderr**.
   This matches the project's writer-injection convention used by
   `licenseValidateOut` and `licenseExportOut`.
10. **Exit codes.**
    - `0` success.
    - `1` internal error (URL malformed, FS error, code bug).
    - `3` network failure (`backend.ErrNetworkFailure`) — matches
      `curlew license --refresh` taxonomy at SPECIFICATION.md:8270.
    - `4` `expired_token`, `access_denied`, or any other terminal RFC 8628
      error — re-auth required.
    - `6` 5xx without problem+json (`backend.ErrServerError`) — matches the
      license refresh taxonomy.

// DeviceStart is the response shape from POST /api/v1/auth/device/start.
type DeviceStart struct {
    DeviceCode              string `json:"device_code"`
    UserCode                string `json:"user_code"`
    VerificationURI         string `json:"verification_uri"`
    VerificationURIComplete string `json:"verification_uri_complete"`
    ExpiresIn               int    `json:"expires_in"`
    Interval                int    `json:"interval"`
}

// DevicePollResult is the success-shape from POST /api/v1/auth/device/poll.
type DevicePollResult struct {
    LicenseJWT   string `json:"license_jwt"`
    AccessToken  string `json:"access_token"`
    RefreshToken string `json:"refresh_token"`
    DeviceID     string `json:"device_id"`
}

var (
    ErrAuthorizationPending = errors.New("backend: authorization_pending")
    ErrSlowDown             = errors.New("backend: slow_down")
    ErrExpiredToken         = errors.New("backend: expired_token")
    ErrAccessDenied         = errors.New("backend: access_denied")
)

// StartDevice initiates the flow.
func (c *Client) StartDevice(ctx context.Context) (DeviceStart, error) { /* PostJSON */ }

// PollDevice polls once. Translates ProblemDetails.Code values into the
// sentinel errors above so the caller can errors.Is rather than re-decoding
// the RFC 7807 envelope.
func (c *Client) PollDevice(ctx context.Context, deviceCode string) (DevicePollResult, error) { /* ... */ }

The `PollDevice` translation table:

| `ProblemDetails.Code`              | Sentinel                  |
|------------------------------------|---------------------------|
| `AUTH_DEVICE_AUTHORIZATION_PENDING`| `ErrAuthorizationPending` |
| `AUTH_DEVICE_SLOW_DOWN`            | `ErrSlowDown`             |
| `AUTH_DEVICE_EXPIRED_TOKEN`        | `ErrExpiredToken`         |
| `AUTH_DEVICE_ACCESS_DENIED`        | `ErrAccessDenied`         |
| anything else                      | bubbled `*ProblemDetails` |

The wrapped form is `fmt.Errorf("%w: %s", ErrXxx, pd.Detail)` so callers get
the sentinel via `errors.Is` and the human detail via `Error()`.

// Package main: cmd/curlew/login.go.
//
// Implements `curlew login` per the RFC 8628 device-code flow specified
// at docs/SPECIFICATION.md:8205-8222. Polls /api/v1/auth/device/start then
// /api/v1/auth/device/poll via internal/backend, prints the user code and
// verification URI for the user, optionally fires a browser at
// verification_uri_complete on TTY hosts when --no-browser is not set, and
// persists the resulting tokens (refresh via internal/backend.Storage,
// license JWT via internal/license.Store, device_id via
// internal/backend/device).
package main

import (
    "context"
    "errors"
    "flag"
    "fmt"
    "io"
    "os"

// loginFlags is the parsed CLI surface for `curlew login`.

func loginCmdOut(args []string, stdout, stderr io.Writer) int {
    flags, err := parseLoginArgs(args)
    if err != nil { /* print error + help, return 1 or 2 */ }
    if flags.Help {
        printLoginHelpTo(stdout)
        return 0
    }

    backendURL := os.Getenv("CURLEW_BACKEND_URL")
    if backendURL == "" {
        backendURL = "https://api.apitool.dev"
    }
    client, err := backend.NewClient(backend.Options{BaseURL: backendURL})
    if err != nil {
        _, _ = fmt.Fprintln(stderr, err)
        return 1
    }

    ctx, cancel := context.WithCancel(context.Background())
    defer cancel()

    start, err := client.StartDevice(ctx)
    if err != nil {
        return loginExitForError(err, stderr)
    }

    presentCode(stdout, start)
    if !flags.NoBrowser && loginIsTTY() {
        _ = loginOpenBrowser(start.VerificationURIComplete) // best-effort
    }
    _, _ = fmt.Fprintln(stderr, "Polling for confirmation...")

    poll, err := pollUntilDecision(ctx, client, start)
    if err != nil {
        return loginExitForError(err, stderr)
    }

    cfgDir, err := loginConfigDir()
    if err != nil { /* return 1 */ }
    if err := persistLogin(cfgDir, poll); err != nil { /* return 1 */ }

    email := emailFromLicenseJWT(poll.LicenseJWT) // best-effort claim parse
    _, _ = fmt.Fprintf(stdout, "Authentication complete. Welcome, %s.\n", email)
    return 0
}

// presentCode prints the bare verification_uri + user_code per Open
// Decision #3. verification_uri_complete is reserved for the auto-open path.
func presentCode(stdout io.Writer, s backend.DeviceStart) {
    _, _ = fmt.Fprintf(stdout, "First, copy your one-time code: %s\n", s.UserCode)
    _, _ = fmt.Fprintf(stdout, "Then visit: %s\n", s.VerificationURI)
}

// pollUntilDecision implements the RFC 8628 §3.5 polling loop with
// authorization_pending / slow_down handling. Caps at start.ExpiresIn seconds.
func pollUntilDecision(
    ctx context.Context,
    c *backend.Client,
    start backend.DeviceStart,
) (backend.DevicePollResult, error) {
    interval := time.Duration(start.Interval) * time.Second
    if interval <= 0 {
        interval = 5 * time.Second
    }
    deadline := time.Now().Add(time.Duration(start.ExpiresIn) * time.Second)
    for {
        if time.Now().After(deadline) {
            return backend.DevicePollResult{}, backend.ErrExpiredToken
        }
        loginSleep(interval)
        res, err := c.PollDevice(ctx, start.DeviceCode)
        switch {
        case err == nil:
            return res, nil
        case errors.Is(err, backend.ErrAuthorizationPending):
            continue
        case errors.Is(err, backend.ErrSlowDown):
            interval += 5 * time.Second // RFC 8628 §3.5
            continue
        default:
            return backend.DevicePollResult{}, err
        }
    }
}

// persistLogin saves the tokens via the existing storage layers.
func persistLogin(cfgDir string, p backend.DevicePollResult) error {
    if err := device.Write(cfgDir, device.Record{
        DeviceID: p.DeviceID,
        IssuedAt: time.Now().UTC(),
    }); err != nil {
        return fmt.Errorf("persist device.json: %w", err)
    }
    storage, err := backend.NewStorage(backend.StorageOptions{
        ConfigDir: cfgDir, DeviceID: p.DeviceID,
    })
    if err != nil {
        return fmt.Errorf("init storage: %w", err)
    }
    if err := storage.SetRefreshToken(p.RefreshToken); err != nil {
        return fmt.Errorf("persist refresh token: %w", err)
    }
    rec := &license.LicenseRecord{
        AccessToken:           p.LicenseJWT, // legacy field name; holds License JWT
        Tier:                  tierFromLicenseJWT(p.LicenseJWT),
        LastValidatedAt:       time.Now().UTC(),
        LastValidationAttempt: time.Now().UTC(),
        ValidationFailures:    0,
    }
    if err := license.NewStore(cfgDir).Save(rec); err != nil {
        return fmt.Errorf("persist license.json: %w", err)
    }
    return nil
}

func loginExitForError(err error, stderr io.Writer) int {
    switch {
    case errors.Is(err, backend.ErrExpiredToken):
        _, _ = fmt.Fprintln(stderr, "Code expired; run curlew login again")
        return 4
    case errors.Is(err, backend.ErrAccessDenied):
        _, _ = fmt.Fprintln(stderr, "Login was denied in the browser")
        return 4
    case errors.Is(err, backend.ErrNetworkFailure):
        _, _ = fmt.Fprintf(stderr, "network failure: %v\n", err)
        return 3
    case errors.Is(err, backend.ErrServerError):
        _, _ = fmt.Fprintf(stderr, "backend error: %v\n", err)
        return 6
    default:
        _, _ = fmt.Fprintf(stderr, "login failed: %v\n", err)
        return 1
    }
}

// stdoutIsTTY returns true when stdout is a character device.
func stdoutIsTTY() bool {
    if os.Getenv("CURLEW_FORCE_NO_TTY") == "1" {
        return false
    }
    fi, err := os.Stdout.Stat()
    if err != nil {
        return false
    }
    return (fi.Mode() & os.ModeCharDevice) != 0
}

// openBrowserDefault dispatches per-OS. Returns nil on best-effort success.
func openBrowserDefault(url string) error {
    var cmd *exec.Cmd
    switch runtime.GOOS {
    case "darwin":
        cmd = exec.Command("open", url)
    case "windows":
        cmd = exec.Command("cmd", "/c", "start", "", url)
    default:
        cmd = exec.Command("xdg-open", url)
    }
    return cmd.Start() // fire and forget
}

func loginConfigDir() (string, error) {
    if d := os.Getenv("CURLEW_CONFIG_DIR"); d != "" {
        return d, nil
    }
    home, err := os.UserHomeDir()
    if err != nil {
        return "", fmt.Errorf("home dir: %w", err)
    }
    return filepath.Join(home, ".config", "curlew"), nil
}

func TestLogin_Polling_PendingThenSuccess(t *testing.T) {
    var pollCount atomic.Int32
    srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        switch r.URL.Path {
        case "/api/v1/auth/device/start":
            w.Header().Set("Content-Type", "application/json")
            _, _ = w.Write([]byte(`{"device_code":"d","user_code":"ABCD-EFGH","verification_uri":"https://x/device","verification_uri_complete":"https://x/device?user_code=ABCD-EFGH","expires_in":900,"interval":1}`))
        case "/api/v1/auth/device/poll":
            n := pollCount.Add(1)
            if n < 3 {
                w.Header().Set("Content-Type", "application/problem+json")
                w.WriteHeader(400)
                _, _ = w.Write([]byte(`{"code":"AUTH_DEVICE_AUTHORIZATION_PENDING","status":400,"title":"pending"}`))
                return
            }
            w.Header().Set("Content-Type", "application/json")
            _, _ = w.Write([]byte(`{"license_jwt":"<minted>","access_token":"a","refresh_token":"rt-aaaaaaaaaaaaaa","device_id":"dev_abc"}`))
        }
    }))
    defer srv.Close()
    t.Setenv("CURLEW_BACKEND_URL", srv.URL)
    t.Setenv("CURLEW_CONFIG_DIR", t.TempDir())
    t.Setenv("CURLEW_FORCE_NO_TTY", "1")

    var slept []time.Duration
    loginSleep = func(d time.Duration) { slept = append(slept, d) }
    t.Cleanup(func() { loginSleep = time.Sleep })

    stdout, stderr, rc := captureRun(t, "login", "--no-browser")
    if rc != 0 { t.Fatalf("rc=%d stderr=%q", rc, stderr) }
    if got := pollCount.Load(); got != 3 {
        t.Errorf("poll count = %d, want 3", got)
    }
    // intervals: 1s, 1s, 1s (no slow_down)
    if len(slept) != 3 || slept[0] != time.Second {
        t.Errorf("sleeps = %v, want three 1s sleeps", slept)
    }
    _ = stdout
}

#### `stub-backend.sh` shape (reusable by M14-006/007/021)

```sh
#!/usr/bin/env bash
# Tiny curlew device-code stub. Reusable by M14-005, M14-006, M14-007, M14-021.
# Listens on :18080 by default; override with PORT.
#
# Usage:
#   ./testdata/m14/stub-backend.sh start          # foreground
#   ./testdata/m14/stub-backend.sh start --bg     # background, writes ./stub.pid
#   ./testdata/m14/stub-backend.sh stop           # kills ./stub.pid
#
# STUB_BEHAVIOR controls the device/poll script. Defaults to "pending,success".
set -euo pipefail
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
case "${1:-start}" in
  start)
    if [[ "${2:-}" == "--bg" ]]; then
      go run "$SCRIPT_DIR/stub_server.go" >"$SCRIPT_DIR/stub.log" 2>&1 &
      echo $! > "$SCRIPT_DIR/stub.pid"
    else
      exec go run "$SCRIPT_DIR/stub_server.go"
    fi ;;
  stop)
    [[ -f "$SCRIPT_DIR/stub.pid" ]] && kill "$(cat "$SCRIPT_DIR/stub.pid")" || true
    rm -f "$SCRIPT_DIR/stub.pid" ;;
  *) echo "usage: stub-backend.sh {start [--bg] | stop}" >&2; exit 1 ;;
esac
```

#### `stub_server.go` outline

- Listens on `${PORT:-18080}`.
- `POST /api/v1/auth/device/start` returns a canned JSON with
  `device_code=stub-d`, `user_code=ABCD-EFGH`,
  `verification_uri=https://app.apitool.dev/device`, `verification_uri_complete=...&user_code=ABCD-EFGH`,
  `expires_in=900`, `interval=1`.
- `POST /api/v1/auth/device/poll` walks `STUB_BEHAVIOR` once per call:
  - `pending` → 400 problem+json `AUTH_DEVICE_AUTHORIZATION_PENDING`
  - `slow_down` → 400 problem+json `AUTH_DEVICE_SLOW_DOWN`
  - `expired` → 400 problem+json `AUTH_DEVICE_EXPIRED_TOKEN`
  - `success` → 200 with the canned tokens (license JWT minted from the
    embedded `internal/license/keys/testdata/private.pem` so the fixture
    round-trips through `license --validate`).
  Default: `pending,success`.
- Logs each request to stdout with method, path, body — same pattern as
  `testdata/team/mock_server.go`.

## Risks and Edge Cases

- **Risk: Browser auto-open hangs the test runner on macOS.** → **Mitigation:** Use the `loginOpenBrowser` package-level variable; tests always replace it with a no-op. `cmd.Start()` is fire-and-forget so even in production we never block on the child process.
- **Risk: `os.ModeCharDevice` returns true under `go test` on some CI runners (TTY-attached CI).** → **Mitigation:** `CURLEW_FORCE_NO_TTY=1` sentinel honored in `stdoutIsTTY`; every test sets it explicitly.
- **Risk: `loginSleep` not reset between tests leaks across the package.** → **Mitigation:** every test that mutates it pairs with `t.Cleanup(func() { loginSleep = time.Sleep })`. Documented at the top of `login_test.go`.
- **Risk: Storing the License JWT in `LicenseRecord.AccessToken` is misleading.** → **Mitigation:** documented in Architectural Decision #7 and a code comment at the persist site. Renaming the field is out of scope (touches every license test); we accept the legacy name.
- **Edge case: `start.Interval == 0` (server omits the field).** → **Handling:** default to 5s per RFC 8628 §3.5 fallback.
- **Edge case: `start.ExpiresIn == 0`.** → **Handling:** treat as expired immediately and exit 4 — defensive against a broken backend response. Covered by a dedicated table entry in `TestLogin_Polling_ExpiredToken_ExitFour`.
- **Edge case: backend returns success on the FIRST poll (no pending iterations).** → **Handling:** loop reaches the `case err == nil` branch on iteration 1; passes.
- **Edge case: SIGINT during polling.** → **Handling:** the parent context is `context.Background()` for now; SIGINT terminates the process and the user re-runs. Wiring `signal.NotifyContext` is a one-liner if review wants it but it's not in the YAML behaviors.
- **Edge case: keychain unavailable in test environment.** → **Handling:** `internal/backend.NewStorage` already falls back to the encrypted file. Tests use `t.TempDir()` for `CURLEW_CONFIG_DIR`; the encrypted-file fallback is exercised. We do NOT pass `ForceFile: true` because production callers don't, so the test path matches.
- **Edge case: ProblemDetails decoding fails (server returns 400 with bad JSON).** → **Handling:** `Client.do` already returns a wrapped error; `loginExitForError` falls through to the generic exit-1 branch.
- **Edge case: User has no $HOME.** → **Handling:** `os.UserHomeDir()` returns an error → exit 1 with a clear message. Tests bypass via `CURLEW_CONFIG_DIR`.
