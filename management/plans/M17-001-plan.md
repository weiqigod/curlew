## Architectural Decisions

These resolve the open decisions called out in the task scope; documenting them here so reviewers and downstream M17-002/M17-003 implementers can find the rationale without re-deriving it.

1. **Signer interface signature** — `Sign(ctx context.Context, req *httpexec.Request, sensitives *variable.SensitiveSet) error`. Mutates `req` in place. Concrete signers call `sensitives.AddValue(resolved)` for any credential they pull from a sensitive variable, mirroring the M12-005 `$hmacSha256` pattern. **No clock argument** on the interface — concrete signers that need a clock own it as a per-package `WithClock(now func() time.Time)` factory option (mirrors `Registry.now` in `internal/variable/dynamic.go`). Stated explicitly in the package doc so M17-002/003 don't reverse-engineer it.

2. **Registry shape** — `*Registry` with `Register(name string, factory Factory) error` and `Lookup(name string) (Factory, error)`. `Factory` is `func(params map[string]any) (Signer, error)`. `Register` rejects duplicate names. `Lookup` returns `ErrUnknownSignerType` wrapped with the requested name and a sorted, comma-joined list of registered names — mirrors `resolveAuthProfile`'s available-list error in `internal/runner/runner.go:78`. `NewBuiltinRegistry()` returns an empty registry in M17-001 (built-ins ship in subsequent slices).

3. **Wiring point inside the runner** — exec-wrap parallel to the `vars.Hooks != nil` block in `Run` (`internal/runner/runner.go:421-472`). The wrap is allocated once per Run, only when the collection or any request resolves to a non-nil signing spec (fast-path mirrors the `vars.Hooks != nil` branch). The per-request resolved spec is threaded to the wrap via a context key (`signer.WithRequestSpec(ctx, *SigningSpec)`), set on the per-call context in each per-item code path before calling `exec`. Rationale: wrapping `exec` once means **all four request paths** (sequential `executePhase`, parallel `parallel.ExecuteWaves`, sequential data-driven `executeDataDriven`, parallel data-driven `executeDataDrivenParallel`) inherit signing without per-path edits to the exec call sites. Per-call ctx threading is isolated to a single helper invoked just before `requtil.ToHTTPRequest`.

4. **Per-request precedence resolution** — a new helper `resolveSigningSpec(item parser.RequestItem, col *parser.Collection) *parser.SigningSpec` returns the effective spec. Precedence: per-request `signing:` (when non-nil and the YAML node was non-null) wins over collection-level. Explicit per-request `signing: null` disables signing for that request even if the collection has a default. The "explicit null" semantics requires distinguishing an unset field from an explicitly-null one — handled via a custom `UnmarshalYAML` on `SigningSpec` plus a sentinel pointer (described in step 2 below).

5. **Test-only noop signer** — registered in `internal/signer/noop_signer_test.go` (no build tag — Go's standard `_test.go` exclusion is sufficient and simpler than a custom build tag). The runner's integration test imports the noop fixture by living in the same package (`internal/runner/runner_test.go`) and using a plain Go test signer constructor. The CLI-level "dry-run shows X-Signed-By" observable in the task YAML is interpreted as a Go-level integration test (the production binary cannot register a `_test.go` signer at runtime). The remaining doc-fix and Go-level verifications still pass literally.

6. **Auth/profile.go is unchanged** — the M17 seam is sibling to `auth_profile`, never an extension. Verified by `git diff internal/auth/profile.go` showing zero lines (encoded as a Definition-of-Done check).

7. **`apitest run --dry-run` semantics** — left unchanged in this slice (it is currently a no-op without `--show-dependencies`). The end-to-end wiring proof comes from the runner-level integration test with the noop signer, not from a literal CLI dry-run. Wiring `--dry-run` to render full templated+signed requests is a separate UX task, not part of M17-001's foundation.

```go
// internal/signer/signer.go
//
// Package signer defines the contract and registry for first-party request
// signers. A Signer mutates an httpexec.Request in place to add signing
// material (typically headers, sometimes query params) just before the
// request is dispatched.
//
// # Clock seam
//
// The Signer interface deliberately does NOT carry a clock argument.
// Concrete signers that need a clock for testability (e.g. AWS SigV4 in
// M17-002, OAuth1 in M17-003) own it inside their own package — the
// convention is a Factory option WithClock(now func() time.Time)
// defaulting to time.Now. This matches the clock seam in
// Registry.now in internal/variable/dynamic.go. Most signers will never
// need a clock; threading it through the interface signature would force
// every implementer to carry an argument they ignore.
//
// # Sensitive values
//
// Each concrete signer is responsible for calling
// sensitives.AddValue(resolved) for any credential it resolves from a
// sensitive variable, mirroring the M12-005 $hmacSha256 pattern.
// AddValue is no-op safe on a nil set.
package signer

import (
    "context"
    "errors"
    "fmt"
    "sort"
    "strings"

    "github.com/peterlindqvist/apitest/internal/httpexec"
    "github.com/peterlindqvist/apitest/internal/variable"
)

// ErrUnknownSignerType is returned by Registry.Lookup when the requested
// type name is not registered. Callers wrap with fmt.Errorf to add the
// requested name and the sorted list of available types.
var ErrUnknownSignerType = errors.New("unknown signer type")

// Signer mutates an httpexec.Request to add signing material. Implementations
// must be safe to call on any *httpexec.Request and may add headers, mutate
// the body, or re-encode the URL. Implementations that resolve credentials
// from sensitive variables should register the resolved string value via
// sensitives.AddValue for redaction.
type Signer interface {
    Sign(ctx context.Context, req *httpexec.Request, sensitives *variable.SensitiveSet) error
}

// Factory builds a Signer from the YAML params: map. Returning a non-nil
// error fails the run before the request is dispatched; the factory must
// surface a structured, actionable error message.
type Factory func(params map[string]any) (Signer, error)

// Registry is a name-keyed lookup of signer factories.
type Registry struct {
    factories map[string]Factory
}

// NewBuiltinRegistry returns a registry preloaded with all first-party
// signers. In M17-001 the registry is empty; aws-sigv4 (M17-002) and
// oauth1 (M17-003) register themselves into NewBuiltinRegistry as they
// land.
func NewBuiltinRegistry() *Registry {
    return &Registry{factories: make(map[string]Factory)}
}

// Register associates name with factory. Returns an error when name is
// already registered (callers should treat this as a programming error).
func (r *Registry) Register(name string, factory Factory) error {
    if _, dup := r.factories[name]; dup {
        return fmt.Errorf("signer type %q already registered", name)
    }
    r.factories[name] = factory
    return nil
}

// Lookup returns the factory for name, or ErrUnknownSignerType wrapped
// with the requested name and a sorted, comma-joined list of registered
// types.
func (r *Registry) Lookup(name string) (Factory, error) {
    if f, ok := r.factories[name]; ok {
        return f, nil
    }
    available := make([]string, 0, len(r.factories))
    for n := range r.factories {
        available = append(available, n)
    }
    sort.Strings(available)
    if len(available) == 0 {
        return nil, fmt.Errorf("%w: %q; no signer types registered", ErrUnknownSignerType, name)
    }
    return nil, fmt.Errorf("%w: %q; available types: %s",
        ErrUnknownSignerType, name, strings.Join(available, ", "))
}

// requestSpecKey is the context key used to thread the resolved per-request
// signing spec through the runner's exec-wrap. Use WithRequestSpec /
// RequestSpecFromContext from the runner; the type is unexported to prevent
// collisions.
type requestSpecKey struct{}

// RequestSpec is the data the exec-wrap needs to invoke the right signer
// for the current request. The runner builds this once per request after
// resolving precedence (per-request > collection > none).
type RequestSpec struct {
    Type   string
    Params map[string]any
}

// WithRequestSpec returns a derived context carrying spec. Pass nil to
// indicate "no signing for this request".
func WithRequestSpec(ctx context.Context, spec *RequestSpec) context.Context {
    return context.WithValue(ctx, requestSpecKey{}, spec)
}

// RequestSpecFromContext returns the spec previously attached via
// WithRequestSpec, or nil when none is present.
func RequestSpecFromContext(ctx context.Context) *RequestSpec {
    v, _ := ctx.Value(requestSpecKey{}).(*RequestSpec)
    return v
}
```

```go
// internal/parser/collection.go — add at top of types section

// SigningSpec is the parsed `signing:` field on a Collection or RequestItem.
// Type names a registered signer in internal/signer; Params is forwarded
// verbatim to the signer factory.
//
// To distinguish "field absent" from "field present but explicitly null"
// (which disables signing for the request even if the collection has a
// default), the parser stores the field as **SigningSpec on Collection
// and *SigningSpec on RequestItem, with the inner pointer set to a
// sentinel SigningSpecNull when the YAML value was explicitly ~ or null.
// Use IsExplicitNull on a non-nil **SigningSpec to detect that case.
//
// In practice, runner code calls resolveSigningSpec(item, col) which
// folds the precedence and returns either a normalised *SigningSpec or
// nil ("no signing for this request").
type SigningSpec struct {
    Type   string         `yaml:"type"`
    Params map[string]any `yaml:"params,omitempty"`

    // explicitNull is set by UnmarshalYAML when the YAML node was
    // explicitly null (`signing: null` or `signing: ~`). Distinguished
    // from "field absent" (the **SigningSpec is nil) and from a normal
    // mapping (explicitNull is false, Type/Params are populated).
    explicitNull bool `yaml:"-"`
}

// IsExplicitNull reports whether the YAML field was explicitly null,
// disabling signing for that request even if the collection defaults to
// signing. Returns false on a nil receiver.
func (s *SigningSpec) IsExplicitNull() bool {
    if s == nil {
        return false
    }
    return s.explicitNull
}

// UnmarshalYAML decodes a signing: node into a SigningSpec. A null node
// sets explicitNull = true; a mapping decodes Type and Params normally
// and rejects an empty Type.
func (s *SigningSpec) UnmarshalYAML(value *yaml.Node) error {
    // yaml.v3 represents explicit null as Tag "!!null" and empty Value.
    if value.Tag == "!!null" || (value.Kind == yaml.ScalarNode && value.Value == "") {
        s.explicitNull = true
        return nil
    }
    if value.Kind != yaml.MappingNode {
        return fmt.Errorf("signing: expected mapping or null, got %v", value.Kind)
    }
    type signingRaw struct {
        Type   string         `yaml:"type"`
        Params map[string]any `yaml:"params,omitempty"`
    }
    var raw signingRaw
    if err := value.Decode(&raw); err != nil {
        return fmt.Errorf("signing: %w", err)
    }
    if raw.Type == "" {
        return fmt.Errorf("signing.type is required")
    }
    s.Type = raw.Type
    s.Params = raw.Params
    return nil
}
```

```go
// signing.go — new file alongside runner.go OR inlined into runner.go
// (placed in runner.go to avoid splintering the package).

// resolveSigningSpec folds collection-level + per-request precedence:
//   - per-request explicit null → returns nil (signing disabled)
//   - per-request non-nil non-null → returns the request spec
//   - per-request nil + collection non-nil → returns the collection spec
//   - both nil → returns nil
func resolveSigningSpec(item parser.RequestItem, col *parser.Collection) *parser.SigningSpec {
    if item.Signing != nil {
        if item.Signing.IsExplicitNull() {
            return nil
        }
        return item.Signing
    }
    if col.Signing != nil && !col.Signing.IsExplicitNull() {
        return col.Signing
    }
    return nil
}

// collectionUsesSigning reports whether any request in any phase, or the
// collection itself, declares a non-null signing spec. Used for the
// exec-wrap fast path.
func collectionUsesSigning(col *parser.Collection) bool {
    if col.Signing != nil && !col.Signing.IsExplicitNull() {
        return true
    }
    for _, sect := range []*parser.Section{&col.Setup, &col.Requests, &col.Teardown} {
        for i := range sect.Items {
            sp := sect.Items[i].Signing
            if sp != nil && !sp.IsExplicitNull() {
                return true
            }
        }
    }
    return false
}
```

```go
    if seenURL != "https://example.com/path" {
        t.Errorf("URL templating order regression: %q", seenURL)
    }
    if seenHeader != "noop" {
        t.Errorf("signer-injected header missing in exec; got %q", seenHeader)
    }
}

type noopFixtureSigner struct {
    header string
    value  string
}

func (s *noopFixtureSigner) Sign(_ context.Context, req *httpexec.Request, _ *variable.SensitiveSet) error {
    if s.header == "" {
        return nil
    }
    if req.Headers == nil {
        req.Headers = make(map[string]string)
    }
    req.Headers[s.header] = s.value
    return nil
}
```

## Risks and Edge Cases

- **Risk:** Threading the signing spec via `context.Context` is unidiomatic for in-process state. → **Mitigation:** the alternative is to thread an extra arg through `ExecuteFunc`, which would touch every executor signature and break public-ish surface (used by tests and by `internal/parallel`). The ctx approach is documented in the package comment plus a `// MUST be called immediately before exec` comment at every set site, with no other consumers reading the key. Stable and tested.

- **Risk:** Custom `UnmarshalYAML` on `SigningSpec` introduces nuance (explicit-null vs unset). → **Mitigation:** tested via four parser cases (null, missing, valid, scalar-rejection) plus the `IsExplicitNull` helper. yaml.v3's representation of explicit null (Tag `!!null` or empty scalar) is well-documented.

- **Risk:** The parallel main path silently skipping signing if `parallel.Config.PreExec` is missed. → **Mitigation:** dedicated `TestRunner_SignerStep_ParallelMainPath` case that asserts the injected header on every request in a 3-item parallel run.

- **Risk:** Signer wrap allocates on every `Run` even when only one of N items uses signing. → **Mitigation:** that's intentional and matches the Hooks fast-path semantics. A single allocation per Run is below noise; the fast-path is at the *exec-call-site* via `RequestSpecFromContext == nil ? unwrapped : signer-path`.

- **Edge case:** Collection with `setup:` items that use signing but main items don't, or vice-versa. → **Handling:** `collectionUsesSigning` walks setup, main, and teardown, so any phase containing a signing field allocates the wrap.

- **Edge case:** `signing: {type: x}` with empty `params:`. → **Handling:** `Params` decodes as nil; factories receive `map[string]any(nil)` and must handle it (the `noop` test signer does; M17-002/003 will validate their own param shapes).

- **Edge case:** `signing` at the include-spliced level — does an included collection's collection-level `signing:` flow through? → **Handling:** `parser.resolveIncludes` already does a deep merge of fields; the `Signing` field follows the same rules as `Variables` and `Retry`. Documented in code comment; covered by an additional fixture-driven test if `resolveIncludes` does *not* propagate the field after manual inspection (verified in step 2 implementation; if it doesn't, file a one-line TODO and fix in step 2's commit).

- **Edge case:** Signer's `Sign` returns an error. → **Handling:** the wrap returns `(nil, fmt.Errorf("signer %q: %w", spec.Type, signErr))`. The retry loop sees the error like any other exec error; `RequestResult.Err` is populated; the request is recorded as `error` (not `fail`) per the behaviour bullet.

- **Edge case:** Refresh-on-failure (401) re-execs the request. → **Handling:** the re-exec branch at line 1811 must also wrap ctx with the signing spec so the second attempt is signed. Step 3 explicitly covers this.
