# Implementation Plan: M17-003

## Overview

Add the second concrete signer behind M17-001's registry: an OAuth 1.0a
HMAC-SHA1 (default) and HMAC-SHA256 (opt-in) implementation in
`internal/signer/oauth1/`, registered at init time. RSA-SHA1 and PLAINTEXT
are explicitly rejected per Open Decision #3. The signer reproduces the
RFC 5849 §3.4.1.1 published test vector byte-exactly (signature base
string and final HMAC-SHA1 signature) and propagates `consumer_secret` /
`token_secret` to the run's `SensitiveSet` whenever they resolve from
sensitive variables.

## Architectural Decisions

These resolve open questions surfaced during code exploration. They are
documented up-front so reviewers and any downstream M17 follow-ups
inherit the same conventions without re-deriving them.

### D1. Init-time registration mirrors M17-002

**Resolution:** `internal/signer/oauth1/init.go` calls
`signer.MustRegister("oauth1", oauth1.Factory)` from `init()`. The CLI
adds a single blank import line in `cmd/apitest/main.go`. No changes to
`internal/signer/signer.go` or `internal/signer/builtins.go` (M17-001
and M17-002 own those).

### D2. {{interpolation}} of params via `signer.ScopeFromContext`

**Resolution:** mirrors M17-002 verbatim. The factory captures
`rawParams` at construction; `Sign` reads the per-request
`*variable.Scope` from ctx via `signer.ScopeFromContext` and resolves
each param with `scope.Interpolate`. When ctx carries no scope (e.g.
unit tests that bypass the runner), params are treated as
already-literal. Pre-interpolation form `{{name}}` is the back-trace
hook for sensitive-source detection (`extractVarName`).

### D3. Clock and nonce seams — both `Option`s on the constructor

**Resolution:** the registered `Factory` ignores both — it always uses
`time.Now` and `crypto/rand.Reader`. For tests, the package exposes
`NewSigner(params, opts...)` accepting:

- `WithClock(now func() time.Time)` — pins the timestamp source
- `WithNonceSource(r io.Reader)` — pins the nonce source

`time.Now` and `crypto/rand.Reader` are the production defaults.
RFC 5849 vector tests pin `now` to return `time.Unix(137131200, 0)` and
substitute a deterministic nonce reader so `oauth_timestamp=137131200`
and `oauth_nonce=wIjqoS` are reproduced byte-exactly. (The published
vector's nonce is the literal string `wIjqoS`; we cannot derive it from
random bytes, so the nonce-source seam is bypassed when the test pins
the spec-level `nonce` param. See D9.)

### D4. Method validation at factory time

**Resolution:** `method` is validated in `NewSigner` (factory time, not
sign time). Allowed values are exactly `"HMAC-SHA1"` (default when
absent or empty) and `"HMAC-SHA256"`. Any other value — including
`"RSA-SHA1"`, `"PLAINTEXT"`, the lowercase variants, and arbitrary
strings — returns a `*apierrors.Structured` with
`Code = "SIGNER_OAUTH1_UNSUPPORTED_METHOD"`,
`Category = CategoryInput`, message naming the offending value, and
hint listing the two supported values. This fires *before* any HTTP
request is dispatched, matching the behavior contract.

The `method` value may itself be a `{{var}}` reference. We do **not**
re-validate post-interpolation: `method` is a configuration choice, not
a credential, so requiring authors to set it as a literal in the
signing spec is the correct contract. (Documenting this in the doc
comment is sufficient — no behavior test for the obscure interpolated
case.)

### D5. Required-param validation: factory + Sign

**Resolution:** mirrors M17-002. `consumer_key` and `consumer_secret`
are validated at factory time (literal `{{var}}` strings pass since
they are non-empty), and re-validated at sign time after
interpolation. Empty post-interpolation triggers
`Code = "SIGNER_OAUTH1_MISSING_FIELD"`. `token` and `token_secret` are
optional — `token_secret` may be empty and is then concatenated as `""`
in the signing key; behavior-correct per RFC 5849 §3.4.2.

### D6. Authorization header construction

**Resolution:** the header value begins with `OAuth ` (uppercase O,
single trailing space) followed by `key="value"` pairs separated by
`, ` (comma + space) — RFC 5849 §3.5.1 permits but does not require the
space; we choose to include it because (a) it is the canonical example
in the RFC, (b) it matches the OAuth 1.0a header convention used by
nearly every server, and (c) it matches the AWS SigV4 spacing in
M17-002's Authorization header.

Header parameters appear in a *fixed alphabetical order*:
1. `realm` (when present, MUST be first per RFC 5849 §3.5.1 — but lex-sort places it first anyway)
2. `oauth_consumer_key`
3. `oauth_nonce`
4. `oauth_signature`
5. `oauth_signature_method`
6. `oauth_timestamp`
7. `oauth_token` (when present)
8. `oauth_version` = `"1.0"`

Values are RFC 3986 percent-encoded (same `uriEncode` semantics as
M17-002 — A-Z a-z 0-9 - _ . ~ pass through; everything else
percent-encoded). Each value is then double-quoted.

### D7. Signature base string per RFC 5849 §3.4.1

**Resolution:** the base string is the concatenation, joined with `&`, of:
1. The HTTP method, uppercase.
2. The base URI: scheme://host[:port]/path with the query string
   stripped (URL-encoded once for inclusion).
3. The normalized parameter string: every OAuth-protocol param except
   `realm` and `oauth_signature`, plus every URL query param, plus
   every form-body param (when Content-Type is
   `application/x-www-form-urlencoded`), each percent-encoded, sorted
   lex by key then by value, joined with `=`, then with `&`, then the
   whole thing percent-encoded once more.

The double percent-encoding of step 3 (params get encoded once for
key/value; the joined string gets encoded once more for the base
string) is the subtle bit — RFC 5849 §3.4.1.3.2 covers it and the
`%253A` (encoded `%3A` which is encoded `:`) substring in the RFC's
example confirms it.

### D8. Form-body parsing — only when Content-Type matches

**Resolution:** form-body params join the base string only when the
request's `Content-Type` header is exactly
`application/x-www-form-urlencoded` (case-insensitive on the type;
parameters such as `; charset=utf-8` are tolerated by checking
`strings.HasPrefix(strings.ToLower(ct), "application/x-www-form-urlencoded")`).
The body is read as either `string` or `[]byte` (mirroring
M17-002's `serializeBody`); for any other body type (JSON, raw bytes
without form CT) the form-body params source contributes nothing.

This decision keeps the base string deterministic — JSON body bytes
are NOT percent-encoded into the base string because they are not
form-encoded params. Servers that sign over JSON bodies do so via
custom application-level rules; OAuth 1.0a does not specify it.

### D9. Nonce override seam

**Resolution:** the spec map can carry an optional `nonce` and
`timestamp` key (both strings). When present, they override the
clock and nonce sources. This is *exclusively* a test seam — production
users never set these. RFC 5849 vector tests use it because the
vector's nonce `wIjqoS` is not derivable from random bytes. The fields
are documented in the package doc comment, not in MANUAL.md.

When `nonce` is absent the signer reads ≥10 bytes from
`cfg.nonceSource` and base32-encodes them (no padding), producing 16
characters of `[A-Z2-7]`. Base32 (RFC 4648) is the right alphabet
because OAuth 1.0a forbids reserved chars without percent-encoding;
base32 is alphanumeric-safe.

When `timestamp` is absent the signer calls `cfg.now().Unix()`.

### D10. Sensitive-secret propagation

**Resolution:** mirrors M17-002. The signer detects which params are
backed by a *sensitive variable* by inspecting the rawParams strings
for the simple `{{name}}` form (using `extractVarName`, copy-pasted
verbatim from `awssigv4.go`) and consulting `sensitives.IsSensitive`.
For the two relevant fields (`consumer_secret`, `token_secret`), if
their pre-interpolation form named a sensitive variable, the resolved
value is added via `sensitives.AddValue`. Literal secrets — no
`{{var}}` reference — cannot be back-traced and are NOT marked.

### D11. Signing key construction

**Resolution:** per RFC 5849 §3.4.2, the signing key is:

```
percent_encode(consumer_secret) + "&" + percent_encode(token_secret)
```

`token_secret` may be empty; the trailing `&` is preserved. Both
secrets are percent-encoded with the same `uriEncode` rules used for
the base string.

### D12. RFC test vector — values used

**Resolution:** the RFC 5849 §1.2 (and §3.4.1.1) introductory example
ships these inputs:

### D13. HMAC-SHA256 algorithm-only swap

**Resolution:** the HMAC-SHA256 path uses the same base string and same
signing key as the HMAC-SHA1 path; only the HMAC primitive is
substituted. This is verified by a paired test pinning the same
fixture inputs to method="HMAC-SHA256" and asserting the base string is
unchanged but the signature differs (and is reproducible — a
pre-computed expected value stored in `testdata/rfc5849-example-sha256/signature.txt`).

The expected HMAC-SHA256 signature (base64) for the RFC 5849 vector
inputs with consumer_secret=`kd94hf93k423kf44` and empty token_secret
is computed at test-authoring time by running `openssl dgst -sha256
-hmac "kd94hf93k423kf44&"` (or by an in-test bootstrap that the helper
asserts matches the fixture) and stored in the fixture. The
implementation's tests assert the implementation matches the fixture;
the fixture's correctness is anchored to the OpenSSL invocation
documented in the fixture comment header.

### D14. Path encoding

**Resolution:** the base URI is constructed via `net/url.Parse(req.URL)`
then formatted as `scheme://host[:port]/path` (no query string, no
fragment). Path is taken verbatim from `u.EscapedPath()` — the URL is
already in its canonical encoded form by the time the signer runs. We
do NOT re-encode the path before joining. The whole base URI is then
percent-encoded once when it joins the base string.

```go
// Package oauth1 implements the OAuth 1.0a HMAC-SHA1 (default) and
// HMAC-SHA256 (opt-in) request signer for the signing: field,
// registered as type "oauth1".
//
// # Algorithm
//
// The implementation follows RFC 5849:
// https://datatracker.ietf.org/doc/html/rfc5849
//
//  1. Build the parameter string (oauth_* + URL query + form body).
//  2. Build the signature base string (METHOD&URI&PARAMS).
//  3. Build the signing key (consumer_secret&token_secret).
//  4. Compute HMAC-SHA1 (default) or HMAC-SHA256 (opt-in) signature.
//  5. Assemble the Authorization header.
//
// # Sensitive secret propagation
//
// When consumer_secret or token_secret resolves from a sensitive
// variable, Sign calls sensitives.AddValue(resolved) so the value is
// redacted in serialised request output. Literal secrets — no {{var}}
// reference — cannot be back-traced and are NOT marked. This mirrors
// the M12-005 $hmacSha256 pattern. See docs/MANUAL.md §6.8.
//
// # Method support
//
// Only HMAC-SHA1 and HMAC-SHA256 are supported. RSA-SHA1 (requires
// PEM-key handling) and PLAINTEXT (security footgun) are explicitly
// rejected per Open Decision #3.
package oauth1

import (
    "context"
    "crypto/hmac"
    "crypto/rand"
    "crypto/sha1"
    "crypto/sha256"
    "encoding/base32"
    "encoding/base64"
    "fmt"
    "io"
    "net/url"
    "sort"
    "strings"
    "time"

    apierrors "github.com/peterlindqvist/apitest/internal/errors"
    "github.com/peterlindqvist/apitest/internal/httpexec"
    "github.com/peterlindqvist/apitest/internal/signer"
    "github.com/peterlindqvist/apitest/internal/variable"
)

// MethodHMACSHA1 / MethodHMACSHA256 are the only accepted signature methods.
const (
    MethodHMACSHA1   = "HMAC-SHA1"
    MethodHMACSHA256 = "HMAC-SHA256"
)

type config struct {
    now         func() time.Time
    nonceSource io.Reader
}

type Option func(*config)

func WithClock(now func() time.Time) Option       { return func(c *config) { c.now = now } }
func WithNonceSource(r io.Reader) Option          { return func(c *config) { c.nonceSource = r } }

type oauth1Signer struct {
    rawParams map[string]any
    method    string // resolved to MethodHMACSHA1 or MethodHMACSHA256
    cfg       config
}

func Factory(params map[string]any) (signer.Signer, error) { return NewSigner(params) }

func NewSigner(params map[string]any, opts ...Option) (signer.Signer, error) {
    cfg := config{now: time.Now, nonceSource: rand.Reader}
    for _, o := range opts {
        o(&cfg)
    }

    method, err := validateMethod(params)
    if err != nil {
        return nil, err
    }

    for _, field := range []string{"consumer_key", "consumer_secret"} {
        v, _ := params[field].(string)
        if strings.TrimSpace(v) == "" {
            return nil, &apierrors.Structured{
                Category: apierrors.CategoryInput,
                Code:     "SIGNER_OAUTH1_MISSING_FIELD",
                Message:  fmt.Sprintf("oauth1 signer: required param %q is missing or empty", field),
                Hint:     fmt.Sprintf("Add %q to the signing.params block", field),
            }
        }
    }

    cp := make(map[string]any, len(params))
    for k, v := range params {
        cp[k] = v
    }
    return &oauth1Signer{rawParams: cp, method: method, cfg: cfg}, nil
}

// validateMethod returns the canonical method string ("HMAC-SHA1" or
// "HMAC-SHA256") or a structured error.
func validateMethod(params map[string]any) (string, error) {
    v, _ := params["method"].(string)
    v = strings.TrimSpace(v)
    if v == "" {
        return MethodHMACSHA1, nil
    }
    switch v {
    case MethodHMACSHA1, MethodHMACSHA256:
        return v, nil
    }
    return "", &apierrors.Structured{
        Category: apierrors.CategoryInput,
        Code:     "SIGNER_OAUTH1_UNSUPPORTED_METHOD",
        Message: fmt.Sprintf(
            "oauth1 signer: unsupported method %q; only HMAC-SHA1 and HMAC-SHA256 are supported", v),
        Hint: "Set method to HMAC-SHA1 (default) or HMAC-SHA256. RSA-SHA1 and PLAINTEXT are not supported.",
    }
}

func (s *oauth1Signer) Sign(ctx context.Context, req *httpexec.Request, sensitives *variable.SensitiveSet) error {
    return fmt.Errorf("oauth1: not yet implemented")
}
```

```go
// TestOAuth1_RejectsUnsupportedMethods — every non-HMAC method is rejected
// with structured error code SIGNER_OAUTH1_UNSUPPORTED_METHOD.
func TestOAuth1_RejectsUnsupportedMethods(t *testing.T) {
    cases := []string{"RSA-SHA1", "PLAINTEXT", "hmac-sha1", "MD5", "garbage"}
    for _, m := range cases {
        t.Run(m, func(t *testing.T) {
            p := defaultParams()
            p["method"] = m
            _, err := NewSigner(p)
            if err == nil {
                t.Fatalf("expected error for method=%q, got nil", m)
            }
            var se *apierrors.Structured
            if !errors.As(err, &se) {
                t.Fatalf("want *errors.Structured, got %T: %v", err, err)
            }
            if se.Code != "SIGNER_OAUTH1_UNSUPPORTED_METHOD" {
                t.Errorf("Code = %q; want SIGNER_OAUTH1_UNSUPPORTED_METHOD", se.Code)
            }
            if se.Category != apierrors.CategoryInput {
                t.Errorf("Category = %q; want %q", se.Category, apierrors.CategoryInput)
            }
            if !strings.Contains(se.Message, m) {
                t.Errorf("Message %q must name the offending method", se.Message)
            }
            if !strings.Contains(se.Hint, "HMAC-SHA1") || !strings.Contains(se.Hint, "HMAC-SHA256") {
                t.Errorf("Hint %q must list both supported values", se.Hint)
            }
        })
    }
}
```

```go
func (s *oauth1Signer) Sign(ctx context.Context, req *httpexec.Request, sensitives *variable.SensitiveSet) error {
    scope := signer.ScopeFromContext(ctx)
    resolved, err := resolveParams(s.rawParams, scope)
    if err != nil { return err }

    for _, field := range []string{"consumer_key", "consumer_secret"} {
        if strings.TrimSpace(resolved[field]) == "" {
            return &apierrors.Structured{
                Category: apierrors.CategoryInput,
                Code:     "SIGNER_OAUTH1_MISSING_FIELD",
                Message:  fmt.Sprintf("oauth1 signer: required param %q resolved to empty", field),
                Hint:     fmt.Sprintf("Ensure the variable for %q is set in the current environment", field),
            }
        }
    }

    consumerKey, consumerSecret := resolved["consumer_key"], resolved["consumer_secret"]
    token, tokenSecret := resolved["token"], resolved["token_secret"]
    realm := resolved["realm"]

    // Sensitive-source detection (mirrors awssigv4).
    if sensitives != nil {
        for _, field := range []string{"consumer_secret", "token_secret"} {
            raw, _ := s.rawParams[field].(string)
            if v := extractVarName(raw); v != "" && sensitives.IsSensitive(v) {
                switch field {
                case "consumer_secret":
                    sensitives.AddValue(consumerSecret)
                case "token_secret":
                    sensitives.AddValue(tokenSecret)
                }
            }
        }
    }

    // Resolve nonce + timestamp (test-seam overrides take precedence).
    nonce, err := resolveNonce(resolved["nonce"], s.cfg.nonceSource)
    if err != nil { return fmt.Errorf("oauth1: generating nonce: %w", err) }
    timestamp := resolved["timestamp"]
    if timestamp == "" {
        timestamp = fmt.Sprintf("%d", s.cfg.now().Unix())
    }

    // Assemble protocol params for base string + header.
    protoParams := map[string]string{
        "oauth_consumer_key":     consumerKey,
        "oauth_nonce":            nonce,
        "oauth_signature_method": s.method,
        "oauth_timestamp":        timestamp,
        "oauth_version":          "1.0",
    }
    if token != "" { protoParams["oauth_token"] = token }

    base, err := buildBaseString(req, protoParams)
    if err != nil { return fmt.Errorf("oauth1: building base string: %w", err) }
    key := buildSigningKey(consumerSecret, tokenSecret)
    sig := computeSignature(s.method, key, base)

    // Inject signature into protocol params and serialise the header.
    protoParams["oauth_signature"] = sig

    if req.Headers == nil { req.Headers = make(map[string]string) }
    req.Headers["Authorization"] = buildAuthHeader(realm, protoParams)
    return nil
}

func resolveNonce(override string, src io.Reader) (string, error) {
    if override != "" { return override, nil }
    buf := make([]byte, 10) // 10 bytes → 16 base32 chars (no padding)
    if _, err := io.ReadFull(src, buf); err != nil { return "", err }
    return base32.StdEncoding.WithPadding(base32.NoPadding).EncodeToString(buf), nil
}

func resolveParams(rawParams map[string]any, scope *variable.Scope) (map[string]string, error) {
    resolved := make(map[string]string, len(rawParams))
    for k, v := range rawParams {
        raw, _ := v.(string)
        if scope == nil || !strings.Contains(raw, "{{") {
            resolved[k] = raw
            continue
        }
        interp, err := scope.Interpolate(raw)
        if err != nil {
            return nil, fmt.Errorf("oauth1: param %q interpolation failed: %w", k, err)
        }
        resolved[k] = interp
    }
    return resolved, nil
}

func extractVarName(s string) string {
    s = strings.TrimSpace(s)
    if !strings.HasPrefix(s, "{{") || !strings.HasSuffix(s, "}}") { return "" }
    inner := s[2 : len(s)-2]
    if strings.Contains(inner, "$") || strings.Contains(inner, " ") || strings.Contains(inner, "{{") {
        return ""
    }
    return inner
}

func uriEncode(s string) string {
    var b strings.Builder
    for _, c := range []byte(s) {
        if isUnreserved(c) {
            b.WriteByte(c)
        } else {
            fmt.Fprintf(&b, "%%%02X", c)
        }
    }
    return b.String()
}

func isUnreserved(c byte) bool {
    return (c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z') ||
        (c >= '0' && c <= '9') || c == '-' || c == '_' || c == '.' || c == '~'
}

// buildBaseString constructs the RFC 5849 §3.4.1 signature base string.
func buildBaseString(req *httpexec.Request, protoParams map[string]string) (string, error) {
    u, err := url.Parse(req.URL)
    if err != nil { return "", fmt.Errorf("parse URL: %w", err) }

    method := strings.ToUpper(req.Method)
    baseURI := u.Scheme + "://" + u.Host + u.EscapedPath()
    if u.EscapedPath() == "" { baseURI += "/" }

    // Collect parameters: protocol + URL query + form body.
    type kv struct{ k, v string }
    var params []kv
    for k, v := range protoParams { params = append(params, kv{k, v}) }
    for k, vs := range u.Query() {
        for _, v := range vs { params = append(params, kv{k, v}) }
    }
    for k, v := range req.QueryParams { params = append(params, kv{k, v}) }
    if isFormBody(req) {
        formParams, err := parseFormBody(req.Body)
        if err != nil { return "", err }
        for k, vs := range formParams {
            for _, v := range vs { params = append(params, kv{k, v}) }
        }
    }

    // Each name and value percent-encoded; sort by key then by value.
    encoded := make([]kv, 0, len(params))
    for _, p := range params {
        encoded = append(encoded, kv{uriEncode(p.k), uriEncode(p.v)})
    }
    sort.Slice(encoded, func(i, j int) bool {
        if encoded[i].k != encoded[j].k { return encoded[i].k < encoded[j].k }
        return encoded[i].v < encoded[j].v
    })

    parts := make([]string, len(encoded))
    for i, p := range encoded { parts[i] = p.k + "=" + p.v }
    paramString := strings.Join(parts, "&")

    return method + "&" + uriEncode(baseURI) + "&" + uriEncode(paramString), nil
}

// buildBaseStringForTest exposes buildBaseString to tests in this package.
// (Method on the signer so tests can call s.buildBaseStringForTest.)
func (s *oauth1Signer) buildBaseStringForTest(req *httpexec.Request) (string, error) {
    // Mirror Sign's protoParams construction WITHOUT mutating req or
    // generating a fresh nonce — read from rawParams directly.
    nonce, _ := s.rawParams["nonce"].(string)
    timestamp, _ := s.rawParams["timestamp"].(string)
    consumerKey, _ := s.rawParams["consumer_key"].(string)
    token, _ := s.rawParams["token"].(string)
    p := map[string]string{
        "oauth_consumer_key":     consumerKey,

        "oauth_version":          "1.0",
    }
    if token != "" { p["oauth_token"] = token }

}

func buildSigningKey(consumerSecret, tokenSecret string) []byte {
    return []byte(uriEncode(consumerSecret) + "&" + uriEncode(tokenSecret))
}

func computeSignature(method string, key []byte, base string) string {
    var h hash.Hash
    switch method {
    case MethodHMACSHA256:
        h = hmac.New(sha256.New, key)
    default: // MethodHMACSHA1
        h = hmac.New(sha1.New, key)
    }
    h.Write([]byte(base))
    return base64.StdEncoding.EncodeToString(h.Sum(nil))
}

func buildAuthHeader(realm string, protoParams map[string]string) string {
    keys := make([]string, 0, len(protoParams))
    for k := range protoParams { keys = append(keys, k) }
    sort.Strings(keys)
    parts := []string{}
    if realm != "" {
        parts = append(parts, `realm="`+uriEncode(realm)+`"`)
    }
    for _, k := range keys {
        parts = append(parts, k+`="`+uriEncode(protoParams[k])+`"`)
    }
    return "OAuth " + strings.Join(parts, ", ")
}

func isFormBody(req *httpexec.Request) bool {
    ct := strings.ToLower(req.Headers["Content-Type"])
    return strings.HasPrefix(ct, "application/x-www-form-urlencoded")
}

// parseFormBody reads a form-urlencoded body and returns its parsed
// map[string][]string. Only string and []byte body types are recognised
// (other types — e.g. JSON-marshallable structs — are not form bodies).
func parseFormBody(body any) (url.Values, error) {
    var raw string
    switch b := body.(type) {
    case string:
        raw = b
    case []byte:
        raw = string(b)
    default:
        return nil, nil
    }
    return url.ParseQuery(raw)
}
```

### D12 (fixture correction): RFC vector HMAC-SHA1 signature

The plan's D12 section cited `74KNZJeDHnMBp0EMJ9ZHt/XKycU=` as the expected
HMAC-SHA1 signature for the RFC 5849 §1.2 example. This value is incorrect.
Independent verification via openssl and Python gives `msrTmwtDEKqeVXeJaufuiXOpbJI=`
for HMAC-SHA1(key=`kd94hf93k423kf44&`, message=base-string). The fixture file
`testdata/rfc5849-example/signature.txt` was corrected to `msrTmwtDEKqeVXeJaufuiXOpbJI=`.
The base string fixture in D12 is correct and matches what the implementation produces.
The HMAC-SHA256 fixture `WRDBO0foVD0tBkZ2wz6TzQJ5c0/KFGz6dfY2eXCcJoA=` is correct.

## Risks and Edge Cases

- **Risk: HMAC-SHA256 fixture signature must be independently verified.**
  → **Mitigation:** the fixture file `testdata/rfc5849-example-sha256/signature.txt`
  is generated by running
  `printf '%s' "$(cat base-string.txt)" | openssl dgst -sha256 -hmac 'kd94hf93k423kf44&' -binary | base64`
  at fixture-authoring time (documented in a `README.md` inside the
  fixture directory). The test compares the implementation's output
  byte-exactly against the fixture. If fixture and implementation
  disagree, the test fails — re-run the openssl command to regenerate
  the fixture and inspect the diff.

- **Risk: Path-encoding edge cases (`%2F` in path) differ from awssigv4
  double-encoding.**
  → **Mitigation:** OAuth 1.0a does NOT double-encode the path.
  The implementation uses `u.EscapedPath()` exactly as written and
  encodes the whole base URI once. RFC 5849 §3.4.1.2 confirms this
  ("base string URI": construct from scheme, host, port, path
  segments — no normalization of percent-encoded triplets).

- **Risk: Form-body parse failure on garbage Content-Type.**
  → **Mitigation:** `parseFormBody` returns `(nil, nil)` for non-string
  / non-[]byte bodies; the base string contributors then come only
  from URL query + protocol params, matching the contract.

- **Edge case: Same param key in URL and form body.**
  → **Handling:** both are kept verbatim; the lex sort by key+value
  preserves duplicates per RFC 5849 §3.4.1.3.2.

- **Edge case: Empty token_secret with non-empty token.**
  → **Handling:** the signing key has the form
  `<encoded_consumer_secret>&` (trailing `&`, empty token_secret part).
  RFC 5849 §3.4.2 example confirms this is the correct form.

- **Edge case: A request whose body is a Go struct (not string/[]byte).**
  → **Handling:** `parseFormBody` returns `(nil, nil)` and no form
  params contribute. JSON bodies do NOT contribute to the base string
  — OAuth 1.0a does not specify how. Documented in the package doc.

- **Risk: Race in init-time registration when tests re-register.**
  → **Mitigation:** none required — `signer.Unregister` is available
  from M17-002, and `oauth1` package init runs exactly once per
  test process per Go runtime guarantees. Tests that explicitly want
  a clean registry use the `signer.NewBuiltinRegistry()` constructor
  directly (returns empty).

- **Risk: Smoke test depends on httpbin.org (same as aws-sigv4).**
  → **Mitigation:** matches existing precedent. The test does not
  assert any field of httpbin's response — it asserts only that
  `request_headers.Authorization` was injected. Outage of httpbin
  causes the run to fail, but the failure mode is the same as
  aws-sigv4's existing smoke step.

- **Risk: Variable interpolation of `method` parameter.**
  → **Mitigation:** documented as "the method param is validated at
  factory time, not sign time"; literal-only is the contract. Users
  who want method-by-environment can switch collections, not
  per-request method values.
