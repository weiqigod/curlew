# Implementation Plan: M14-007

## Overview

Replace the CLI's RS256-only `VerifyRS256` with an algorithm-agnostic `VerifyJWT(token, jwks)` that dispatches on the JWS header `alg` against a hard allowlist of `{"ES256"}`, add an HTTP-backed `OnlineFetcher` that pulls the JWKS from `/api/v1/.well-known/jwks.json` (and writes through to `~/.config/curlew/jwks_cache.json`), and migrate every test fixture and embedded JWKS from RS256 → ES256 so that the new contract is the only contract in the tree.

## Architectural Decisions (resolved up-front)

1. **Allowlist is exactly `{"ES256"}` per behaviour 4.** The spec calls the verifier "algorithm-agnostic" so the dispatcher table will be a private map; the *initial* table contains a single entry. The map structure (`map[string]algVerifier`) makes adding RS256/EdDSA later a one-line change but the production allowlist is `{"ES256"}` today, with no compile-time aliases for RS256.
2. **All existing RS256 fixtures are regenerated as ES256.** This is mandated by behaviour 4 — keeping any RS256 fixture would mean the verifier still accepts RS256, which contradicts the allowlist. Affected files: `internal/license/keys/jwks.json` (embedded), `internal/license/keys/testdata/{private.pem,private2.pem,jwks_extra.json,license.json}`, `internal/license/keys/testdata/generate.go`, and the `testdata/m14/stub_server.go` minter.
3. **`kid` format moves to the production scheme `<env>-es256-<YYYYMM>-<6char-uuid>`** per spec :8060. The two test kids become `dev-es256-202605-a3f4d2` (primary, observable) and `dev-es256-202605-b8c1e7` (secondary, used by the cached-fallback test). The existing `curlew-2025-01` / `curlew-2025-02` strings are removed everywhere — no aliasing.
4. **Behaviour 5 (`typ == "license+jwt"`) is enforced by `VerifyJWT`.** The minter helpers in `jwt_fixtures_test.go` and `stub_server.go` move from `typ: "JWT"` → `typ: "license+jwt"`. This is a clean break because (a) the field is mandatory after this slice and (b) every minter we control updates together.
5. **Cache-Control max-age=3600 is a soft TTL (behaviour 7).** The cache file gains a sibling `jwks_cache.meta.json` with `{"fetched_at": "<RFC3339>", "max_age_seconds": 3600}`. The resolver consults the cache *before* the online fetch (existing order), and the soft-TTL is used by a new `(*JWKSClient).Fetch` to short-circuit a fresh network request when the cache is still warm. Stale-cache fallback during backend outages remains permitted: the resolver already prefers cached data over a failed fetch — the soft TTL only governs *whether to attempt a fetch* in the online path. Implementing this without restructuring the resolver: the soft-TTL check lives inside `JWKSClient.FetchJWKS` (the `OnlineFetcher` impl) so the resolver is unchanged.
6. **`internal/backend.JWKSClient` is the new HTTP client wrapper.** It implements `license.OnlineFetcher` so the existing resolver chain (embedded → bundle → cached → online) remains the single source of truth — no resolver rewrite. This honours the M14-004 boundary (all HTTP work lives in `internal/backend/`) and gives us a place to handle `Cache-Control` parsing without polluting the license package with HTTP concerns.
7. **No alias for `VerifyRS256`.** Behaviour 6 is explicit: "the function is renamed VerifyJWT(token, jwks) ... and the old name is removed". One commit removes both `VerifyRS256` and the `*rsa.PublicKey` parameter from the call site, swapping in `VerifyJWT(tok, jwks *jwks.Set)`.

```go
// Sentinel errors specific to the algorithm-agnostic verifier.
var (
    ErrInvalidAlgorithm = errors.New("license: invalid_algorithm")
    ErrInvalidType      = errors.New("license: invalid_type")
)

// licenseJWTType is the RFC 8725 §3.11 explicit type for License JWTs.
const licenseJWTType = "license+jwt"

// algVerifier resolves a public key from a JWKS set and verifies a signature.
type algVerifier func(set *jwks.Set, kid string, signed, sig []byte) error

// algRegistry maps the JWS header `alg` to its verifier.
// Allowlist-as-data: any alg not in this map is rejected with ErrInvalidAlgorithm
// (RFC 8725 §3.1). The registry is package-private; production allowlist is {ES256}
// per docs/SPECIFICATION.md:7990 (algorithm-agnostic verifier, initial allowlist {ES256}).
var algRegistry = map[string]algVerifier{
    "ES256": verifyES256,
}

// VerifyJWT verifies tok against set per the License JWT verification process
// (docs/SPECIFICATION.md:7990-8011).
//   1. Reject if Header.Typ != "license+jwt"      (RFC 8725 §3.11)
//   2. Reject if Header.Alg not in algRegistry    (RFC 8725 §3.1)
//   3. Look up Header.Kid in set (algorithm-specific)
//   4. Verify signature
func VerifyJWT(tok *Token, set *jwks.Set) error {
    if tok.Header.Typ != licenseJWTType {
        return fmt.Errorf("%w: typ=%q want %q", ErrInvalidType, tok.Header.Typ, licenseJWTType)
    }
    verify, ok := algRegistry[tok.Header.Alg]
    if !ok {
        return fmt.Errorf("%w: alg=%q", ErrInvalidAlgorithm, tok.Header.Alg)
    }
    return verify(set, tok.Header.Kid, tok.signed, tok.signature)
}

func verifyES256(set *jwks.Set, kid string, signed, sig []byte) error {
    pub, ok := set.LookupES256(kid)
    if !ok {
        return fmt.Errorf("%w: kid=%s", ErrKeyNotFound, kid)
    }
    if len(sig) != 64 {
        return fmt.Errorf("%w: ES256 signature length=%d want 64", ErrSignatureInvalid, len(sig))
    }
    sum := sha256.Sum256(signed)
    r := new(big.Int).SetBytes(sig[:32])
    s := new(big.Int).SetBytes(sig[32:])
    if !ecdsa.Verify(pub, sum[:], r, s) {
        return fmt.Errorf("%w: ES256 verify failed", ErrSignatureInvalid)
    }
    return nil
}

package backend

import (

const (
    // JWKSPath is the well-known JWKS endpoint per RFC 8615.
    // Refs docs/SPECIFICATION.md:8237 + :8058.
    JWKSPath = "/api/v1/.well-known/jwks.json"

    // jwksCacheFile is the on-disk cache of the latest server JWKS.
    // Mode 0600. Refs docs/SPECIFICATION.md:8009.
    jwksCacheFile     = "jwks_cache.json"
    jwksCacheMetaFile = "jwks_cache.meta.json"

    // defaultMaxAge is used when the server omits Cache-Control max-age.
    defaultMaxAge = 3600 * time.Second
)

// JWKSClient fetches and caches the License-JWT verifying JWKS from the backend.
// Implements license.OnlineFetcher.
type JWKSClient struct {
    client   *Client
    cfgDir   string
    now      func() time.Time
}

// NewJWKSClient constructs a JWKSClient bound to cfgDir.
func NewJWKSClient(client *Client, cfgDir string) *JWKSClient {
    return &JWKSClient{client: client, cfgDir: cfgDir, now: time.Now}
}

type jwksCacheMeta struct {
    FetchedAt      time.Time `json:"fetched_at"`
    MaxAgeSeconds  int       `json:"max_age_seconds"`
}

// FetchJWKS implements license.OnlineFetcher. It returns a fresh JWKS from the
// backend, falling back to the on-disk cache if the soft TTL has not elapsed.
// On a successful fetch it persists jwks_cache.json (mode 0600) and
// jwks_cache.meta.json with the parsed Cache-Control max-age.
func (c *JWKSClient) FetchJWKS() (*jwks.Set, error) {
    // 1. Soft-TTL: if the cache file is fresh per the recorded max-age, use it
    //    without touching the network.
    if set, ok := c.cacheIfFresh(); ok {
        return set, nil
    }

    // 2. Network fetch.
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    set, maxAge, err := c.fetch(ctx)
    if err != nil {
        return nil, err
    }

    // 3. Persist cache (best-effort; a failed write does not poison the success path).
    _ = c.writeCache(set, maxAge)
    return set, nil
}

func (c *JWKSClient) cacheIfFresh() (*jwks.Set, bool) {
    meta, err := c.readMeta()
    if err != nil {
        return nil, false
    }
    if c.now().Sub(meta.FetchedAt) >= time.Duration(meta.MaxAgeSeconds)*time.Second {
        return nil, false
    }
    data, err := os.ReadFile(filepath.Join(c.cfgDir, jwksCacheFile))
    if err != nil {
        return nil, false
    }
    set, err := jwks.ParseJWKS(data)
    if err != nil {
        return nil, false
    }
    return set, true
}

func (c *JWKSClient) fetch(ctx context.Context) (*jwks.Set, time.Duration, error) {
    req, err := c.client.buildRequest(ctx, http.MethodGet, JWKSPath, nil)
    if err != nil {
        return nil, 0, err
    }
    req.Header.Set("Accept", "application/jwk-set+json, application/json")
    resp, err := c.client.httpClient.Do(req)
    if err != nil {
        return nil, 0, fmt.Errorf("%w: %v", ErrNetworkFailure, err)
    }
    defer resp.Body.Close()
    if resp.StatusCode >= 500 {
        return nil, 0, fmt.Errorf("%w: HTTP %d", ErrServerError, resp.StatusCode)
    }
    if resp.StatusCode < 200 || resp.StatusCode >= 300 {
        return nil, 0, fmt.Errorf("backend: jwks fetch HTTP %d", resp.StatusCode)
    }
    body, err := io.ReadAll(resp.Body)
    if err != nil {
        return nil, 0, fmt.Errorf("%w: read jwks body: %v", ErrNetworkFailure, err)
    }
    set, err := jwks.ParseJWKS(body)
    if err != nil {
        return nil, 0, fmt.Errorf("parse jwks response: %w", err)
    }
    return set, parseMaxAge(resp.Header.Get("Cache-Control")), nil
}

// parseMaxAge extracts max-age from a Cache-Control header. Returns defaultMaxAge
// (3600s) when absent or unparseable.
func parseMaxAge(cc string) time.Duration {
    for _, part := range strings.Split(cc, ",") {
        kv := strings.TrimSpace(part)
        if !strings.HasPrefix(kv, "max-age=") {
            continue
        }
        if n, err := strconv.Atoi(strings.TrimPrefix(kv, "max-age=")); err == nil && n > 0 {
            return time.Duration(n) * time.Second
        }
    }
    return defaultMaxAge
}

func (c *JWKSClient) writeCache(set *jwks.Set, maxAge time.Duration) error {
    if err := os.MkdirAll(c.cfgDir, 0o700); err != nil {
        return err
    }
    data, err := json.Marshal(set)
    if err != nil {
        return err
    }
    if err := os.WriteFile(filepath.Join(c.cfgDir, jwksCacheFile), data, 0o600); err != nil {
        return err
    }
    meta := jwksCacheMeta{FetchedAt: c.now().UTC(), MaxAgeSeconds: int(maxAge / time.Second)}
    metaBytes, err := json.Marshal(meta)
    if err != nil {
        return err
    }
    return os.WriteFile(filepath.Join(c.cfgDir, jwksCacheMetaFile), metaBytes, 0o600)
}

func (c *JWKSClient) readMeta() (*jwksCacheMeta, error) {
    data, err := os.ReadFile(filepath.Join(c.cfgDir, jwksCacheMetaFile))
    if err != nil {
        return nil, err
    }
    var m jwksCacheMeta
    if err := json.Unmarshal(data, &m); err != nil {
        return nil, err
    }
    return &m, nil
}
```

## Risks and Edge Cases

- **Risk:** The big-bang RS256→ES256 fixture migration could leave a stray RS256 reference somewhere that compiles but fails at runtime. → **Mitigation:** the verifier rejects non-ES256 with `ErrInvalidAlgorithm`, which is loud and immediately localised. A targeted grep for `RS256`, `RSA PRIVATE`, `curlew-2025-0[12]` in `internal/license/`, `cmd/curlew/`, `testdata/` is added to the implementation checklist.
- **Risk:** `cmd/curlew/license.go` taking on a `backend` import could create a long-term coupling problem. → **Mitigation:** the dependency already exists (`license --refresh` imports `internal/backend`). No new import is added; only one new constructor call at the licence-validate site.
- **Risk:** Smoke test flakiness from port collision on 19081 when CI runs multi-jobs. → **Mitigation:** the existing `lsof -ti tcp:${PORT} | xargs kill -9` pre-clean pattern (already used at port 19080) is reused.
- **Edge case:** `Cache-Control: no-store` or `max-age=0`. → **Handling:** `parseMaxAge` returns 0 in those cases, which triggers an immediate refetch on the next `Fetch` call — desirable.
- **Edge case:** Server returns 200 with `Cache-Control` header missing entirely. → **Handling:** `parseMaxAge` defaults to 3600s per the spec; documented in code comment and a unit test.
- **Edge case:** `jwks_cache.meta.json` exists but `jwks_cache.json` is missing or corrupt. → **Handling:** `cacheIfFresh` returns false on any read/parse error; fetch path takes over, repairing the cache.
- **Edge case:** Sibling test fixture `jwks_cache.json` already on disk from a prior test run. → **Handling:** every test uses `t.TempDir()`; smoke test uses `mktemp -d` per section.
- **Edge case:** `rsa` import lingering in `jwt.go` after rename. → **Handling:** removing the import is part of Step 3's checklist; lint will catch a stray unused import.
- **Edge case:** Behaviour 4 says "rejects with InvalidAlgorithm without attempting key lookup". → **Handling:** dispatcher checks `algRegistry` *before* calling the verifier function; the lookup happens inside `verifyES256`, which only runs if the alg matched.
- **Edge case:** ES256 raw signature (R||S) length exactly 64 bytes vs. ASN.1-DER which `crypto/ecdsa.SignASN1` produces. → **Handling:** the minter helpers use `ecdsa.Sign` (returning `r,s *big.Int`) and `r.FillBytes(buf[:32])` to produce raw 64-byte JWS-compatible signatures. The verifier rejects any non-64-byte signature with `ErrSignatureInvalid` to defend against malformed JWTs.
